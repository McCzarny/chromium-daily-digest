Blink, Rendering & Web Platform

  • Renamed the position-visibility CSS property values anchors-visible and anchors-valid to anchor-visible and anchor-valid to align with CSSWG specifications, keeping legacy plural keywords behind a runtime feature. (065f994)
    BlinkCSS
  • Refactored blink::IDBKey to use std::variant instead of parallel members, shrinking its size and cutting heap memory usage by roughly 50%. (da7f116)
    BlinkPerformanceStorage
  • Altered ContainingBlock layout logic to return a LayoutBox instead of a LayoutBlock, addressing stale tree state issues during anchor positioning style updates. (91bd52e)
    BlinkCSS

Architecture, Refactoring & Performance

  • Stripped heavy concept-checking std::ranges constraints and range-based span constructors out of high-impact global headers like base/, url/, and wtf/, reducing overall compile CPU times by approximately 6.5%. (df5cca2)
    BaseBuildPerformance
  • Migrated raw pointers inside templated containers (std::vector, std::array) to raw_ptr across casting and remote audio subsystems to harden protection against UAF vulnerabilities. (427e602) (37c3307)
    BaseSecurity
  • Refactored TracedValue::ValueHolder to use std::variant instead of manual untagged unions and enums, resolving a memory leak for heap-allocated strings. (8998a39)
    BasePerformance

Security, Permissions & Enterprise Policy

  • Restricted browser-process tracing and GPU memory dumps in DevTools to trusted sessions, preventing untrusted clients from extracting cross-process profiles. (d76b46e)
    DevToolsGPUSecurity
  • Officially deprecated the SafeBrowsingExtendedReportingEnabled enterprise policy, removing active mapping logic now that Enhanced Protection covers reporting preferences. (63b1c79)
    EnterprisePolicySecurity
  • Strengthened File System Access write validations to block unauthorized writes into sensitive subdirectories like .git/hooks during createWritable operations. (b601ae1)
    SecurityStorage

UI, Accessibility & Platform Integrations

  • Modularized browser components by migrating tab-level helpers and observers away from WebContentsUserData into individual TabFeatures instances. (281fcd9) (477d79b)
    BrowserTabsUI

    AccessibilityAndroid
  • Unified the shared C++ HistoryUI controller across desktop and mobile platforms while removing legacy Android stub implementations. (984b91c)
    AndroidHistoryUI

Build Infrastructure, Tooling & Testing

    BuildInfra
