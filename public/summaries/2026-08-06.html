Core Infrastructure & Architecture

  • ⚠️Synchronous legacy IPC has been completely removed with the transition to Mojo. ipc/ipc_sync_channel.h is deleted, and RenderThread::GetChannel() now returns IPC::ChannelProxy* instead of IPC::SyncChannel*. (a006055)
    BaseNetworkBrowser
  • ⚠️Refactored multi-network Chrome Custom Tabs to bind requests directly via net::UrlRequest target networks, requiring a signature change to ContentBrowserClient::WillCreateURLLoaderFactory (adding bool is_for_network_service). (925f969)
    NetworkAndroidBrowser
  • Removed legacy helper class IPC::MojoMessageHelper, inlining MojoHandleAttachment creation directly into ParamTraits<mojo::MessagePipeHandle>. (a060853)
    BaseBrowser

Security & Privacy

  • Added explicit origin-validation checks inside File System Access API handle implementations to reject foreign-origin transfer token bypasses. (74bd851)
    SecurityPrivacyStorage
  • Hidden privileged clients from the Service Worker Clients API and explicitly disabled prerendering for PrivilegedWebContents to prevent navigation throttle bypass vectors. (e33ef02) (d9083c9)
    SecurityServiceWorkerPrivacy
  • Added IsRelatedToCurrentFrameHost() checks in RenderFrameProxyHost IPC handlers to prevent speculative cross-BrowsingInstance processes from acting on active documents. (de1ee18)
    SecurityNavigation

Blink Engine, Web Platform & Rendering

  • Renamed RegisterURL() and GenerateURL() to RegisterUrl() and GenerateUrl() inside Blink's internal PublicURLManager to align with C++ abbreviation casing guidelines. (839d19b)
    BlinkStorage
  • Added compile-time and runtime type specifier support ('d', 'x', 'X', 's') in blink::Format(), VFormat(), and VFormatTo() in WTF. (64a80e7)
    BlinkBase
  • Resolved timing race conditions in ImagePaintTimingDetector when first video frames painted while poster images were still pending by replacing poster tracking with new video frame ImageRecord creation. (7c52286)
    BlinkMediaPerformance

UI, Views, & WebUI

  • Configured ViewsAX to mark WebView nodes as ignored, preventing duplicate tree nodes from exposing to platform accessibility APIs while preserving the bridge to web content trees. (ff8931f)
    AccessibilityUI
  • Deferred tab drag migration and target window updates until after RunWindowMoveLoop unwinds from the callstack, preventing move loop reentrancy. (269f665)
    UITabs

Android & ChromeOS Features

  • Replaced OnGlobalLayout() on decor views with onLayoutChange() in ChromeAndroidTaskImpl to check old vs. new bounds, reducing unnecessary WindowStateManager#update() IPC calls and preventing main-thread ANRs. (e9117f0)
    AndroidPerformance
  • Updated vertical tab layouts on Android tablets to satisfy 48dp touch targets, adjusting button heights, padding, and TabListFaviconProvider sizes. (88c96b1)
    AndroidTabsUI
