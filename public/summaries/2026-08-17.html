Chromium Digest: 2026-08-17

Overview

Daily summary for Chromium changes on main branch (2026-08-17), covering 618 total commits (512 relevant). Spanning from commit (3bf742b) to (7044c92).

Security & Cryptography

  • Added full support for ML-KEM-768 key generation, serialization routines, PKCS#8/SPKI integration, and end-to-end integration into crypto::hpke for Base mode Seal and Open operations. (db220c8)
    CryptoSecurity
  • Guarded identity.launchWebAuthFlow against browser context shutdown races by immediately aborting active authentication requests during profile shutdown. (88a292e)
    ExtensionsBrowser

Blink, Layout & CSS Engine

  • Corrected CSSSelector bit-field assignments for IsScopeContainingField to fix incorrect attribute selector bucketing in RuleSet and scope activation bugs. (31df839)
    BlinkCSS
  • Updated the style adjuster to map inline drawables as inline-blocks instead of blocks to allow fixed positioning support inside canvas layout subtrees. (677c2bb)
    BlinkGPU

Performance & Core Optimization

  • Established structured hierarchical parent-child theme observation on Widget, removing manual process-wide GetAllOwnedWidgets() traversal loops during theme changes. (6b597cd)
    UIPerformance
  • Added a state guard to WebViewImpl to ensure Page::UsesOverlayScrollbarsChanged() is only invoked when OS overlay scrollbar preferences actually toggle. (87d7c8f)
    AndroidPerformance

UI/UX & Platform Architecture

  • Migrated tab list coordinator patterns, listeners, and Incognito testing overrides from nullable booleans to primitive TriState representations, introducing an immutable TabListConfig data class. (7044c92) (e616b05)
    AndroidTabs
  • Continued structural migration away from direct Browser class usages by replacing dependencies with BrowserWindowInterface across core browser metrics and profiles. (c23dffd) (ab520dc)
    BrowserUI

Infrastructure, Build & Tooling

  • Introduced base::DummyMemoryConsumerRegistry as a placeholder implementation in enterprise companion services to prevent test crashes during worker initialization outside content. (f677b0b)
    BaseEnterprise
  • Reverted Clang modules enablement on Windows following compile-time regressions on ASAN and win-libfuzzer builders. (5a571a9)
    BuildWindows
