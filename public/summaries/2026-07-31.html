A comprehensive daily digest of Chromium changes on 2026-07-31 (main branch) covering 658 total commits, with 501 selected as relevant. The activity spans from commit (5ff48ff) to (a51f7bd).

UI/UX & Platform Features

  • Decoupled tab search initialization logic from Vertical Tabs state to ensure tab search is always accessible, and improved vertical tab list dragging for edge cases. (a51f7bd) (1a24e9e) (d2a8f21)
    TabsUIAndroid
  • Replaced deprecated profile string IDs with unguessable BrowserContext tokens in BrowserActionDragData serialization and exposed 'Inspect popup' for extensions on Desktop Android. (bc6ac8c) (917195d) (c6d4f3c)
    ExtensionsBrowserAndroid
  • Renamed PostMessageToWebview to PostAimMessage across Contextual Tasks Mojom interfaces and handlers, and programmatically enabled MojoJS on startup. (7db907a) (ec4e433) (fb3137a)
    AIUIBrowser
  • Added support for URL, text, and PDF drag-and-drop on the Android LocationBar via LocationBarDragDropHandler. (6d68980) (78e6ce2)
    AndroidUI

Security & Sanitization

  • Disallowed EOCD64 record tokens in CRX file headers behind a default-enabled feature flag to prevent malformed archive exploitation vectors. (fac0b68)
    SecurityExtensionsUpdater
  • Utilized an inert document when constructing sanitizer-disallowed elements during HTML streaming/parsing to prevent constructor-time side effects. (8135fe5)
    BlinkSecurityHTML
  • Hoisted the OriginMayUseRemoteDesktopClientOverride security policy check to the beginning of ValidateDomainAndRelyingPartyID in WebAuthn. (7f59498)
    SecurityNetwork

Media, Audio/Video, & Device APIs

  • Fixed upstream Symphonia MP3 decoding failures on zero-length granule sections and enabled DirectOpusAudioDecoding experiment on Android. (7cc5b36) (3f9ba89)
    MediaAndroid
  • Enabled background event monitoring in GameControllerDataFetcherMac to ensure PlayStation and Xbox controllers are detected inside macOS PWAs. (d562e23)
    macOSUI

Core Infrastructure, Performance, & Bug Fixes

  • Increased hash computation chunk size from 4 KB to 1 MB in FileAnalysisRequestBase, reducing IPC and D-Bus overhead on virtual filesystems. (00052c0)
    ChromeOSPerformanceEnterprise
  • Updated ChromeBrowsingDataRemoverDelegate and DownloadManager to handle deferred history loading and uninitialized download manager states properly. (41b6ed0)
    HistoryDownloadsBrowser

Blink & Rendering Engine

  • Expanded CSS Masonry layout overflow direction handling to support fill-reverse and track-reverse rules matching flexbox scroll origin logic. (5808836)
    BlinkCSS
  • Refactored SkiaOutputDeviceDawn into SkiaOutputDeviceDawnSwapChain and introduced SkiaOutputDeviceDawnD3D11BltMode for DXGI BitBlt partial rendering. (6ae0cda) (0d2c4a6)
    GPUBlinkWindows

Security, Privacy & Enterprise Policies

  • Introduced device-level Local Network Access policies for ChromeOS and widened IDN spoof checks to reject Katakana Middle Dot when adjacent to non-Japanese characters. (1900a2a) (7cc70a2)
    PolicyChromeOSSecurity
  • Hardened WebNN GPU process security by deriving operand descriptors directly from compiled model I/O metadata instead of trusting untrusted compiler Mojo messages. (77bef96)
    GPUAISecurity

C++ Base Library & Refactoring

  • Migrated all Chromium usages of base::RangeAsRvalues to the C++20 standard library equivalent std::views::as_rvalue and removed the legacy implementation. (1b3a1f7) (9f638e5)
    Base
  • Successfully removed temporary base::zip alias and base/types/zip.h, transitioning all usage to standard std::views::zip. (37c05ae)
    Base
