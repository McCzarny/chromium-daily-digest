Week 43 of 2026 (2026-10-18 to 2026-10-23)

Chromium Weekly: 2026 Week 43

Overview

Across 6 days in Week 43 of 2026, Chromium development saw major embedder-facing breaking changes including the extensive cleanup and removal of Shared Storage, Top-Level Storage Access, and Related Website Sets APIs. Significant security hardening arrived across renderer process sandboxes, extension handling, and credential UI sanity, alongside notable web platform additions like Incremental Font Transfer conformance, WebTransport send-group stats, and audio/canvas optimizations.

Breaking Changes & Embedder APIs

  • ⚠️BREAKING CHANGE Shared Storage API removed: ContentBrowserClient worklet hooks, SharedStorageBudgetMetadata plumbing in fenced frames, storage models (BrowsingDataModel::StorageType::kSharedStorage), remover masks, and inspection targets have been removed. (0289254) (a431c50) (e3e3e05)
    StoragePrivacyBrowser
  • ⚠️BREAKING CHANGE Related Website Sets (First-Party Sets) core deleted: FirstPartySetsHandler, ContentBrowserClient RWS hooks, and kStorageAccessAPIRelatedWebsiteSets removed; RWS-decided grants are deleted on startup. (845d377)
    BrowserNetworkStorage
  • ⚠️BREAKING CHANGE Top-Level Storage Access plumbing removed from stable embedder APIs, including net::CookieSettingOverride::kTopLevelStorageAccessGrantEligible and ContentSettingsType::TOP_LEVEL_STORAGE_ACCESS. (75b7b36)
    NetworkStorageBrowser
  • ⚠️BREAKING CHANGE Removed per-widget software compositing flags: force_software_compositing in views::Widget::InitParams and the aura::WindowTreeHost creation parameter were eliminated; widgets now strictly inherit the global compositing policy. (0435c36)
    UICompositorGPU
  • ⚠️BREAKING CHANGE ui::TreeNodeModel<T> removed and TreeModel devirtualized: public template helper class deleted, and multiple accessor methods across TreeModel and TreeModelNode are no longer virtual. (3be49d7)
    UIBase
  • ⚠️BREAKING CHANGE Windows and iOS embedder interface shifts: ChildModule hooks removed from Windows ContentBrowserClient in favor of GetRendererSandboxPolicyExtension, and web::CertPolicy was privatized from iOS public security headers. (5860166) (1140de6)
    BrowserSecurityiOS
  • ⚠️BREAKING CHANGE Declarative Net Request rules matching response header values (values/excludedValues) now mandate host permissions, skipping unmatched rules and incrementing kIndexedRulesetFormatVersion to 37. (22a2af9)
    ExtensionsNetworkSecurity
  • ⚠️BREAKING CHANGE Build configuration cleanups: Third-party Khronos headers target (//third_party/khronos) deleted in favor of //third_party/angle/include, and Trichrome Android targets were removed from chrome/android/BUILD.gn. (c244b2d) (fa9b540) (9c01668)
    BuildGPUAndroid

Security & Privacy

  • Hardened renderer sandboxing and window management: Restricted process-info-pidinfo to self on macOS, validated CreateNewWindowParams referrers on child frames, and enforced single-use window touch drag tracking on Linux/Wayland. (e24ae5a) (fc98b05) (5491e56) (0552262)
    SecurityLinuxmacOS
  • Credential and UI spoofing protections: Sanitized site-controlled username strings supplied via navigator.credentials.store() to collapse control characters, and restricted WebAppUrlLoader committed URL requirements on shared background navigations. (71b45ec) (6c67a1f)
    SecurityAutofillPrivacy
  • Extension and capture hardening: Immediately revoke directory capabilities during extension unzipping, abort active tabCapture sessions upon cross-origin chrome:// navigations, and gate enterprise download actor attribution behind kEnterpriseExtensionActorAttribution. (7a0c3ee) (851a6a2) (d6712da)
    ExtensionsSecurityEnterprise
  • Cryptographic protections: Disallowed ML-KEM in HPKE Auth mode to avoid BoringSSL integration crashes, and made crypto::kex::X25519() fallible to reject small-order points. (ae89152) (df5b66f)
    CryptoSecurity
  • File System Access sensitive path blocklists expanded to restrict web write access to shell configuration dotfiles and internal .git directories. (d6f2c70)
    StorageSecurity

Web Platform & Blink Engine

  • Shipped Incremental Font Transfer (IFT) conformance updates: Patches now fetch via dedicated load-patch-file flows and base font glyphs are validated prior to network patch requests. (c229f16) (3c20103) (2c6e109)
    BlinkFonts
  • Implemented WebTransportSendGroup.getStats() returning bytesWritten, bytesSent, and bytesAcknowledged metrics via batched stream statistics Mojo queries. (4cc5073) (8e23d67)
    NetworkBlink
  • Web-visible UI behavior fixes: Form <select> pickers now trigger open events upon clicks to associated <label> elements, and .class selectors correctly match non-HTML XML namespace elements. (3c0b846) (6b6415c)
    BlinkHTMLCSS
  • Defense-in-depth relatedTarget sanitization: Stripped cross-origin relatedTarget references to null across MouseEvent, PointerEvent, and FocusEvent dispatches under ClearCrossOriginRelatedTarget. (bb79a99)
    BlinkSecurity
  • Shipped OfflineAudioContext incremental rendering and close() support alongside direct-socket source-specific multicast joins (joinGroup/leaveGroup). (4c7feeb) (8774e07)
    BlinkMedia

Performance & Architecture

  • base::FeatureList lookup optimization: Enabled caching of fully resolved enabled feature states directly, cutting overhead from 10.92 ns down to 4.10 ns (~62% faster) per IsEnabled() call. (df3a810)
    BasePerformance
  • Accessibility CPU optimizations: AX node removal skips untracked DOM IDs and inline text box serialization drops duplicate text shape allocations, eliminating ~10% of Blink accessibility CPU overhead. (839b84f) (a396129)
    AccessibilityBlinkPerformance
  • Linearized IME and canvas operations: Refactored PlainTextRange::CreateRange() to resolve runs linearly to eliminate large textarea input lag, and unified canvas initialization inside Reshape. (5eade4f) (37eaf3d)
    BlinkPerformanceHTML
  • Display refresh synchronization: Enabled kUseDisplayRefreshRateForTimer by default on macOS to dynamically sync compositor fallback timers to physical display refresh rates rather than fixed 60 Hz. (c254fd1) (de1036a)
    macOSCompositorPerformance
  • Broad migration of Android JNI bindings from raw long pointers to type-safe JniUniquePtr/JniRawPtr smart handles across autofill, dialogs, extensions, and sync bridges. (1e5b7ea) (bc707de) (e399952) (7600d89)
    AndroidBase

DevTools & Tooling

  • CDP wheel-event delta scaling corrected: Input.dispatchMouseEvent mouse-wheel deltas now scale by CSS, pinch, and browser zoom levels, rejecting nonfinite or out-of-range delta configurations. (b629151)
    DevToolsBlink
  • BiDi and CDP autofill synchronization: Implemented WebDriver BiDi autofill.trigger mapped to CDP Autofill.trigger, guaranteeing responses wait for full multi-frame field extraction. (dc8635a)
    DevToolsAutofill
