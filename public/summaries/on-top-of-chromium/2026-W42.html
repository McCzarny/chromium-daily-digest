Chromium Weekly: 2026 Week 42

Overview

Week 42 brings substantial architectural changes across Chromium, led by the ongoing migration of tab helpers into TabFeatures and embedder API cleanups in ContentBrowserClient and StoragePartition. In total, 3939 relevant commits out of 4950 total across 7 days were analyzed, prioritizing improvements for desktop embedders on Windows and macOS. Core focus areas include extension security hardening, hardware compositing for desktop UI widgets, and foundational base performance optimizations.

Breaking Changes & Embedder APIs

  • ⚠️BREAKING CHANGE: ContentBrowserClient child-module hooks have changed on Windows: GetChildModuleVersion() is replaced by GetChildModule() returning a ChildModule struct, and PreSpawnChild() now accepts base::optional_ref<const ChildModule>. Additionally, ContentBrowserClient adds IsUnboundedElementEscapingAllowed to govern viewport escaping for privileged extension subframes. (b73ceff) (c02f9fc)
    WindowsSecurityBrowser
  • ⚠️BREAKING CHANGE: content::StoragePartition adds a pure virtual GetQuotaManagerProxy() method for bucket changes, requiring custom storage partition embedders to implement the override. Additionally, BrowserWindowInterface::Type::TYPE_PICTURE_IN_PICTURE was renamed to TYPE_FLOATING without an alias, and ActionManager::FindAction() now requires callers to explicitly pass an action scope. (3377a85) (1b27f5e) (89aa9ea)

Browser Architecture & Tab Management

  • ⚠️BREAKING CHANGE: WebContentsUserData helper attachment was migrated out of TabHelpers::AttachTabHelpers into the modular TabFeatures framework across multiple subsystems, including Translate, History, SubresourceFilter, Zoom, and Autofill. Downstream embedders maintaining custom patches against tab_helpers.cc must update their feature initialization points. (875cc29) (5b4cbd9) (c54bf53) (3e5b9b4) (4590613) (50758ef)
    TabsBrowser

Extensions & Security

  • Extension action popup URLs specified via manifest or chrome.action.setPopup are now strictly validated to use the chrome-extension:// scheme, rejecting blob: and filesystem: schemes to eliminate RCE vectors. Furthermore, kRestrictGeneratedPathsInWebAccessibleResources is enabled by default to block wildcard access to internal generated resources like _favicon. (7811f3b) (fad4d6c)
    ExtensionsSecurity
  • Extension service workers now support clipboard writes by default when granted the clipboardWrite permission, and service worker registration recovery was hardened to retry failed registrations gracefully without thrashing nonexistent workers. In addition, chrome.mimeHandler introduces optional canEmbed support for embedded MIME handlers. (6eb0b84) (2446f13) (7c857c3)
    ExtensionsServiceWorker

Desktop UI & Windowing

  • ⚠️BREAKING CHANGE: Window features can now request always-on-top popup windows (ALWAYS_ON_TOP_POPUP) when the window_management permission is present. In addition, WebuiOmniboxHandler has been decoupled from content::WebUI to accept profiles and WebContents directly, enabling non-WebUI host controllers. (afff432) (5a5ef6e)
    BrowserUIWindows
  • Desktop windowing received stability fixes on both desktop platforms: secondary Windows widgets now default to hardware GPU acceleration instead of software D3D10Warp compositing, while macOS resolves out-of-memory crashes on fullscreen exit by clearing the first responder before hiding WebContents NSViews and suppresses app shim background launches during browser shutdown. (9ebbe2c) (9458c44) (a32d2fe)
    UImacOSWindows

Networking & Core Infrastructure

  • Pervasive shared dictionaries are enabled by default for cross-origin delta compression. In security hardening, WebSocket cancellation is restored when servers request unselected client certificates, captive-portal WebDialog dialogs now block file downloads via CanDialogDownload(), and Windows elevation and GCPW services enabled Redirection Guard to thwart privilege escalation via junction points. (f5be834) (3cf2b1b) (82594fc) (38714c0) (06f21c7)
    NetworkSecurityWindows
  • base::FeatureList evaluation was optimized with lock-free atomic cache hits to eliminate map lookups in repeated IsEnabled() checks, and PrefService lookups now utilize GetValueFromNonDefaultStores() to bypass linear searches. Additionally, ImportantFileWriter preserves temporary files upon replacement failures to safeguard against data loss. (521faa0) (1323b32) (a6c86ee)
    BasePerformanceStorage
  • ⚠️BREAKING CHANGE: Include-what-you-use cleanups decoupled url/url_canon_stdstring.h from url/gurl.h, requiring out-of-tree embedders to include canonicalization headers directly. Additionally, SharedMemoryMapping::memory() callers were migrated to type-safe GetMemoryAs<T>() and span APIs across GPU, media, and base subsystems. (a9a1cfc) (133929c)
