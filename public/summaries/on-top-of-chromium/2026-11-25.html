Chromium Digest: 2026-11-25

Overview

On 2026-11-25 the main branch received 1288 commits, of which 1017 were filtered as relevant to Windows/macOS embedders. The day was dominated by a large batch of public-interface signature changes (proxy policy, tab strip, auth token vault, GCM, HTML serialization, ui::TreeModel), the outright removal of the OOPIF PDF policy, and a broad set of security hardening and startup-performance wins. Range: first commit (b9ad86e) (https://chromium.googlesource.com/chromium/src/+/(b9ad86e)), last commit (3a1d1cd) (https://chromium.googlesource.com/chromium/src/+/(3a1d1cd)).

Breaking Public API Changes

  • ⚠️AreUserProxyOverrideRulesAllowed() signature and scope enforcement changed. The exported two-argument form (const PrefService*, policy::PolicyService*) is replaced by a single policy::PolicyService* argument in components/proxy_config/proxy_prefs_utils.h, so downstream callers fail to build. Behaviorally the EnableProxyOverrideRulesForAllUsers policy must now be POLICY_SCOPE_MACHINE; a user-scoped instance is silently ignored for unaffiliated users, which also affects proxyOverrideRulesPrivate extension modifiability. (57195b3)
    NetworkEnterprisePolicy
  • ⚠️TabStripModelDelegate::MoveToExistingWindow() gains a required std::optional&lt;tab_groups::TabGroupId&gt; parameter. The pure-virtual in chrome/browser/ui/tabs and chrome::MoveTabsToExistingWindow() were updated in-CL; any embedder subclass or caller breaks. Tabs added to a group in another window now insert at the group tail and preserve Focus Mode, and split-tab insertion exits focus mode outside the focused group. (75c5419)
    TabsUIBrowser
  • ⚠️ui::TreeModel traversal surface removed and observation contract tightened. GetChildren(), GetIndexOf(), GetParent() and the Nodes typedef are deleted from the exported ui/base/models/tree_model.h with no deprecation window (consumers must use TreeModelNode accessors). TreeModelObserver now derives from base::CheckedObserver with a check_empty observer list, so destroying a model with live observers CHECK-fails, and the exported NotifyObserverTreeNode*() helpers are gone. (439ecc1) (a210a2f)

TrustedVaultClient::FetchKeys()'s completion callback now yields std::vector<trusted_vault::TrustedVaultKeyAndVersion> instead of a vector of raw keys, forcing updates in every implementation and in SyncServiceCrypto/passkey consumers. In parallel, OAuth2AccessTokenFetcher loses GetNetworkLatency()/GetChallengeSigningLatency() in favor of the new pure-virtual GetLatencies() returning an OAuth2AccessTokenFetcher::Latencies struct, so out-of-tree subclasses and mocks must add the override. Security & Privacy

  • Untrusted-renderer and cross-origin trust boundaries tightened. MediaInterfaceProxy/FramelessMediaInterfaceProxy now ReportBadMessage() instead of CHECK-killing the browser when a renderer passes an already-bound decoder; url::Origin deserialization rejects invalid pickled tuples and CHECKs in the SchemeHostPort constructor; ClipboardHostImpl::ReadFiles() only accepts kCopyPaste (closing a selection-buffer file-name read); and mixed-content reports strip cross-origin URLs to their origin before they reach a cross-origin RenderFrameHost. (b8d3ae8) (2915c95) (5dcedee) (2d55c14)
    SecurityMediaBlink
  • Safe Browsing referrer chains no longer leak unrelated IPs or allowlist remnants. SanitizeReferrerChainEntries() clears ip_addresses unless subframe and main frame share a host (previously a main-frame URL was paired with a third-party subframe IP), RemoveSafeBrowsingAllowlistDomains clears IPs too, is_url_removed_by_policy is evaluated per entry, and consumer Enhanced/Standard-protection users no longer upload server IPs at all — only ESB or enterprise-managed profiles do. (fa24034) (9ecb305) (07f19ae)
    PrivacyNetworkSecurity
  • Crash reports no longer carry UMA identifiers in the system profile. MetricsService::RecordCurrentEnvironment() now hands MetricsServiceClient::OnEnvironmentUpdate() a re-serialized copy with client_uuid, session_hash, fg_bg_id and cloned_install_info cleared via the new MetricsLog::ClearUmaIdentifiers(), closing a leak into the Crashpad environment stream. Logs, prefs and the persistent system profile keep identifiers; custom crash-key or uploader logic that read those fields will see them absent. (e6a1451)
    PrivacyBase
  • WebAuthn privacy and PIN-flow hardening. Silent getAssertion probes now build a minimal CTAP request behind enabled-by-default kWebAuthnOmitExtensionsInSilentGetAssertion (removal planned M163), so largeBlobKey, largeBlob, credBlob, cmtgKey and prf are never sent to pre-flight probes or written prematurely. GPM PIN change is reworked to require OS user verification first (failing closed where OS UV is unavailable) with local PIN hashing/verification isolated in gpm/local_gpm_pin_crypto. (fd45a7f) (600901a) (009c9ea)

ScriptPromise now catches and clears pending V8 exceptions from reaction attachment/resolver allocation instead of leaking them into a cross-origin caller frame; HistoryClustersTabHelper::OnUkmNavigationComplete() early-returns and re-checks annotations to fix a use-after-free; SVG SMIL RemoveAnimation() no longer holds a HashMap iterator across a rehash; and BookmarkCodec validates permanent-node dictionaries and bounds persisted IDs to stop a startup crash on corrupt bookmark JSON. Browser & Extension Behavior

Performance & Startup

  • Startup main-thread work reduced. HistoryServiceFactory defers backend init to first window first presentation (fixing blank NTP favicons) with measured BrowserWindow.FirstPaint −5.5 ms and FirstWebContents.NonEmptyPaint3 −26.5 ms, and DowngradeManager returns early when the recorded last version equals the current one, skipping macOS OpenDirectory XPC / Windows domain and Azure AD queries on every warm start (ReloadButton.FCP −2.0 ms). (959e9d3) (14a5582)
    PerformanceHistoryBrowser
  • Page-load and menu-open latency wins. Bundled V8 code caching for chrome://new-tab-page/ (behind kWebUIBundledCodeCacheForNewTabPage) reports NTP load startup −32 ms cold / −36 ms warm on Linux and −19 / −17.5 ms on macOS Apple silicon. The Cocoa History menu is lazily populated behind kHistoryMenuOptimizations, dropping TabRestoreServiceChanged() from 135 ms to 0.21 ms and session load from 137 ms to 0.24 ms for large restored sessions. (f1d384f) (2adfc18)
    PerformancemacOSUI
  • Algorithmic and decode hot-path improvements. Bookmark lookups gain an IdIndex (BookmarkModel::GetNodeById()) so GetBookmarkNodeByID() is O(1) instead of a recursive DFS, removing quadratic behavior in extension batch operations, WebUI PathOps and undo. Read Anything's suffix-array construction switches to prefix doubling, turning a 2.5 s case on a 100k-character page into a fast path with identical output. (948ff69) (7c032c8)
    PerformanceBookmarksUI
  • Memory pressure and binary-size wins. TransferBuffer::AllocateRingBuffer() retries smaller shared-memory sizes with kReturnNullOnOOM before the final minimum-size attempt, so GLES2/raster/WebGPU contexts survive transient shm pressure instead of being lost. Several large static tables (sync DataType lookup, metrics CRX-ID map, Google/YouTube TLD sets, Blink legacy TLD table) move from .data.rel.ro to .rodata, removing hundreds of dynamic ELF relocations from the startup path. (6ae0cca) (ec54826) (7555976)
