Chromium Digest: 2026-08-22

Overview

Analyzed 87 commits from Chromium main branch positions #(1684318) through #(1684532). This digest highlights relevant platform, architecture, UI, security, and extension infrastructure updates for Chromium embedders on Windows and macOS.

Security, Embedder APIs & Networking

  • Exposed EnableMojoJsBindingsWithBroker on the public content::RenderFrameHost interface to allow embedders to restrict a frame's Mojo.bindInterface access exclusively to interfaces served by a caller-supplied BrowserInterfaceBroker. (d5f9bc7)
  • Scoped clipboard paste authorization based on user interaction to the specific requesting frame, preventing top-frame activations from authorizing cross-origin child frames. (79c8297)
  • Sanitized product name strings displayed in WebUSB chooser UI by trimming trailing NUL characters. (514fcd3)
  • Made private key handling in client certificate generation scripts idempotent to reduce repository churn. (c931044) (1fab2c4)

Extensions & Privileged Features

  • Refactored Mojo PageHandler management for component extensions into dedicated frame-scoped (DocumentUserData) and profile-scoped service worker factories. (d6ed892)
  • Prevented unnecessary ExtensionMojoBinderRegistry KeyedService instantiation during read-only queries in OTR or guest profiles. (0f0dca7)
  • Exposed privileged-web-contents feature flag in chrome://flags for testing privileged WebContents infrastructure. (7d2bc33)

Performance Manager & Resource Scheduling

  • Introduced an idempotent SetVote(std::optional<Vote>) API to PriorityVotingSystem to simplify priority voters and eliminate client-side map wrappers. (6cd1564) (82ae54b)
  • Removed OptionalVotingChannel wrapper after integrating optional vote support directly into the core voting channels. (8021028)
  • Implemented auto-todo entry expiration and background cleanup in Context Hub using a default 30-day TTL. (3e3a152)

Browser UI & Layout Components

  • Extracted Views UI modules for autofill address, payment dialogs, and popup rows out of monolithic build targets into specialized subdirectories. (6fe805a) (a490aff) (6330758)
  • Reduced WebUI omnibox state leakages across tab switches by saving cursor positions and validating active tab IDs prior to dispatching autocomplete queries. (d49a166) (6e4b116)
  • Introduced ComposeboxInputModel to unify context attachment calculations and set composebox inputs to plaintext-only. (3086a9c) (beb5cbb)
  • Migrated ConnectionHelpTabHelper lifecycle management into TabFeatures. (5c93650)

Infrastructure, Code Health & Testing

  • Decoupled printing test infrastructure from BrowserWithTestWindowTest and extracted standalone test support targets under chrome/test/base as part of Project Bedrock. (07d11bd) (0db7fb6) (2a00d92) (1f40624)
  • Replaced deprecated base::KiBU() memory helpers with base::KiB() across gpu, chrome/browser, services, and media modules. (4cd92ce) (89ea59c) (aeb14e9) (d1e3700) (6c9b9c0)
  • Modernized memory copying in TaskTrace::GetAddresses() using span::copy_from(). (e7522ba)
  • Ensured TaskEnvironment worker threads outlive global ScopedFeatureList instances during test teardown to prevent segmentation faults. (827be56) (5c5b1c8)
