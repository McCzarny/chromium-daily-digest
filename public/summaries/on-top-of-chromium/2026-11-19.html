Chromium Digest: 2026-11-19

Overview

On 2026-11-19 the main branch received 1240 commits, of which roughly 960 were judged relevant to Chromium embedders. The range runs from (1459778) to (88225bf). Five confirmed breaking changes land in embedder-facing interfaces (extension response payloads, NavigationUIData, TabStripModelObserver, ComponentUpdateService::Cancel, and the system proxy resolver switch), alongside several security hardening fixes, Windows/macOS browser UI work, measurable performance wins in bookmark menus and text layout, and build-level changes around C23 and PartitionAlloc.

Breaking Changes & Required Migrations

  • ⚠️Breaking: extensions::ExtensionFunction::ResponseCallback now carries extensions::mojom::ResponseWrapperPtr instead of base::ListValue, and the same substitution ripples through LocalFrameHost.Request() and ServiceWorkerHost.RequestWorker() via a new ResponseWrapper union. Embedders that subclass ExtensionFunction, install a custom response_callback_, or implement those mojom methods must migrate. This is CL 1/3 moving declarativeNetRequest.getDynamicRules() serialization off the browser UI thread (up to 30,000 rules per call). (af69b74)
    ExtensionsPerformance
  • ⚠️Breaking: content::NavigationUIData::CloneForNewNavigation() is renamed to MaybeCreateForRedispatchedNavigation() with a clarified contract (subclasses may return nullptr when all caller-supplied fields are default). Any embedder overriding the virtual or calling the redispatch clone in OpenURLParams::FromNavigationHandle() fails to compile until migrated. (797a1d8)
    NavigationBrowser
  • ⚠️Breaking: TabStripModelObserver::OnTabBlockedStateChanged(tabs::TabInterface*) becomes OnTabBlockedStateChanged(tabs::TabHandle), and the newer OnTabChanged(tabs::TabHandle, TabChangeType) hook is added (defaulting to forward to the deprecated OnTabChangedAt, with in-tree observers migrated). Downstream browser forks implementing either observer member must update. (749b032) (ad58ca3) (c2fa9e1) (7f05439)
    TabsUI
  • ⚠️Breaking: ComponentUpdateService::Cancel(id) becomes Cancel(id, update_client::CancelMode), a new pure virtual on the exported, commonly-mocked updater interface. All embedder implementations and mocks break. Runtime behavior is deliberately unchanged for now (UrlFetcherDownloader::Cancel ignores kKeepPartialDownload), and CrxUpdateService::CancelMeteredDownloads() now picks the mode per component. (03e4b71)
    UpdaterExtensions
  • ⚠️Breaking: switches::kUseSystemProxyResolver is deleted. Native system proxy resolution (WinHTTP on Windows, CFNetwork on macOS) is now gated by BASE_FEATURE(kSystemProxyResolver, FEATURE_DISABLED_BY_DEFAULT) enabled via --enable-features=SystemProxyResolver, with legacy --winhttp-proxy-resolver taking precedence. Proxy-service construction — including the URLRequestContextBuilderMojo path — always routes through net::ConfiguredProxyResolutionService::CreateUsingSystemProxyResolver(), so out-of-tree system-resolver implementations are affected, and macOS PAC execution is still unsupported in the utility-process resolver. (8a813b9)
    NetworkmacOSWindows

Security & Privacy

  • getDisplayMedia frame-rate constraints can no longer crash the browser process: an ideal frameRate of 0, negative or subnormal produced a 0 fps value that passed VideoCaptureFormat::IsValid() and hit a DCHECK_GT/divide-by-zero in DesktopCaptureDevice. Constraint selection now enforces a 1/1024 fps minimum, non-positive rates are rejected before reaching the device, and the device-level check is a CHECK_GT. (580ea91)
    MediaSecurity
  • GWP-ASan and on-demand heap profiling are restored in release/official builds. An over-broad EXPENSIVE_TEST_LOGIC_IS_ON() guard had disabled GWP-ASan in production and flipped PoissonAllocationSamplerInclusion to kDynamic, breaking Perfetto HeapProfilingDataSource and DevTools Memory.startSampling; kEnforce is now unconditional with hooks deferred until sampling starts. (0bece1a)
    BaseSecurityDevTools
  • IDN spoof-check hardening: the whole-script-confusable loop in IDNSpoofChecker::SafeToDisplayAsUnicode() now runs for all USPOOF_SINGLE_SCRIPT_RESTRICTIVE labels before the kana/combining-mark exception gate, closing a bypass where one added combining mark (U+0301/U+0326) suppressed the check on Cyrillic/Greek lookalikes. Relatedly, dragged .url shortcuts now sanitize Windows reserved device names (COM1.url → _COM1.url) and base::IsReservedNameOnWindows() also matches superscript device digits and trailing-space variants. (ba5d1b8) (952223d)
    NetworkSecurityWindows
  • Origin validation tightened in two user-visible surfaces: persistent notification click/close events are only dispatched to a service-worker registration that is live and whose storage key matches the notification's origin (including notifications already persisted with attacker-supplied registration IDs), and PiP/always-on-top title bars resolve non-standard and filesystem: URLs from the committed or precursor origin tuple with ELIDE_HEAD restricted to hierarchical HTTP(S), blocking origin spoofing in the window title. (0e75955) (cb1367d)
    NotificationsSecurityUI

Networking & Authentication

  • All Windows SSPI work (AcquireCredentialsHandle, InitializeSecurityContext) is serialized on a single shared sequence, still off the network thread. Overlapping calls against the same typed credentials previously failed with SEC_E_INVALID_TOKEN, breaking NTLM/Negotiate authentication. Gated by kSerializeSspiCalls in net/base/features, restoring branch-156 serialization semantics. (c4a99be)
    NetworkWindows
  • HostResolverManager no longer aborts in-flight DNS transactions when configuration arrives or refreshes, except for transactions that genuinely depended on the configuration. On Windows and macOS, where the platform resolver owns nameserver and Private DNS selection, this removes spurious early/concurrent lookup failures during network transitions. (b45ed08)
    Network
  • Device Bound Session Credentials now reject cross-site refresh session configs by default (kDeviceBoundSessionsRequireSameSiteRefresh, shipped enabled): a refresh response whose final registration URL is not same-site with the fetcher endpoint fails fatally (SessionError::kCrossSiteRefreshSessionConfig) and the existing session is deleted. Separately, CacheStorageCache truncates stale stream bytes, so an opaque response body can no longer remain readable after an empty put (both the response header and blob paths were fixed). (d296a63) (47f720b)
    NetworkSecurityStorage
