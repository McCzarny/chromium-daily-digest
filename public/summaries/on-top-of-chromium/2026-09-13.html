Chromium Digest: 2026-09-13

Overview

This digest covers 21 commits analyzing changes across desktop browser UI, extensions security, audio infrastructure, and automation for Chromium projects. From the analyzed range starting at (d52f8a4) to (c135e39), no major breaking changes to public embedder APIs were identified.

UI & Browser Views

  • Optimized startup and rendering performance in the ChroMenu desktop app menu redesign by delay-loading dynamic submenu views until needed, and polished layout alignments for custom borders, shortcut placements, and edge-to-edge menu actions. (04395db) (91b06b6)

Extensions & Security

  • Restricted Isolated Web App (IWA) deep-link navigations by disallowing isolated-app:// URLs in the chrome.history extension API, excluding them from persistence, and cancelling auto-bookmark navigation transitions. (286508d)

Media & Audio

  • Migrated AudioSystem thread-safety checks from base::ThreadChecker to base::SequenceChecker across media service implementations to align with sequence-bound asynchronous Mojo backends. (02967f9)

DevTools & Automation

  • Added support for propagating userContext across WebDriver BiDi context creation responses, navigation lifecycle events, realm descriptors, and network parameters. (4b1be76)

Storage & Infrastructure

  • Improved stability in CacheStorage backend teardown by gracefully handling closed states in CloseImpl, and cleaned up deprecated EffectiveStorageAccess metrics. (2d7d0d9) (aa0b558)
