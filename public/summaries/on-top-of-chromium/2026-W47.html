Breaking Public APIs

  • ⚠️BREAKING CHANGE PolicyMap::Entry values are now immutable ref-counted data; mutable accessors such as GetMutableValue(), GetMutableValueUnsafe(), and non-const value() were removed. Policy providers must clone, mutate, and call set_value(). The change pays for itself with about 6 MiB RAM and 136 ms warm-start / 326 ms cold-CBCM CPU saved per additional profile. (b760e58)
    PolicyBase
  • ⚠️BREAKING CHANGE Several stable content hooks changed: WebContents::StartPrerendering() now requires NavigationUIData, NavigationUIData::CloneForNewNavigation() became MaybeCreateForRedispatchedNavigation(), ShowRepostFormWarningDialog() returns bool so false cancels the reload, and ContentBrowserClient::WillInterceptWebSocket() takes an additional BrowserContext*. Update overrides and call sites. (d757f4b) (797a1d8) (0df9dbc) (9f0499b)
    NavigationBrowserNetwork
  • ⚠️BREAKING CHANGE content/public/browser gained a pure-virtual RenderProcessHost::GetStartupTimings() and removed WebUIConfigMap::GetRegisteredConfig(const GURL&) in favor of a narrower GetProcessLockHost(); ContentBrowserClient::ShouldTryToUseExistingProcessHost() was also removed. Embedders and test mocks must implement or migrate, and WebUI process reuse now follows inlined process-lock logic. (d82800b) (a9d5c36) (d4c9d38)
    BrowserUITesting
  • ⚠️BREAKING CHANGE GRIT now compresses .js, .html, .css, .svg, .json, and code-cache resources with zstd; ui::ResourceBundle::IsGzipped() and IsBrotli() were removed in favor of IsCompressed(), and extensions source maps load via LoadDataResourceString(). Custom .pak pipelines and callers of the removed APIs must migrate. (4a89327) (3f2c376)
    BaseBuildExtensions
  • ⚠️BREAKING CHANGE url::SchemeHostPort and url::Origin now reject non-file standard schemes with empty hosts, and WebSecurityPolicy::LockSchemeRegistries() permanently blocks late custom-scheme registration after RenderThreadStarted(). Embedders registering standard schemes or round-tripping such origins will get invalid values or CHECKs. (73392c2) (4e6d72e)
    NetworkSecurityBlink

Security & Privacy

  • ⚠️BREAKING CHANGE File System Access was hardened across prefs, grants, and permission requests: seven FSA prefs are now tracked in Secure Preferences and existing grants reset once on upgrade, move-overwrite and rename revalidate case variants and handle types, FileChooserImpl rejects renderer-supplied kOpenDirectory, user-edited ALLOW guards downgrade to ASK, and the entry factory gains a sensitive-entry read check. (635d0c5) (8a370d8) (36a0f18) (88ba2de) (4ba5176) (ea88bf4)
    SecurityStorageProfiles
  • Negotiate/GSSAPI now revalidates DNS canonical names against allowlists before and after the handshake, preventing ambient credentials from going to unrequested hosts. TLS client-certificate auth also rejects empty or zero-length signatures and empty algorithm preferences, evicting broken keys from cache so stale-key retry works. (461e753) (16cfb97) (2895bec)
    NetworkEnterpriseSSL
  • Dedicated workers with CSP sandbox responses that lack allow-same-origin now get opaque StorageKeys, and inherited Storage Access API status is cleared. ServiceWorker race-network-and-fetch-handler no longer redispatches post-fallback redirects as a fresh FetchEvent, closing cross-origin URL and credential exposure plus an opaque-tainting bypass. (adc26fc) (8f1eee4) (d031101)
    SecurityStorageServiceWorker
  • Clear-on-exit now deletes partitioned cookies whose top-level site is session-only. Web Serial and Web Bluetooth permissions were also tightened: serial grants are scoped to the canonical service UUID, scanning is gated by GetBluetoothAllowed(), and a failed insecure RFCOMM connect can no longer unbond paired input devices. (cfd48e2) (5c7518a) (b5d347e) (53964c8)

Networking & Enterprise

  • Proxy port restrictions and HTTP/0.9 rejection through forward proxies are now enabled by default, validating every proxy endpoint against IsPortAllowedForScheme() and rejecting statusless HTTP/0.9 or ICY responses with ERR_INVALID_HTTP_RESPONSE; normal proxy fallback remains and killswitches are available. (2e584f2)
    NetworkSecurity
  • ⚠️BREAKING CHANGE switches::kUseSystemProxyResolver was deleted; native WinHTTP/CFNetwork proxy resolution is now behind the disabled-by-default SystemProxyResolver feature, and out-of-tree resolver implementations must use ConfiguredProxyResolutionService. Secure DNS bundled-settings flag removal also pins DoH fallback off without consulting Safe Browsing. (8a813b9) (f6dabd3)
    NetworkPrivacymacOS
  • Enterprise HTTPS proxies can redirect disguised-error 407 primary navigations to the challenge's validated url= through a safe browser-initiated GET with no body, no SameSite=Strict cookies, and a one-hop cap. WebSocket close semantics were also fixed to send transport shutdown only after the closing handshake, avoiding spurious 1006 closes. (cb20f3e) (6011ccf) (bfc1d8f)
    EnterpriseNetworkSecurity
  • DNS and QUIC defaults were tuned: optimistic DNS, intermediate DNS results, and RTT-based IPv6 fallback are enabled; HostCache capacity is now scoped per NetworkAnonymizationKey to prevent cross-origin eviction; and QUIC IPv6-to-IPv4 migration plumbing landed behind a disabled feature. (827b566) (c2a5dc3) (b5a6ded)

On 210K bookmarks, AppKit traversal drops from about 62 s to 24 s and later to under 1 s, profile teardown falls from about 42 s to 20 s and later to about 1 s, and 100-item folders open in roughly 25-40 ms. Build scripts or packaging that assume the old C dialect, libc++abi target, or Node major may need updates. (7332e81) (3758a35) (b13ee12)
