Chromium Digest: 2026-11-10

Overview

Chromium main-branch activity for 2026-11-10 covered 1,337 commits, with 1,117 relevant to embedders and browser projects. First commit: (67684b5). Last commit: (22b1ae8). The day includes several hard API migrations, security hardening in navigation, file-system access, and Safe Browsing, plus measurable performance and memory fixes.

Breaking API Changes

  • ⚠️Removed content::ReduceAcceptLanguageControllerDelegate, BrowserContext::GetReduceAcceptLanguageControllerDelegate(), and components/reduce_accept_language/ outright. Embedders that override BrowserContext for this method or link the removed GN targets must migrate or drop the overrides. (f232316)
    BrowserNetwork
  • ⚠️media::VideoFrame::GetVisibleSkYUVAInfo() and GetVisiblePlanesSkPixmaps() are removed in favor of GetVisibleSkYUVAPixmaps() / GetVisibleRGBPlanePixmap(); skia::ConvertYUVAToRGBA() now takes SkYUVAPixmaps. Update pixel readback, capture, compositing, and golden-test code. (5050876)
    Media
  • ⚠️gpu::raster::RasterInterface readback now takes a single const SkPixmap& in ReadbackARGBPixelsAsync() and ReadbackImagePixels(), removing the SkImageInfo plus row-bytes/pointer signature. Out-of-tree implementers and test fakes must migrate. (56406bd)
    GPU
  • ⚠️image_fetcher::ImageData is now scoped_refptr<base::RefCountedMemory> across ImageFetcher APIs. Failed fetches return a non-null empty buffer instead of an empty string, so existing empty() checks and string-style access must be audited. (56f4230)
    NetworkUI
  • ⚠️TabStripModelObserver::OnTabPinnedStateChanged and OnTabWillBeRemoved now take only tabs::TabHandle; the index parameter is gone with no compatibility shim. Observers must re-derive indices and handle unresolved handles explicitly. (db61849) (2bdfb75)
    TabsUI

Security & Privacy

  • Tracked-pref migration is now first-run-only. Marking an existing pref as ENFORCE_ON_LOAD outside first run deletes it from the unprotected Preferences store and resets it to default; downstream projects adding protected prefs must register a new pref and copy values through PrefService. (7b397a0)
    SecurityProfiles
  • File System Access hardening: RDP/AVD client-drive UNC paths (tsclient/client servers) are now caught by sensitive-entry checks, dot components in root paths are rejected, and incognito contexts can no longer expose a synthetic platform path into the regular profile. (d036c0a) (b5376fa) (066fc3e)
    SecurityStorage
  • Safe Browsing archive analysis no longer skips regular files named *.app inside DMGs/ZIPs/RARs/7z; only actual .app directories are skipped, closing an executable-evasion gap. (1077c26)
    Security
  • SavePackage now validates that the current RenderFrameHost still matches the requesting frame before network requests or serialized-HTML generation. This prevents a cross-site iframe navigation from causing content to be saved in the new document's security context. (1ed75c0)
    SecurityNavigation
  • Cast Remoting hardens cross-origin subframe authorization: inactive and fenced frames are rejected, sink friendly_name is stripped for cross-origin subframes, and unauthorized subframe starts can no longer preempt or disconnect an active main-frame bridge. (de51e30)
    SecurityMedia

Networking & Extensions

  • DBSC correctness fixes: key-generation cancellation aborts cleanly, session-restore callbacks unblock only their own flow, and pre-provisioned keys are deleted rather than left to GC. The per-IdP pre-provisioned key cap is replaced by a per-site signing quota. (6396070) (73e32ca) (7358df3) (07f3a95)
    NetworkSecurity
  • CrxDownloader cancellation now survives fallback URLs and successor downloaders such as BITS, Delivery Optimization, and macOS BackgroundDownloader. Cancelled attempts finish as CANCELLED unless they complete and pass SHA-256 verification. (d6b6a61)
    Updater
  • Proxy Override Rules now clear extension-controlled values when the pref becomes unmodifiable, including persisted values at startup, and dispatch a consolidated chrome.preferencesPrivate onChange. (b054393)
    ExtensionsPolicy
  • On Isolated Web App update or policy install over a user install, service worker registrations are deleted when the installation signing key is revoked, preventing a revoked version from intercepting the new version's navigations. (ef73a14) (26ffad9) (f7eb1fb)
    ExtensionsSecurityServiceWorker

Browser UI & Behavior

  • macOS history swipe is rewritten on top of NSEventPhaseChanged delta accumulation instead of trackSwipeEventWithOptions:. This fixes navigation on touchscreen Macs and avoids an AppKit callback-suppression bug. (550b8a5)
    UImacOS
  • Touchpad scroll is no longer delivered twice to Views. The redundant conversion doubled deltas and could accidentally switch tabs after a small clickpad scroll. (09434e3)
    UI
  • Tab-group and horizontal tab-strip layout crash fixed by caching minimum size alongside preferred size, invalidating on non-animated focus changes, and exiting tab-closing mode on focus transitions. Overflow-indicator rendering is also unified with z-ordering and hit-test partitioning. (a43a42b) (1d0d0f2)
    TabsUI
  • Windows taskbar pin migration now preserves the Omnibox Everywhere AUMID, fixing duplicate taskbar buttons, and chrome://default-browser-modal no longer crashes renderers when queried outside the real modal surface. (5f7162f) (7fa3f20)
    WindowsBrowserUI

Performance & Memory

  • WeakPtr code-size optimization: IsValid() becomes pure in release, operator* and operator bool() are always-inline, and operator bool() avoids a redundant null check. Measured ~52 KiB reduction in 32-bit libchrome.so. (a986a21)
    BasePerformance
  • Omnibox HistoryInfoMap moves to absl::flat_hash_map with O(1) row deletion. OnHistoryDeletions(500) is 5.14× faster, and deletion of credential-bearing URLs is now correct. (9e3f816)
    HistoryPerformance
  • GpuImageDecodeCache now notifies ContextCacheController around flushes, closing a 1 MiB GPU-memory leak exposed by startup compositor prioritization. Measured gpu:effective_size improvement is −9.49%. (6307b81)
    GPUPerformance
  • Windows ParallelPreReadFileMainDllWin is promoted to Stable at 1%, improving Chrome startup by parallelizing main DLL preread. (8e4e135)
    WindowsPerformance

Developer & Build Impact

  • The libc++ roll changes std::vector element destruction from back-to-front to front-to-back via std::destroy. Embedders relying on reverse destruction order must audit; one Chromecast destructor order was fixed in-tree. (9bdf20b)
    BuildBase
  • Build migrations: third_party/jsoncpp moves source/ → src/ (update GN/DEPS/patch paths), IDS_DOM_DISTILLER_* becomes IDS_WEB_DISTILLER_*, and third_party/libunwindstack moves to libunwindstack_tmp. (e0ec226) (3d7a126) (31b2c4d)
    Build
  • CDP V8-interrupt policy is inverted to a shared allow-list. Non-allow-listed commands on worker sessions are queued to the next yield instead of interrupting V8, changing ordering and timing for embedders driving CDP. (83076a7)
