Chromium Digest: 2026-08-31

Overview

Daily development digest for Chromium covering 642 total commits, with 503 relevant changes analyzed for desktop environments (Windows and macOS). Ranging from core browser architecture modifications and security hardening to privacy improvements and UI modularization, this digest outlines the key updates for downstream developers. The tracked changes span from commit (6f12a33) to (44ebe43).

Core Infrastructure & Embedder APIs

  • ⚠️The return type of HistoryService::Init() was changed from bool to void across internal implementations, unit tests, and browser factories, modifying the component API signature. (44ebe43)
    HistoryBrowserBase
  • Added support for the --disable-best-effort-tasks switch via a centralized scoped execution fence in ContentMainRunnerImpl. (4b0f3fc)
    BaseBrowser
  • Completed the migration of MemoryCache to base::MemoryConsumer, removing redundant platform-level memory pressure listeners. (627978f)
    BasePerformance

Security, Cryptography & Networking

  • Fully deleted device/fido/cbor_extract.h and associated utility functions, migrating all call sites to standard components/cbor parsing mechanisms. (ac8e0a0)
    CryptoSecurity
  • Added support for the ML-KEM-768 key encapsulation mechanism in crypto/kem. (f6638c6)
    CryptoSecurity
  • The kRestrictForbiddenSecurityHeaders feature flag has been removed, permanently enforcing strict checks against forbidden Sec- headers received from renderers. (57d593a)
    NetworkSecurity
  • Blocked renderer-supplied wildcard Accept-Encoding values and designated compression dictionary headers as unsafe to prevent request header manipulation. (34fd888)
    NetworkSecurity

Browser UI & Modularization

  • Restored GetAIPageContent() within BrowserWebContentsDelegate, fixing a regression causing DevTools Page.getAnnotatedPageContent requests to fail. (d08a3dd)
    AIDevToolsBrowser
  • Completely removed the New Tab Page middle slot promo component, along with its backing Mojo APIs, handler logic, and browser tests. (dd7083a)
    BrowserUI
  • Added support for displaying extensions inside the tab organizer panel. (4d6cb91)
    ExtensionsTabsUI
  • Modularized multiple legacy views dialog leaf modules from //chrome/browser/ui into dedicated independent build targets under //chrome/browser/ui/views. (0cb7ed6)
    UIBuildBrowser

Privacy & Preferences

  • Updated renderer preferences utility and browser-level preference wiring to pass Universal Opt-Out settings directly to the Global Privacy Control (GPC) setting across desktop contexts. (6f12a33)
    PrivacyBrowser
