Security & Cryptography

  • Extracted ParseFileChooserResponse() in remoting/host/file_transfer/file_chooser_common_win.cc to validate serialized Mojo messages using mojo::MessageHeaderValidator before deserialization in the SYSTEM-privileged process, preventing potential out-of-bounds heap reads. (fbce880)
    SecurityWindows
  • Dropped support for RSA-4096 key generation in the crypto library to discourage legacy RSA usages and encourage modern cryptographic standards. (19c61af)
    CryptoSecurity

Browser UI & Architecture

  • Updated LensOverlayEntryPointController and LensOverlayController on macOS to check IsWindowFullscreenForTabOrPending(), disabling entry points and dismissing active overlays during tab/content fullscreen transitions. (45fba15)
    BrowserUImacOS
  • Continued the Project Bedrock architecture refactoring by converting legacy Browser* references to BrowserWindowInterface across multiple subsystems including preloading, safe browsing, extensions, and web apps. (87cc931) (96dd00f) (29bc2e9)
    BrowserUI

Performance & Base Libraries

  • Switched the PartitionAlloc AllocToken ABI from a Fast ABI to a non-Fast ABI to prevent severe binary size expansion when scaling up AllocTokens for smart sampling (GWP-ASan) and memory zapping. (4cbbbd0)
    BasePerformance
  • Refactored FieldTrial::AppendGroup and FieldTrial::SetGroupChoice to take std::string_view instead of const std::string& to eliminate unnecessary heap allocations. (910cc71)
