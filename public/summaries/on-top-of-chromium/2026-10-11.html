Chromium Digest: 2026-10-11

Overview

This digest covers 22 commits on the Chromium main branch (ranging from #(1716398) to #(1716523), first commit (f41c59f), last commit (894a6b8) by position). No MAJOR breaking changes to stable public APIs were confirmed. Notable work includes an internal refactor of the Extensions windows API, a multi-part cleanup of redundant build dependencies, a blob storage paging fix, and a ShadowRealm crash fix relevant to embedders like Electron.

Extensions

  • Split chrome.windows extension functions out of tabs_api.{h,cc} into new windows_api.{h,cc} files. This is a mechanical, behavior-preserving internal refactor — the extension-facing chrome.windows API surface is unchanged; only internal C++ file organization moved. (3939f2e)
    ExtensionsBrowser

Build / Infrastructure

  • Multi-part cleanup removing redundant browser_public_dependencies from leaf targets in //chrome/browser, //chrome/browser/ui, and //chrome/test, now that //chrome/browser:browser has no sources or circular includes and //chrome/browser/ui:ui has been removed. Internal build-graph simplification; no public API impact. (d85d15e) (a819749) (91c274f) (95f693b) (bc7362f)
    BuildBrowser
  • License tooling cleanup: removed obsolete/stale SPECIAL_CASES entries from tools/licenses/licenses.py (native_client, ppapi, v8-i18n, openscreen, angle, etc.). (f41c59f)
    InfraBuild

    MediaBuild

Storage / Performance

  • Fixed blob storage paging behavior: MaybeScheduleEvictionUntilSystemHealthy() previously paged every populated item to disk whenever paging triggered, because total_memory_usage was computed once outside the loop. Now bytes being paged are counted as evicted so paging stops once expected usage is at/below the limit, resulting in smaller, more frequent paging batches. A behavioral fix to internal storage logic, not a public API change. (2f0832d)
    StoragePerformance

Bug Fixes (Embedder-Relevant)

  • Fixed a ShadowRealm full-GC crash: Blink's GC metrics recorder hit NOTREACHED() when attributing metrics to a ShadowRealm context (resolving it to ShadowRealmGlobalScope and calling UkmRecorder()). Now returns no UKM recorder / invalid source ID for ShadowRealms. Notably referenced from an Electron issue, so this fix is relevant to embedders. (8aa7b26)
    BlinkBrowser
  • Restored mouse cursor visibility for native dialogs on Windows: native dialogs could inherit a hidden cursor when typing-hides-cursor was active, because ::ShowCursor(FALSE) in DesktopWindowTreeHostWin decremented the thread-global cursor counter and mouse events over native dialogs bypassed Chrome's event filter. Fixed by stopping legacy ::ShowCursor() calls and restoring cursor visibility in HandleCancelMode(), guarded behind features::kHideCursorWhileTyping. (a2be9ee)
    UIWindows
  • WebVTT cue layout fix: non-snap-to-lines cues with percentage line values could render below the video area after an earlier spec-conformance change removed a translate transform. Implemented the closest-position adjustment along the line axis so partially/fully clipped cue boxes stay within the rendering area. (58ed0c7)
    BlinkHTML
  • Network metrics cleanup: removed four expired ReportingAndNEL.NumberOfLoaded* histograms and their recording helpers from SQLitePersistentReportingAndNelStore. Dead code removal; no functional change to NEL/Reporting behavior. (1fb712e)
    NetworkStorage

UI / UX

  • NTP theme sync fix: normalized NTP background URL image options across platforms in theme_translation.cc so cross-platform theme equality checks, history deduplication, and Backdrop URL validation work between Desktop and Mobile. Also moved image URL option helpers into a new //components/themes/common target. (d02281c)
    ThemesSyncUI
  • Drive integration consent dialog adapted for larger screens (floating card on tablets, web contents inset, background tint, loading overlay on dismiss). Android-specific. (a3ddc14)
    UIAndroid
  • iOS Gemini infobar banner: capped dynamic font size for the CTA button and preserved multi-line/scale-to-fit settings. iOS-specific. (894a6b8)
    UIiOS
