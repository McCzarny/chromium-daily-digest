Chromium Digest: 2026-10-23

Overview

On 2026-10-23, Chromium's main branch received 1,046 commits, of which 834 were relevant to this digest after filtering out ChromeOS/Ash, iOS, Android-only, and Blink/V8 rendering internals. The day was headlined by three breaking public-API changes (viz overlay metadata removal, ui::TreeModel/TreeNodeModel restructuring, and a WebTransport send-stats mojom redesign), alongside a substantial batch of security hardening in File System Access, touch drag handling, and extension capture, plus measurable performance work in base::FeatureList, the omnibox, and macOS display handling. First commit: (b338778); last commit: (fc9710f).

Breaking Public API Changes

  • ⚠️BREAKING: Removes TransferableResource::MetadataOverride::is_overlay_candidate from the exported viz struct (components/viz/common/resources/transferable_resource.h) and the matching field from transferable_resource.mojom, including its StructTraits accessor and deserialization. GetIsOverlayCandidate() now derives only from SHARED_IMAGE_USAGE_SCANOUT on the backing SharedImage. Embedders constructing the mojom struct or setting the hint will fail to compile or silently lose overlay hints. (32b45ee)
    CompositorGPU
  • ⚠️BREAKING: Deletes ui::TreeNodeModel<T> and detaches standalone ui::TreeNode<T> from ui::TreeModelNode; TreeModel::GetRoot/GetChildren/GetIndexOf/GetParent and TreeModelNode title/accessibility accessors become non-virtual; the protected TreeModel() constructor is removed so models require an explicit unique_ptr<TreeModelNode> root. Any embedder subclass deriving from TreeNodeModel or overriding these accessors breaks (or silently stops being called). (3be49d7)
    UIBrowser
  • ⚠️BREAKING: WebTransport::GetSendStreamStats(uint32) is replaced by a batched GetSendStreamStats(array<uint32>) => (array<WebTransportSendStreamStats?>), WebTransportClient gains a required OnOutgoingStreamStatsFinalized(...), and WebTransport::UnregisterSendStream() is removed. Send-group getStats() now reports real aggregated counters instead of zeroes; custom network-service or WebTransport client implementations must be updated. (4cc5073)
    Network

Security & Privacy

  • File System Access handle serialization now takes the caller's blink::StorageKey, records the owning origin in LocalFileData, and verifies it on deserialize, plus transfer-token validation during serialize. Closes a cross-origin token escalation where a compromised renderer could persist a foreign token into its own IndexedDB bucket. (71ea1e9)
    StorageSecurity
  • File System Access now rejects Windows hypervisor UNC share roots, sensitive host directories, and shell startup dotfiles, hardening the picker against dangerous file grants. No API change, but embedders relying on broad path access will observe new denials. (bc29f45)
    StorageSecurityWindows
  • Relands touch-drag hardening: adds additive aura::Env::ConsumeTouchForDrag(window) with per-window ActiveTouch tracking so renderer-initiated drags must correspond to a touch pressed on the WebContents itself, and each press can start at most one drag. Fixes synthetic-drag spoofing from other windows; content that latched drags onto unrelated touches will now be rejected. (0552262)
    UISecurity
  • Credential UI now sanitizes site-supplied usernames and display names via GetSingleLineDisplayText(), collapsing control characters, newlines, whitespace runs, and unterminated bidi controls in the account chooser, federated save bubble, and auto sign-in bubble — closing a UI-spoofing vector. (71b45ec)
    PasswordManagerSecurity
  • Extensions tab-capture tightening: tabCapture.getMediaStreamId() now passes include_incognito_information() when resolving tabs (fixing an incognito-access leak), and TabCaptureRegistry::CanCaptureWebContents() rejects chrome:// pages on navigation, so an active capture session stops when the captured tab navigates to a chrome:// URL (component/command-line allowlisted extensions exempt). (851a6a2) (2665b0b)
    ExtensionsSecurity
  • base::Pickle invariants are promoted from DCHECK to CHECK: writing to a WithUnownedBuffer() pickle, out-of-range header_size, and Reserve()/claim exceeding 4 GB now fail in release builds instead of corrupting memory. Correct callers are unaffected; misuse now crashes deterministically. (439c14a)
    Base

Networking, Enterprise & Policy

  • network::mojom::NetworkContext gains two new pure-virtual methods: GetProxySettings() (surfaced in chrome://net-internals with original/effective proxy config and the cached bad-proxy list) and Clone(PendingReceiver<NetworkContext>) (cloned receivers live in a separate ReceiverSet, enabling off-UI-thread preconnect/QUIC via CrossThreadNetworkContext). Additive to the protocol, but embedders implementing NetworkContext (test doubles, custom network services) must add overrides. (bd7264f) (e6a8723)
    Network
  • Adds default-implemented ContentBrowserClient::GetInitialInsecureDnsMode() (returns kDisabled) plus NetworkServiceParams::initial_insecure_dns_mode so the stub host resolver is created with the right mode at service init; WebView opts in. Existing embedders continue to compile unchanged. (3de3a50)
    Network
  • WebAppUrlLoader now requires kUrlLoaded to be a committed cross-document navigation whose committed URL still matches, plus a same-origin check on manifest_id in ExternalAppResolutionCommand — fixing a shared-background-WebContents origin-confusion issue. Note the error-classification shift: non-committing responses (204/205/downloads) now report kFailedUnknownReason/kInstallURLLoadFailed rather than timeout errors, so callers matching on those codes should update. (6c67a1f)
    NavigationSecurity
  • Enterprise/SSL updates: managed client certificates can use the sanitized device hostname as Subject CN (common_name_source, behind kClientCertCommonNameAttribute) with renewal triggering, and Secure Gateway defaults flip kEnableDynamicRouteFetching/kEnterpriseProxyErrorHandling on while remaining kill switches. A new ENTERPRISE_PROXY PolicyLogger source adds enterprise proxy diagnostics. (b916210) (f93347c) (44ea4b6)
    EnterpriseSSLPolicy
  • HTTP cache now fails 206 responses whose body length does not match their own Content-Range (leniency removal for malformed servers), and MHTML classification is made case-insensitive per RFC 2045 for NavigationRequest::IsMhtmlMimeType()/download_utils::MustDownload(), so Multipart/Related/Message/RFC822 variants no longer fall through to download or render paths. (baeba81) (e8322aa)
    NetworkNavigation

Browser UI, WebUI & DevTools

  • The WebUI omnibox popup now hides with the location bar in fullscreen (LocationBarView::VisibilityChanged() closes it and moves focus to the page), with a new virtual OmniboxPopupView::ReshowPopup() to reopen a surviving draft on exit and OmniboxEditModel::HasDraft() to end unfocused drafts on navigation. Excludes macOS/ChromeOS immersive and the WebUI toolbar variant. (d6c5238)
    BrowserUI
  • macOS: WebContentsOcclusionCheckerMac + NativeWidgetMacNSWindowHost now hide the Views compositor when a window is occluded so Viz releases buffers (new ui::views feature), and ExternalBeginFrameSourceMac avoids the slow CGDisplayModeGetRefreshRate() path when CADisplayLink is active. Occluded windows/surfaces should show lower memory and GPU usage. (d694c16) (94e30b1)
    macOSCompositor
  • Windows: SetWindowDisplayAffinity() is only called when the affinity actually changes and is skipped for hidden owned windows, fixing DWM blank/white-box artifacts caused by third-party overlays on captured or overlaid windows. (ccdfaa6)

(ee558d4) (b647abf) (17a8be6)

Front-end only, but embedder WebUI extending these controls or relying on Polymer internals (this.$.id, notify: true) needs updating. Performance & Memory

  • base::FeatureList now caches the resolved enabled state instead of the raw OverrideState (new kCachedResolvedEnabledMask/kCachedExplicitOverrideMask bits, fallback resolution moved into a NOINLINE FeatureList::ResolveFeatureEnabledState()), taking lookups from ~10.92 ns to ~4.10 ns. Public IsEnabled()/GetOverrideState() semantics are unchanged; only base::internal bit masks changed, so code poking cached_value directly must be updated. (df3a810)
    BasePerformance
  • AutocompleteResult no longer pre-reserves ~30 AutocompleteMatch slots, saving roughly 50 kB per instance and ~250 kB per desktop window (two controllers × two results plus the SearchboxHandler snapshot) with no intended behavior change. (14a0a49)
    BrowserPerformance
  • macOS display-link robustness: kUseDisplayRefreshRateForTimer is default-on so the BeginFrameSource timer matches the display's actual refresh rate when DisplayLinkMac creation fails, and CADisplayLink failures fall back to CVDisplayLink instead of a 60 Hz timer. Frame cadence may differ on machines with flaky display-link support. (c254fd1) (de1036a)
    macOSCompositorPerformance
  • Windows Media Foundation playback sets MF_MEDIA_ENGINE_AUDIOONLY and skips DirectComposition setup when the resource has audio but no video (low-latency mode preserved), removing unnecessary GPU/video work for audio-only media. (05ee29c)
    MediaWindows
