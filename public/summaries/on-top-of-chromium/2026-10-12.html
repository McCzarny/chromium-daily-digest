Chromium Digest: 2026-10-12

Overview

Out of 669 commits on 2026-10-12 (main branch), 492 were relevant to Chromium-based projects. The day was dominated by AI/Actor/Glic feature work, security hardening, and large-scale build/test cleanup. Two confirmed breaking changes require embedder action: removal of the default scope argument from ActionManager::FindAction() ((89aa9ea)) and the ContentBrowserClient child-module API change ((b73ceff)). First commit: (e3c2b8b), last commit: (7a83bdf).

Breaking Changes

  • ⚠️ActionManager::FindAction() loses its default scope argument. All callers must now explicitly pass a scope (root_action_item() or nullptr) or compilation fails. Motivated by bugs from clients passing incorrect scopes; ~24 files across chrome/browser were updated. (89aa9ea)
    UIBrowser
  • ⚠️ContentBrowserClient child-module API changed. GetChildModuleVersion() is replaced by GetChildModule() returning a new ChildModule struct (version + path), and PreSpawnChild() now takes base::optional_ref<const ChildModule>. ChildModuleManager consolidated to GetLatestModule(). Windows embedders overriding these sandbox/dynamic-patching hooks must update their implementations. (b73ceff)
    WindowsSecurityBrowser
