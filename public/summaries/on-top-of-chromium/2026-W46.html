Overview

Chromium development for Week 46 of 2026 featured 6,940 total commits across six days, with 5,160 changes relevant to Windows and macOS browser embedders. Security & Privacy

  • ⚠️BREAKING CHANGE Cast Remoting permission checks moved entirely to the browser process. Remoter::StartWithPermissionAlreadyGranted() was deleted from remoting.mojom. (a9c8e34) (a7f76d8)
    SecurityMedia
  • DevToolsActivePort is now written atomically via ImportantFileWriter with permissions tightened from 0644 to 0600 to prevent symlink-planting attacks in user data directories. (033c1b9)

  • Fixed a Connection-Allowlist bypass where ClearNetworkRestrictions cleared the ID while cloned CorsURLLoaderFactory instances were still active. (07baaf8)
