Overview

Out of 852 total commits on the main branch, 664 were relevant to this digest (first commit: (20d60c9), last commit: (71c913d)). The day was dominated by internal refactoring (Bedrock test migration, ChildProcessId migration, FindBarController UnownedUserData migration), security hardening (ML-DSA CUP signatures, Secure Gateway OAuth domain validation, DevTools delegate allowlist enforcement, Windows handle-duplication fix), and feature work around Glic/Contextual Tasks, the WebUI app menu, PDF Ink, and vertical tabs. Two confirmed breaking changes affect embedders: the update_client CrxDownloader API signature change and the removal of public FindBarController accessors from BrowserWindowFeatures.

Breaking Changes

  • ⚠️CrxDownloader API signature change: CrxDownloader::StartDownload() / StartDownloadFromUrl() now require a ProgressCallback parameter, and set_progress_callback() was removed entirely. Embedders and downstream update-client consumers must pass a progress callback (or base::DoNothing()) and can no longer set it out-of-band. This also fixes fallback downloaders not receiving progress updates. (65a5621)
