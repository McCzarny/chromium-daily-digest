Chromium Digest: 2026-11-14

Overview

On 2026-11-14, Chromium development saw 322 total commits, of which 167 were relevant to Windows and macOS browser-level changes, ranging from network telemetry and enterprise isolation to base library optimizations and UI improvements. The changes span from commit (1eda7d4) to (38ccb8a).

Networking & Security

  • HttpNetworkTransaction now records proxy information and connection attempt records when stream setup completes via OnCertificateError or OnNeedsClientAuth, ensuring proper proxy attribution. (19b9c56)
  • Requests associated with pooled QUIC sessions receiving an HTTP/3 GOAWAY frame now surface an explicit retry code to enable automatic fallback on a new connection. (873a1c2)
  • Scoped Device Bound Session Credentials (DBSC) delete-on-exit cleanups now match strictly against session-only cookie origins instead of wiping all sessions across a profile. (c89b831)
  • Enterprise DLP clipboard copies are now tagged with their originating profile to prevent data leaks when the policy is applied at the profile level. (9de620b)
  • Implemented CRLSet binary search optimizations and modernized Merkle Tree Certificate path verification to use standard parsed X.509 CA certificates. (83b96e7) (dd76f4b)
  • Introduced NetworkNameCache to query Wi-Fi SSIDs off the UI thread asynchronously to avoid blocking device policy reporting on Windows. (86f91bf)

Browser UI & Desktop Experience

  • Omnibox popup views on macOS now observe visibility changes to re-synchronize bounds and re-request focus after native Space transitions. (58ce498)
  • Migrated Contextual Tasks ephemeral buttons out of standalone custom management and unified them into the PinnedToolbarActionsContainer framework. (1b1ff2a) (02c5baf) (a70a89d)
  • Refactored omnibox rich image updates to update row-scoped suggestion cells synchronously from the bitmap cache, avoiding full popup re-layouts. (31fd027)
  • Disallowed external drag operations on macOS for empty DropData payloads to prevent inadvertently dropping profile cards onto the Dock Trash. (9f08078)
  • Reverted Tab Search metrics migration back to chrome.metricsPrivate to prevent renderer histogram filtering rules from dropping top-chrome WebUI samples. (53a8d7d)

Base Libraries & Core Infrastructure

  • Enhanced FieldTrialAllocator with a leading atomic generation ID sequence number to let child processes detect stale variations state without breaking PMA disk compatibility. (f4cf0d5) (cb591fa)
  • Added webui_module_path equal to REPO_PATHS support to the Mojo TypeScript binding generator to produce cleaner repo-relative import statements. (08ad851)
  • Replaced runtime-initialized flat_map collections for command-to-action lookups with static constexpr fixed_flat_map tables to eliminate startup overhead. (8047795)
  • Modernized EventListenerMap lookups to return a base::span instead of a const ListenerList reference, reducing unnecessary empty list heap allocations. (581f233)
  • Implemented setting, clearing, and string formatting support for crash keys within the window.rust crash components with thread-safety wrappers. (cb809cf) (56ae826)

Media, Graphics & XR

  • Deferred WebGPU wire client disconnect logic onto a fresh task stack to prevent use-after-free crashes during context loss callbacks. (8f02a7f)
  • Added WebXR support for querying and controlling display refresh rates using the XR_FB_display_refresh_rate OpenXR extension. (172b31e)
  • Redesigned MediaRemoter to decouple remote playback control from tab mirroring, adding robust handling for in-flight cancelled offers. (9bfadb0) (d5b009a) (9d80e28)
