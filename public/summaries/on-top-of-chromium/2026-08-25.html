A review of 962 total commits on the main branch for August 25, 2026, with 792 relevant commits focusing on Windows and macOS desktop embedders, browser UI, networking, security, and APIs. Spanning from commit (2d8238f) to (fea03ff).

Developer Tools & Public APIs

  • ⚠️The virtual method MayAccessAllCookies() has been permanently removed from DevToolsAgentHostClient, a stable public interface implemented by embedders and protocol clients, requiring cookie-clearing protocols to use CookieManager directly. (0a6bbbc)
  • Privileged operations in DevTools—including file system interactions, port forwarding, device updates, and browser restarts—are now restricted exclusively to local frontends. (a39fcdb)

Networking, Security & Protocols

  • Fixed a re-entrant memory corruption vulnerability in ConfiguredProxyResolutionRequest::QueryComplete when PAC script execution terminates unexpectedly. (78fb4f5)
  • Fixed WebSocket stream teardown over HTTP/2 by properly sending zero-length data frames carrying END_STREAM to close the local half of the stream rather than dropping it silently. (95ab9f9)
  • Plumbed the is_stale parameter through EndpointConnector and QuicSessionAttempt to enforce mandatory socket confirmation, preventing the insecure use of 0-RTT on stale endpoints. (0f764fc)

Browser UI & Architecture

  • Continued refactoring patterns to decouple single-feature managers like OverscrollPrefManager and GlicIphController from the monolithic BrowserWindowFeatures class to the UnownedUserData framework. (456a4b8) (bfda3d9)
  • Integrated credential compromise warning banners into the password detail card UI, powered by design tokens and gated behind a feature flag. (47b95c2)

Core Infrastructure & Performance

  • Refactored ContentSettingsRegistry::Register() to take lightweight parameters using std::string_view and spans rather than constructing heavy std::vector and std::set objects inline. (9f14b56)
  • Optimized AlignedAlloc inside PartitionAlloc to round up allocations to alignment size after accounting for inline metadata, preventing massive memory waste on power-of-two sized requests. (d44365c)
