Summary of 1032 commits processed on the main branch for October 22, 2026, with 833 relevant changes targeting Windows and macOS embedders. Spanning from (b7b54b5) to (a550a6f).

Core Embedder & Architecture

  • ⚠️content::DocumentService now inherits from base::SelfDeleting, eliminating direct manual delete this patterns and requiring a base::SelfDeletingPassKey in constructors with MakeSelfDeleting instantiation. (1740410)
  • Removed legacy max mapping size, message number, and shared memory size limits from mojo::core::Configuration as modern mojo-ipcz no longer enforces these limits. (b986854)
  • Added Rust bindings for url::Origin (scheme and serialize methods) and GURL, facilitating safe migration of core child process security checks. (332f889) (54bdb3f) (50c0c95)

Security & Data Protection

  • Clipboard operations now enforce strict origin-cleanliness checks before exporting bitmaps or data URLs, disabling copy commands on tainted cross-origin canvases. (6778fee) (dedf2af)
  • Added explicit browser process validation to DOMStorageContextWrapper namespace and storage area bindings, dropping invalid messages from compromised renderers. (02dc3d4)
  • Expanded File System Access API blocklists to prevent write access to sensitive system paths like .git configurations and shell startup files. (d6f2c70)
  • Hardened CRX extension unpacking with UnzipFilesystemImpl, restricting file opens to create-only mode and purging existing targets before writing manifests or hashes. (7a0c3ee)

Browser UI & Desktop Experience

  • Restricted Most Recently Used (MRU) tab switching via Ctrl+Tab strictly to the currently focused browser window's TabStripModel, eliminating cross-monitor focus jumps. (6d33681)
  • Enabled LensSidePanelUnification and ContextualTasksSidePanel by default across desktop platforms to streamline side panel task coordination. (4061337)
  • Introduced dedicated devtools://devtools-remote host for remote DevTools frontends to isolate origin-scoped storage from bundled application files. (9012c26)

Networking & Media

  • Added a memory-safe Rust implementation of HttpChunkedDecoder under net/http/ behind the kRustHttpChunkedDecoder feature flag. (ac8c74c)
  • Integrated MediaFoundation video capture on Windows to stream frames through shared-image pools instead of raw DXGI GpuMemoryBuffer handles. (3e5db22) (9ab4a36)
  • Enforced requirement that web-facing Dawn OpenGL backends must use Chrome's ANGLE pipeline to guarantee driver workarounds. (a3e21e5)

Performance & Base Utilities

  • Migrated mojo::InterfaceEndpointClient internal lookup maps from std::map to absl::flat_hash_map to reduce query overhead. (6c1a689)
  • Gated base::Lock and thread checking ownership tracking on EXPENSIVE_DCHECKS_ARE_ON, improving CPU performance in standard test builds. (5683154)
  • Cached gpu::CollectDawnInfo() results per GPU process lifetime to eliminate multi-second hangs when repeatedly loading chrome://gpu. (2ffdf56)
