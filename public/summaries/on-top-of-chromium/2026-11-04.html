Chromium main contained 1,253 commits, of which 985 were filtered as relevant to Chromium-based projects. The reviewed range runs from (41ec4b3) to (336c0a2).

Breaking APIs and Compatibility

  • ⚠️TabStripModel context-menu APIs now require tabs::TabHandle for group, window, split, and tab-update operations instead of integer tab indices. Downstream embedders using the index-based APIs must migrate to handles. (4123a75)
    TabsBrowser
  • ⚠️The public TabFeatures::page_action_controller() accessor was removed. Callers must use page_actions::PageActionController::From(tab) instead. (f887a8f)
    TabsBrowser
  • ⚠️The macOS PWA policy AdHocCodeSigningForPWAsEnabled and its kUseAdHocSigningForWebAppShims feature flag were removed. Administrators relying on the policy must remove it; ad-hoc signing is now unconditional. (6a2cf36)
    PolicymacOSBrowser
  • ⚠️Legacy memory-pressure listener registration APIs were deleted from base and Blink platform headers. Embedders must migrate to base::MemoryConsumer and base::MemoryConsumerRegistration. (34431f8)
    BaseMemoryBlink
  • ⚠️ExplodedPageState serialization is now move-oriented: copying is disabled, ExplodedFrameState::assign() was removed, and serialization helpers now consume and return StructPtr values. Embedders using the old copy or out-parameter contracts need source updates. (e279c7a)
    NavigationBlink
  • ⚠️TrustedVaultClient gained pure virtual CanEnroll() and Enroll() methods. Downstream implementations of this public abstract interface must implement the new operations. (6533c45)
    SyncSecurity
  • ⚠️Temporary blink::mojom::Manifest overloads were removed from web-app installation helpers. Code still using those overloads must migrate to blink::Manifest and Manifest::Builder types. (903519b)
    BrowserBuild

Security, Privacy, and Networking

  • Web Share file staging now removes existing path entries and creates files with FLAG_NO_FOLLOW, returning PERMISSION_DENIED on failure. This prevents symlink or hardlink targets from being truncated. (e48e0a7)
    SecurityBrowserStorage
  • Windows named Mojo IPC servers now claim the first pipe instance, verify ownership, and re-arm the next instance before releasing connections, mitigating pipe-name and DACL squatting. (2a1d1a6)
    WindowsSecurityNetwork
  • HLS data-source loading rejects HTTP-to-data: redirects, and component policy validation now requires HTTP or HTTPS schemes before applying origin checks. These changes close redirect and inner-origin policy bypasses. (a526db9) (8e254c6)
    NetworkSecurityMedia
  • Password favicon fetching can opt into blocking local and private-network addresses, including after redirects, preventing password UI requests from reaching internal hosts. (144394a)
    SecurityPasswordManagerNetwork
  • File System Access now blocks hidden files and directories directly under the user's home directory and their descendants. This default-enabled protection changes which user-selected paths web content can access. (7cdaeee)
    SecurityPrivacyStorage

Extensions, Web Apps, and Browser Behavior

  • ⚠️chrome.management.setEnabled now rejects attempts to re-enable Safe Browsing/Omaha-greylisted extensions unless the request comes from the extensions WebUI. Extensions must handle the new kCannotReEnableGreylistedError result. (017112d) (154b991)
    ExtensionsSecurityPolicy
  • chrome.tabs.move, chrome.tabs.group, and chrome.windows.create({tabId}) now reject Document Picture-in-Picture child tabs with kNotAllowedForPictureInPictureError, aligning them with existing duplicate and reload restrictions. (8cf09e8)
    ExtensionsTabsBrowser
  • Force-installed extensions that are permitted in Incognito remain enabled when Enterprise Isolated Mode replaces Incognito. User preference changes can no longer disable the policy-mandated state. (458e818)
    ExtensionsEnterprisePolicy
  • chrome.webRequest.onErrorOccurred now reports details.ip when a request reached a remote endpoint but failed before response headers. This is additive for extension observers. (c0f3b8c)
    ExtensionsNetwork
  • Document Picture-in-Picture entry points now reject recursive child activation and guard WebContents lifetime across window closure, reducing UAF and invalid nested-PiP paths. (b107527)
    BrowserSecurityMedia

Browser UI and User Experience

  • The full WebUI omnibox popup is now clipped against the organizer tray and vertical tab strip, with occlusion updates on desktop platforms; clicks inside occluding views are ignored. (e4a66d1)
    UITabsBrowser
  • WebUI omnibox drag-and-drop handling was corrected: self-drops no longer trigger searches, dropped text places the caret correctly, and toolbar drag state is cleared reliably. (691e4d6)
    UIBrowser
  • The macOS system-menu integration for Tab Groups was removed, including its context enum value and associated histogram. Embedders mirroring that menu integration or switching on the enum must remove the obsolete path. (f92ce56)
    macOSTabsUI
  • Organizer panel WebUI is now preloaded through WebUIContentsPreloadManager, improving panel-open latency while avoiding preload conflicts when the extensions panel is nested inside it. (f375c3f)
    UIPerformanceBrowser

Performance, Media, and Developer Tools

  • DevTools Page.startScreenRecording now waits until capture is usable, reports capture errors, and supports browser-window capture with validation for dimensions and frame rate. Automation clients should account for delayed completion and stricter invalid-parameter handling. (fb87847) (fd2358d)
    DevToolsMediaBrowser
  • WebSocket encoding now writes directly into the output string instead of using a temporary byte vector and copy, reducing CPU time and allocations for large DevTools and WebSocket traffic. (d9b658a)
    NetworkPerformanceDevTools
  • Common base string and command-line helpers now reserve capacity and use more efficient concatenation paths, reducing reallocations for large paths, escaped strings, and hexadecimal conversions. (07832a0)
    BasePerformance
  • Windows and macOS system proxy resolvers now shut down gracefully: pending native lookups are cancelled without callbacks, and new requests return ERR_CONTEXT_SHUT_DOWN after shutdown. (67d3e21)
    NetworkWindowsmacOS
