Chromium Digest: 2026-08-28

Overview

This report synthesizes 730 total commits down to 571 relevant changes for desktop embedders targeting Windows and macOS on the Chromium main branch (spanning from (70c0eb0) to (169db56)). The focus areas include security hardening, browser UI refinements, networking improvements, extension infrastructure optimizations, and desktop performance enhancements.

Security & Memory Safety

  • PartitionAlloc was updated to inspect the BackUpRef (BRP) reference count before reusing slots on smaller-size realloc operations, closing potential use-after-free vectors. (e5b9eae)
  • Converted PasswordForm password fields from std::u16string to password_manager::PasswordString, wrapping process-bound strings to obfuscate credentials resident in memory. (20d9b0e)
  • Added explicit checks for RenderFrameHost::IsActive() prior to consuming user activations and displaying WebUSB, WebHID, and WebSerial chooser dialogs. (070879a)

Browser UI, Views, & Desktop Integration

  • Continued the architecture 'Bedrock' initiative by extracting leaf UI modules, dialog handlers, and window delegate classes out of the monolithic chrome/browser/ui target. (f2b1568) (d512b58)
  • Standardized Realbox AI mode compose button animations to use compositor transitions instead of layout morphing and fixed an unrelated Windows widget deactivation bug. (b564ad7)
  • Added support for a double-Ctrl or double-Command keyboard shortcut trigger to invoke Autofill AtMemory features and configured Prompt API layers to validate tool-call inputs. (cec9bd1)

Networking & Protocol Stack

  • Blocked renderers from providing dcb or dcz values within Accept-Encoding request headers, ensuring that dictionary compression is handled entirely within the network service. (4568e18)
  • Updated QuicSessionPool AsyncDnsJob methods to take EndpointConnector parameters by reference rather than pointers, conforming to modern Chromium C++ guidelines. (e6fc0a4)

Extension Framework Architecture

  • Refactored extension feature code generation to emit static constexpr descriptors, allowing SimpleFeature and ComplexFeature to avoid duplicating configuration parameters. (99e60f5)
  • Migrated conditional guards for Isolated Web Apps within ChromeContentBrowserClient and tab helpers to use ENABLE_EXTENSIONS_CORE && !IS_ANDROID. (df36708)
