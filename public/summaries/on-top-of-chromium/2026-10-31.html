Chromium Digest: 2026-10-31

Overview

This release includes 77 analyzed commits spanning networking hardening, browser UI updates, memory and allocator throughput gains, and Windows/macOS graphics optimizations. Key changes include Alt-Svc certificate validation enforcement on bidirectional streams, dynamic WebContents migration for the WebUI Omnibox across windows, PartitionAlloc dequarantine speedups on Windows, and direct D3D11 graphics context collection on Windows ANGLE setups. First analyzed commit: (18d8327), last analyzed commit: (1577b99).

Network & Security

  • Ignored and suppressed Alt-Svc headers on BidirectionalStream connections with invalid or untrusted TLS certificates, matching HttpNetworkTransaction behavior to prevent persistent redirection to attacker-controlled alt-service endpoints. (a30a0f0)
    NetworkSecuritySSL
  • Preserved cached QUIC ServerNetworkStats (SRTT and bandwidth estimates) when connection attempts are cancelled locally due to connection races (such as in AsyncDnsJob), avoiding costly 300ms default initial RTT fallbacks. (b87b938)
    NetworkPerformance
  • Restricted SHARED_IMAGE_USAGE_MIPMAP to GPU service-only operations (used by Viz's SkiaRenderer), enforcing IPC rejection in SharedImageStub for client requests attempting to bind mipmap usage directly. (5c04ddb)
    GPUSecurity
  • Consolidated Safe Browsing browser-side visual classification architecture into ClientSideDetectionHostBase to provide uniform screenshot capture and feature extraction pipelines across platforms. (18d8327)
    SecurityBrowser

Browser UI & Navigation

Performance, Memory & Base

  • Optimized PartitionAlloc's SchedulerLoopQuarantine on Windows x86_64 by omitting redundant 64-byte poisoning passes during slot dequarantine when blocks were already zapped upon entry, reducing benchmark allocation times by 4% to 8%. (296a15b)
    BasePerformance
  • Updated MemoryPressureListenerPolicy to avoid ordering consumers that release memory via disk writes (such as BlobMemoryController) to purge data under critical system memory pressure, preventing heavy disk swap thrashing. (a17c586)
    BaseStoragePerformance
  • Removed the experimental SIMDUTF implementation of base::Base64Encode() to align base encoding utilities with strict memory-safety rules. (e004a2a)
    BaseSecurity

Graphics, GPU & Media

    GPUCompositor
