Chromium Digest: 2026-11-16

Overview

On 2026-11-16 the main branch received 1067 commits, of which 855 were relevant to Chromium embedders. The day's dominant theme is public-API churn: PolicyMap values became immutable, RenderProcessHost gained a pure-virtual startup-timings API, WebUIConfigMap::GetRegisteredConfig() was removed, and several smaller stable signatures changed. Alongside that, there are meaningful security hardening changes to File System Access, FedCM and extension MojoJS scoping, plus measurable performance wins in ui/views hit-testing and SimpleCache mass-doom handling. Range: (0f21023) → (a6cafef).

Security & Privacy

  • Seven File System Access prefs (extended-permission exceptions and defaults, chooser data, read/write guards) are registered in kTrackedPrefs with ENFORCE_ON_LOAD + TRACKING_STRATEGY_ATOMIC, so hand-editing Preferences in plain text can no longer grant persistent FSA permission. Because existing values are not migrated into Secure Preferences, all existing FSA grants, guard exceptions and defaults are reset once on upgrade on Windows/macOS and users are re-prompted; this is intentional since forged and legitimate values are indistinguishable. (635d0c5)
    SecurityStorageProfiles
  • File System Access grant handling hardened three ways: move-overwrite on case-insensitive filesystems now invalidates case-variant destination grants in both active and persisted permission maps (previously a case-alias handle retained read access), move()/rename() re-validate that the on-disk entry still matches the handle type under the exclusive move locks (closing a file/directory type-confusion hole), and FileChooserImpl now rejects kOpenDirectory from the renderer rather than hitting NOTREACHED() — a deterministic browser-process crash for a compromised renderer. (8a370d8) (36a0f18) (88ba2de)
    SecurityWindowsStorage
  • FedCM popups and links now use an opaque initiator_origin on desktop (behind the default-enabled kFedCmOpaqueInitiatorOrigin kill switch), matching the spec's *fresh top-level traversable* model. Observable side effects for IdPs: Sec-Fetch-Site becomes cross-site instead of none, and the first request no longer carries SameSite=Strict cookies across a 301 redirect. Android has behaved this way since 2023 via Custom Tabs. (f4cb785)
    SecurityNetworkPrivacy
  • A cluster of leak/crash hardening fixes: Reporting API crash stacks now redact cross-origin no-CORS script frames (previously only extension URLs were filtered), Safe Browsing no longer leaks resource.url into the tab's pending allowlist across cross-host redirect chains or view-source: URLs, FIDO HID payloads above kHidMaxMessageSize transition to kMsgError instead of hitting a DCHECK or an empty optional, and the Windows meta-installer delay-loads secur32.dll to close a DLL-hijack surface. (d11f5a9) (6d328ae) (8542332) (0a0420d)
