Security & Architecture

  • Blocked web-initiated navigations targeting custom direct launch schemes (google-chrome:, chromium:) within Blink and added browser-side validation in ChromeContentBrowserClient to terminate compromised renderers. (5abdd77)
    SecurityBrowserNavigation
  • Added browser-side handshake logic in NavigationRequest and RenderFrameHostImpl to enforce connectionallowlist iframe attributes, resolving target origin tokens and blocking non-compliant framed resources. (22f569c)
    SecurityNetwork
  • Updated IsolatedWebAppThrottle::MaybeThrottleNavigationTransition to intercept and throttle iframe navigation requests targeting other installed Isolated Web Apps (IWAs), preventing application isolation boundary bypasses. (fff02df)
    SecurityNavigation
  • Hardened Windows Updater Service IsServerElevated checks by verifying the named pipe server PID via GetNamedPipeServerProcessId and inspecting its token owner directly instead of relying on the pipe handle owner. (dd98718)
    SecurityUpdaterWindows
  • Added strict checks and sanitization for point and size geometries prior to Mojo deserialization across macOS integration paths to harden the browser against renderer exploits or malformed inputs passing NaNs or infinities through IPC. (72561e6)
    SecuritymacOSUI

Browser UI & Desktop Features

    AccessibilityBrowserUI

Extensions & Enterprise

  • Refactored ExtensionMojoBinderRegistry from a global singleton into a profile-keyed service, replacing runtime centralized allowlist filtering with compile-time PassKeys and per-file OWNERS security enforcement. (3f06fa4)
    ExtensionsSecurity
  • Updated enterprise client certificate services to filter managed identities against the TLS server's requested CA certificate authorities (certificate_authorities via SSLCertRequestInfo), ensuring managed identities are only offered when they match requested CAs. (6ad034f)
    EnterpriseSecurityNetwork
  • Added the Extensions.Toolbar.TimeToFirstActionClick histogram to track user engagement dynamics, recording a timestamp upon extension installation and emitting duration on first interaction. (a3f4d21)
    ExtensionsUI
