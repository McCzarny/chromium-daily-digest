Overview

Analysis of recent Chromium commits covering Windows and macOS production builds, focusing on Content embedder APIs, browser UI refactoring, extension management, networking, and security improvements.

Content Embedder APIs & Core Infrastructure

  • ⚠️Removed base::Process and accessors from content::ChildProcessData and updated BrowserChildProcessObserver::BrowserChildProcessLaunchedAndConnected signature. (397f322)
  • Routed ParseManifestFromString through PageManifestManager and ManifestManagerHost to enforce browser-side security validations. (fb23fc5)

Extensions & Policy Management

  • Bypassed policy update downloads for blocked extensions in low-trust environments. (e2b859b)

  • Automatically closed web app detailed install dialog when origin label is occluded. (229f682)

Networking, Security & Printing

  • Migrated ChromeCompaneroLoader to sequence-bound mojo::Remote. (db1edf8)
