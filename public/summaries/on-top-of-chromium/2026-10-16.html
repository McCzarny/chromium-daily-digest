Chromium Digest: 2026-10-16

Overview

Daily summary of Chromium development activity on main branch for 2026-10-16. Out of 1029 total commits, 799 relevant changes were analyzed, spanning from (4f88c24) to (17577a8), focusing strictly on Windows and macOS embedders, browser architecture, UI, networking, and extensions.

Security & Certificate Transparency

  • Removed the obsolete kCertificateTransparencyIgnoreOcspScts feature flag, its expired flag, and all underlying code paths dedicated to processing stapled OCSP SCTs. (fd14521)
  • Enhanced ResourceMultiBufferDataProvider to validate data origins and CORS cross-origin states before mutating metadata or redirecting, and disallowed HLS content from loading local file URLs. (fb2af07) (eda3f57)

Extensions & WebUI APIs

  • Completely removed ExtensionActionStorageManager, which was previously responsible for persisting default settings for deprecated browser actions in the StateStore. (489c362)
  • Updated chrome://extensions-internals to a structured HTML page with a dedicated raw JSON endpoint (/extensions.json) to better support tooling and bug reports. (dc3e11a)
  • Migrated internal extension and browser event constructors under chrome/browser and extensions/ to pass scoped_refptr instead of raw pointers. (12fdc84) (b72ea00)

Browser UI & Core Management

  • Refactored saved tab group menus to dynamically present an enabled Close group action when an associated tab group is currently open. (80502ea)
  • Optimized memory usage and lookup performance inside SafetyListManager by interning strings and special-casing high-frequency https:// rules. (e0b81f9)
  • Refined macOS notification dispatcher and app shim controller logic to accurately measure service restart backoffs and distinguish between launch origins. (c824088) (3a09f53)

Build Infrastructure & Platform Maintenance

  • Updated GN configurations in build/rust/std to use libs instead of all_dependent_configs for standard library system dependencies on Windows. (229a7f4)
  • Modified the Windows updater component to leak the thread pool instance safely upon shutdown and joining, preventing COM server task crashes. (adfea24)
