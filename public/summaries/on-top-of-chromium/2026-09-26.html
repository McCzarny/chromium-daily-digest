Chromium Digest: 2026-09-26

Overview

This digest reviews 61 commits from the Chromium repository, focusing on changes relevant to desktop browser builds (Windows and macOS), embedder interfaces, extensions, security, networking, and UI frameworks, spanning from commit https://chromium.googlesource.com/chromium/src/+/(a07fd8a) to https://chromium.googlesource.com/chromium/src/+/(c436a9b).

Browser Architecture & Tab Management

  • Migrated multiple tab helpers (RevokedPermissionsService::TabHelper, StorageAccessAPITabHelper, V8CompileHintsTabHelper, TabContextDecryptionTokenTabHelper, GlicMarketingPageTabHelper, and NavigationExtensionEnabler) away from WebContentsUserData and direct attachment in TabHelpers::AttachTabHelpers, moving ownership directly into tabs::TabFeatures. (869eb54) (dbedf7b) (e4c416c) (4d448e8) (bbc3a55) (3c0479c)
  • Migrated LocationBarModel to UnownedUserDataHost and removed legacy public feature accessors (location_bar_model(), swap_location_bar_models()) from BrowserWindowFeatures in favor of LocationBarModel::From(). (0c2df90) (db047ab)
  • Consolidated process security tracking by moving is_unused_ from RenderProcessHostImpl into ProcessLock within ChildProcessSecurityPolicyImpl while maintaining legacy accessors. (c436a9b)

Security & Extensions

  • Fixed extension state persistence in chrome.management.setEnabled when policy/component extensions disable user extensions, ensuring DISABLE_BY_ANOTHER_EXTENSION is set so UI toggles and persistent states remain functional. (c357222)
  • Hardened drag-and-drop security by requiring the left mouse button in WebContentsViewAura::StartDragging, preventing compromised renderers from initiating unauthorized drags. (47c56d6)
  • Added exploit test coverage ensuring blob:null synchronous about:blank commits cannot forge arbitrary precursor opaque origins, and removed an obsolete M104 force-install fix-up from ExtensionService. (5b5f818) (fbf799a)

Networking

  • Refactored wildcard QUIC hint lookups in HttpServerProperties from a reversed-string set to an iterative parent domain lookup, ensuring correct longest-prefix matching for nested subdomains without masking parent wildcards. (94795ae)

Desktop UI & Views

  • Modernized application menu (ChroMenu) styling with block margin reductions, macOS footer layout alignments, maximum width parity fixes, and SafetyHub metrics instrumentation. (a07fd8a) (6a0c47b) (54dd0b0) (a7967c5) (d9f47bf)
  • Converted nested OmniboxPopupSelection enums to scoped enum classes and debounced synchronous autocomplete results in AutocompleteController to eliminate suggestion flicker. (2502016) (60e0a08)
  • Improved toolbar interactions by adding click suppression to WebUI pinned toolbar buttons and allowing infobar action links to sit adjacent to message labels in the centralized infobar framework. (27ee861) (3046b37)

Base & Performance Infrastructure

  • Optimized compilation times and memory footprint by outlining base::debug::StackTrace::addresses() and mojo::internal::MessageDispatchContext::error_trace(), and forward-declaring LanguageTag across i18n headers. (4d4aebc) (076165b) (eb84631) (29057f7)
  • Annotated stack-only Gin wrapper helper classes (Dictionary, DataObjectBuilder, TryCatch, ObjectTemplateBuilder) with STACK_ALLOCATED() and replaced raw_ptr fields with raw pointers to reduce reference overhead. (69c4dba)
  • Inlined ExtensionSet::Size() and moved large map representations to eliminate btree_map header dependencies from protobuf. (48cc49c)

Testing & Test Infrastructure

  • Expanded InputProtectionTestApi interactive UI tests to validate click protections and input cooldown enforcement across overlapping Always-On-Top (AOT) desktop widgets and self-interacting hosted surfaces. (4569aa6)
  • Optimized presubmit performance in PRESUBMIT_test.py by mocking Java dependency import checks to prevent whole-repo recursive file traversals. (378a4e0)
