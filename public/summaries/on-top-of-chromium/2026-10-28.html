Overview

On 2026-10-28, Chromium's main branch received 1,066 commits, of which 862 were relevant to embedders and developers. The range is (5a4654b) to (bff1c44).

Breaking Public API Changes

  • ⚠️Removes the renderer-side subresource Safe Browsing Mojo path: mojom::SafeBrowsing, MojoSafeBrowsingImpl, CreateCheckerAndCheck(), and the Safe Browsing constructor parameters on RendererURLLoaderThrottle/URLLoaderThrottleProviderImpl are gone. Embedders that bind, clone, mock, or construct these types must migrate. (3a7099a) (26d8e8b) (610fd1e)
    SecurityNetwork
  • ⚠️Removes public views::NativeViewHost hit-test APIs (SetHitTestTopInset, GetHitTestTopInset), kWidgetNativeViewHostKey, and kNativeViewHostManagesLayers; layer-managed behavior is now unconditional and some layer APIs are ChromeOS-only. Windows/macOS embedders compiling against the removed surface will break. (c300b58)
    UICompositor
  • ⚠️Deletes the public content/public/browser/swap_metrics_driver.h and its SwapMetricsDriver/Delegate API. Any embedder implementing or creating the driver must remove that integration. (f999b87)
    BrowserPerformance
  • ⚠️Changes stable tab mute APIs from tab indices to tabs::TabHandle: TabStripModel::WillContextMenuMuteSites, SetSitesMuted, and tab_utils::IsSiteMuted/AreAllSitesMuted. Index-keyed callers need rewriting and should handle null handles. (531252d)
    TabsBrowser
  • ⚠️Converts blink::Manifest from an aggregate struct to an encapsulated value class with private constructors and Manifest::Builder/BuildChecked(); field mutation and default construction must migrate. Source-breaking for C++ consumers of the public manifest header. (1ede608)
    BlinkBrowser
  • ⚠️Removes SecurityDomainId from TrustedVaultConnection::DownloadGaiaPasswordPublicKey(), TrustedVaultRequest, related URL-fetch reporting, and the per-security-domain UMA family. Implementations, mocks, and callers need signature updates. (b561687)
