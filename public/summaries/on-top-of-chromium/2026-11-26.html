Chromium Digest: 2026-11-26

Overview

937 commits landed on Chromium main, of which roughly 669 were judged relevant to embedders; this digest covers the Windows/macOS-relevant subset. The range starts at (7e1b62c) and ends at (6ec3d67). The day is unusually heavy on hard API breaks: seven public/embedder-facing removals touch Performance Manager, ui/base localization, Sync trusted-vault settings, the SharedImage usage enum, ContentBrowserClient WebUI code-cache virtuals, NavigationURLLoaderDelegate, and the network request revalidation plumbing. Security work dominates the rest (insecure-content password blocking, tabCapture restrictions, permission-data isolation), with a large PDF paint-path performance win and a handful of user-visible desktop UI fixes.

Performance

  • PDF PaintManager::DoPaint() switches from drawImage() to writePixels() via a new CopyPixels() helper that splits the scroll region into four surrounding rects so scrolled content isn't copied twice — drawImage*() is slow for unpremultiplied images and had caused a large regression after M146 in production (Skia-renderer-free) builds. On a MacBook Pro M4 Max @120 Hz: frames presented 63 → 119, DoPaint() 15.3 ms → 2.5 ms, input-to-content p50 63 ms → 47 ms, renderer main-thread busy 100% → 38%; PDF.RenderAndPaintTime should return to ~4.5 ms on Mac and Windows. (2503312)
