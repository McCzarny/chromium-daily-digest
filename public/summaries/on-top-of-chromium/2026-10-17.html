Chromium Digest: 2026-10-17

Overview

Across 266 total commits (152 analyzed as relevant), development focused heavily on desktop windowing and graphics pipeline optimizations for Windows and macOS, security hardening against Windows privilege escalation, and underlying base library performance improvements. Key commits span from (efb0817) to (4603aa2). No breaking embedder API changes were introduced.

Desktop UI & Graphics

  • Removed software compositing overrides for secondary Windows browser widgets (context menus, tooltips, status bubbles, omnibox popup), enabling them to default to hardware GPU acceleration without forcing D3D10Warp.dll software fallbacks. (9ebbe2c)
    UICompositorWindows
  • Fixed a macOS layout issue where WebUI toolbars failed to receive first-responder status due to parent view bounds not being positioned prior to child views in BrowserViewLayout. (afcc5be)
    UImacOS
  • Introduced the kMacDeferInputContextUntilFirstPaint feature flag on macOS to defer AppKit text input context activation until the first paint or key event, reducing startup stalls from external IMEs. (5c21056)
    UIPerformancemacOS
  • Decoupled search query filtering from menu rendering via AppMenuSearchController::Delegate, and prevented duplicate Reading Mode context menu entries in RenderViewContextMenu. (9f1ad6e) (f9cfeba)
    UIBrowser

Security & Extensions

  • Extended ContentBrowserClient with IsUnboundedElementEscapingAllowed to allow privileged extension subframes (such as contextual tasks side panels) embedded in trusted main frames to escape viewport bounds. (c02f9fc)
    SecurityExtensionsBrowser
  • Hardened Google Credential Provider for Windows (GCPW) against TOCTOU and pre-creation local privilege escalation by introducing SecureOpenFile, SecureCreateFile, and junction redirection checks. (06f21c7)
    SecurityWindows
  • Removed local caching of OAuth access tokens in PaymentsNetworkInterfaceBase, directly delegating token requests to IdentityManager to ensure automatic refreshes on expiry. (21a6046)
    PaymentsSecurityNetwork

Base Utilities & Performance

  • Optimized PrefService reads by adding PrefValueStore::GetValueFromNonDefaultStores(), returning cached default pointers directly when un-overridden instead of executing secondary linear lookups. (1323b32)
    BasePerformance
  • Switched to base::InsertOrAssign() and flat_map::insert_or_assign() in CommandLine and SequenceLocalStorageMap to eliminate redundant map lookups and temporary allocations. (40d22af)
    BasePerformance
  • Eliminated user32.dll dependencies from base::ProcessIterator path comparisons in the Windows updater to prevent crashes under win32k system call disable mitigations. (b1da851)
    UpdaterBaseWindows
  • Introduced kMojoFixGeometricBufferGrowth2 to decouple geometric Mojo buffer growth from unrelated experiments and avoid reallocation jank on Windows. (a65e1b3)
    BasePerformance

Media & Screen Capture

  • Promoted D3D12VideoEncodeAccelerator and D3D12SharedImageEncode to default-enabled on Windows builds. (efb0817)
    MediaGPUWindows
  • Restored VP8/VP9 screen content encoding hints (ContentHint::Screen) and minimum quantizer clamps in Cast mirroring to eliminate blurred text during tab streaming. (31d2063)
    Media
  • Cleaned up obsolete desktop capture device interface methods SetDesktopCaptureWindowIdAsync and SetNotificationWindowId from content/public/browser. (7319966)
    MediaBrowser

Testing & Tooling

  • Continued modularization of monolithic UI test targets by splitting autofill, profile picker, and payments UI helpers into isolated test GN targets. (fcd7246) (4ab49f8) (44b0d4e) (bdbfc79)
    TestingBuild
  • Removed no_exit_time_destructors build exemptions across test support targets in //ui/views, //ui/base, //extensions, and //services/network. (0a9bfcc) (3fba161) (552acf3) (110d2c6)
    BuildTesting
