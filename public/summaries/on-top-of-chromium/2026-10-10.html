Chromium Digest: 2026-10-10

Overview

This digest covers 68 commits landed on Chromium main between (8531890) and (8551093). No MAJOR breaking changes to stable public APIs were confirmed; the batch consists mostly of bug fixes, internal refactoring, feature-flag cleanup, UI/UX polish, and test/infrastructure changes. Per custom instructions, ChromeOS/Ash, Android-specific, iOS-specific, and Blink/V8 rendering changes are de-emphasized.

Security & Privacy

  • CRD host hardening: remote_webauthn now validates the calling extension origin for native messaging hosts, rejecting arbitrary extensions from driving the WebAuthn proxy (extension ID list moved to remote_webauthn_constants). Also on macOS, AgentProcessBroker records each agent's real UID and rejects BindChromotingHostServices() callers whose UID doesn't match the active agent, matching per-user isolation on Linux/Windows. (008b2a4) (fa7decb)
    SecurityNetwork
  • Bluetooth: ClearAdvertisementClients() now calls MaybeStopDiscovery() so BlueZ discovery sessions are released when clients are cleared on tab hide/focus loss, instead of leaving platform scans active for the tab's lifetime. (18e4f79)
    BluetoothBrowser
  • Private AI: Added certificate_util with PemToDer/PemToDerChain helpers (BoringSSL PEM tokenizer) to decode PEM X.509 certificates to DER for Private AI TLS sessions, including OakCT certificate bundles. (ca2f0ce)
    CryptoSecurity

AI & Intelligence

  • Decisions API: Added AILanguageModelDecisionModel, a blink.mojom.AIDecisionModel backend scoring options via the Prompt API's on-device foundation model (Gemma 4), with prompt building, token-quota checks, and serialized decide() calls. A follow-up routes AIManager to this backend, gated behind chrome://flags#decisions-api (experimental). (e1d526d) (a07b28e)
    AIBrowser
  • Actor/Glic: AttemptFormFillingTool now supports credit_card_opaque_token for direct form filling without the suggestion-selection dialog (Desktop and iOS), rejecting invalid combinations with kArgumentsInvalid. Also fixed stale recreation-state overrides clobbering expanded Glic shows on Android, added a glic-ssr chrome://flags entry, recorded Glic.Fre.Invoked metrics, and improved the Glic start benchmark (H2 test server, type-only imports, network-service warmup). (54ae2f1) (218b85f) (4e1ca1e) (136175f) (b0abae7)
    AIBrowser
  • iOS Gemini: Forwarded conversation-load errors through GeminiSessionDelegate/Handler/Mediator to transition to zero state on failure, and moved ForceDismissFloaty() triggers into GeminiContainerMediator. (009068a) (209e78c)
    iOSAI

Browser UI & UX

MenuItemView::GetMnemonic() was fixed for &&, and action-bound menu items now show mnemonic text. Nothing sets the hooks yet in the first CL, so no immediate behavior change. (8542b55) (705e8fd) (b38624c)
    UIBrowser

Sync, Profiles & Preferences

  • Cross-device themes: CrossDeviceThemeTracker now matches synced themes by OS type/form factor/DataType instead of per-device GUID, replacing GetThemeForDeviceGuid with GetThemeForOsTypeAndFormFactor and removing unused DeviceInfoTracker observation and per-device fields. This is an internal API change within Chrome's own components, not a public embedder API. (2cdaa03)
    SyncThemesProfiles
  • Cross-device prefs: CrossDevicePrefTracker no longer records/propagates pref entries when the value equals the registered default and no local entry exists, fixing false "written preference" counting during startup initialization. (703e689)
    SyncProfiles
  • Journeys (History): Journey collections are now synced from the server into the local history database and resolved against the journey's visits for the details page; unmatched items and empty collections are dropped. Shared gtest printers moved to a common test-only file. (f53d33e) (1849672) (02f294b)
    HistorySync

Policy & Enterprise

  • Policy UI cleanup: Removed leftover Lacros allUsers scope code — deleted GetPolicyScope() from PolicyConversionsClient, inlined user/machine scope conversion, and removed the IDS_POLICY_SCOPE_ALL_USERS localized string and its UI mapping. This removes an internal method from a POLICY_EXPORT class but only affects the chrome://policy WebUI display path. (f796f33)
    PolicyUI

Printing & Downloads

  • Android printing: The 3-stage print lifecycle now binds the target frame's GlobalRenderFrameHostId at initiatePrint and propagates it through print()/finishPrint(), so teardown reaches the originating frame even if it navigated or entered BackForwardCache. (3f0cdf9)
    PrintingAndroid
  • WebAPK icon hashing: WebApkSingleIconHasher now uses SelectFaviconFrameIndices to pick the best bitmap frame instead of hardcoding bitmaps[0], fixing 16x16 frames being sent to the WebAPK minting server for multi-frame .ico icons. (5ef7532)
