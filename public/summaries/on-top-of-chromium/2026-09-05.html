Chromium Digest: 2026-03-31

Overview

A total of 41 commits were reviewed in this cycle, with focus placed on browser infrastructure, extensions, security, UI layouts, and core developer tools affecting macOS and Windows desktop embedders. The commits analyzed range from (fe12b50) to (535bbdd).

UI & Browser Views

  • Fixed an issue in ToolbarView::LayoutCommon() where hidden contextual tasks buttons zeroed out leading margins, restoring default margins and Back button Fitts' law edge hit-target expansion in maximized and RTL layouts. (76d845d)
  • Added NonBrowserFeaturePromoController to user education to decouple non-browser features (such as Omnibox Everywhere and Profile Picker) from standard browser window controllers. (fe12b50)
  • Enabled menu dialog containers created from <menulist> and <menubar> elements to properly compute posInSet and setSize attributes for screen readers. (afdd1cd)
  • Removed unused ProgressBar::background_color() accessor from ui/views and exposed CSS Shadow DOM parts on the Omnibox composebox Lens chip for custom UI styling. (5ecae5d) (535bbdd)

Extensions & Component Architecture

  • Introduced support for component extensions to enable and consume Mojo JS bindings inside service worker contexts via ExtensionMojoBinderProvider. (c1b4af8)
  • Routed dynamic component extension resources (/strings.m.js) directly through ExtensionConfigProvider to eliminate unnecessary indirection. (7ad74a0)
  • Added AimEligibilityComponentInstallerPolicy with staged update installation across browser restarts and bundled manifest fallback protection. (4a08d0c)
  • Converted ExtensionInstalledWatcher to use window-scoped UnownedUserDataHost for consistent object lifetime management across browser window features. (a012785)

IPC, Security & Networking

  • Added native hash_map type support to Mojom IDL and C++/Blink code generators, directly mapping to hash map structures such as absl::flat_hash_map. (33b3764)
  • Added ElideEmail utility in //remoting/base to prevent UI domain spoofing by independently preserving leading username characters and verified domain/TLD suffixes. (a687182)
  • Modernized buffer pointer manipulation and range operations across Chrome updater modules using C++20 std::ranges::assign_range. (59f7b8f) (9cdaa95) (090f6cc)
  • Updated update_crs_root_ids_enum.py to parse MTC issuers from signer_set.textproto. (28f4b9e)

Media, Speech & Machine Learning

  • Updated IsOnDeviceSpeechRecognitionSupported() on x86 Windows and macOS platforms to require base::CPU().has_avx(), preventing crashes in gemmlowp fallback kernels. (cab02c6)
  • Added re-entrancy protection and null buffer handling during synthesis failures in ReadAloudDecoderSequencer. (7845104)
  • Reshaped INT32 GATHER indices to 1-D on the WebNN GPU delegate for hardware accelerator compatibility. (c6b524d)
  • Modernized map and container iteration across media and audio services to use C++ structured bindings and std::ranges::contains(). (1286e9c) (8980f2e)

Toolchain & Developer Tools

  • Rolled Clang and Rust toolchains to upstream revisions. (b26ae1e)
  • Improved line-length wrapping and expression indentation rules in the WebUI Lit template formatter. (108563d)
