Chromium Digest: 2026-08-01

Overview

This digest covers 31 commits ranging from (8086799) to (8127138). Key highlights include SiteInfo isolation enhancements for privileged WebContents, memory optimizations in extension feature handling, disk storage space gating for on-device AI sessions, and removal of legacy network interception commands from the DevTools protocol.

Browser Architecture & Process Security

  • Embedder isolation resolution (EmbedderIsolationInfo::kPrivileged) now derives directly from immutable WebContents creation parameters (PrivilegedWebContents), ensuring renderer-initiated navigations and subframes commit privileged SiteInfo and never share process space with unprivileged content. (dd5caab)
  • Prevented process crashes during app window reparenting (ReparentWebContentsIntoAppBrowser) by validating WebContents state prior to executing rapid double-trigger intent picker launches. (5d49e09)
  • Reverted a speculative struct size check on Windows FILE_NOTIFY_INFORMATION structures within FilePathWatcherWin. (73eaf28)

Extensions Infrastructure & APIs

  • Refactored SimpleFeature definitions to store non-owning string_view spans backed by static storage rather than runtime std::string vectors, eliminating over 1,000 allocations and saving ~70 KiB of private heap per process. (bc1bc89)
  • Guarded extension API window creation routines (windows.create and tabs.create) with WeakPtr lifetime tracking to prevent crashes if window destruction occurs asynchronously during execution. (c999d75)

Browser UI & Desktop User Experience

  • Updated OmniboxAutofillDelegate to automatically hide the omnibox autofill chip once the target form is filled via standard or omnibox autofill. (37189e4)
  • Added a snoozeable In-Product Help (IPH) prompt triggered upon creating side-by-side split tab views. (2538ada)
  • Updated reading mode selection distillation in ReadAnythingAppModel to inspect parent containers, preventing empty panel states. (8c3f5c5)
  • Exposed a native cursor position IPC primitive on AiOverlayDialogPageHandler. (978d510)
  • Updated ContextHubService to automatically write generated first-party AutoTodos into local cache storage. (4d604ca)

Networking, WebID & DevTools Protocol

  • Removed deprecated request interception commands (setRequestInterception, continueInterceptedRequest, and getResponseBodyForInterception) from the DevTools Network domain in favor of the Fetch domain. (961a989)
  • Introduced AccountsFetcher::FetchAccountsForIdps to cache IdentityProviderInfo during FedCM request flows, avoiding redundant network round-trips. (5f44079)
  • Streamlined script hash tracking in DevToolsListener by adopting std::set and const dictionary lookups. (c50da2d)

On-Device AI & Document Services

  • Gated session initialization across built-in AI APIs (Prompt, Writer, Rewriter, Summarizer, Proofreader, Classifier) on adequate disk cache space, surfacing detailed DevTools warnings on failure. (fcfe54d)
  • Introduced PDFTranslationCoordinator to verify PDF document translatability based on text presence, lack of active JavaScript, and password protection status. (9b26d19)

Media, Graphics & Base Infrastructure

  • Updated HlsManifestDemuxerEngine to ensure audio-only primary renditions lacking explicit URIs fall back to using the variant URI. (2e7fe47)
  • Removed unused boolean parameters (supports_multiplanar_rendering and supports_multiplanar_copy) from gpu::GraphiteBackendTextureInfo. (49bf239)
  • Refactored base::RefCounted object instantiations across //chrome to use base::MakeRefCounted(). (b6b5c55)
  • Exposed support component targets (support_util, support_preprocessor, support_tokenizer) in third_party/litert/BUILD.gn. (bf5e2f9)
  • Added DumpWithoutCrashing calls in display management to diagnose empty display bounds occurrences. (fefb48b)
