Chromium Digest: 2026-10-24

Overview

A total of 46 commits were analyzed spanning revisions (e55752e) to (695e487). The changes focus primarily on browser UI stability, Windows accessibility fixes, enterprise clipboard auditing, network API optimizations, and security hardening for PDF navigations. No major breaking changes to public embedder APIs were identified.

Security & Enterprise Protection

  • Disallowed creating Service Worker main-resource handles for PDF navigations as a defense-in-depth measure, preventing PDF renderer processes from receiving Service Worker-intercepted subresource responses or gaining storage access to the hosting origin. (f8cc87d)
  • Updated enterprise Data Controls clipboard enforcement to trigger DLP content analysis even when clipboard text is replaced, ensuring managed environments still audit and enforce policies for data restricted to the browser. (b09fb88)
  • Updated static preloaded HSTS entries across the global transport security preload database. (2e8c19f)

Browser UI & Navigation

  • Fixed an infinite loop and browser hang in dynamic bookmark menus caused by repeated additions and removals of observers when loading bookmarks while the application menu was active. (19aeeb8)
  • Refined infobar priority queuing to prevent lower-priority replacement bars from displacing queued higher-priority bars, and suppressed queued-count indicator pills on persistent, non-closeable infobars. (2918066) (7ac45f4)
  • Fixed an issue in the WebUI Omnibox popup where cutting a selection from previewed match text erroneously erased the full input row, preserving proper editing and undo history. (695e487)
  • Scoped Contextual Tasks side panel thread modifications and thread creations to individual active tabs, and enabled side panel thread state to persist across tab closures for recovery via TabRestoreService. (1e37553) (8a5b2f0) (b01d831) (dbe5983)
  • Addressed Tab Organizer panel UI issues by correcting child view hit-testing when open, auto-closing section menus on loss of focus, and preserving tab group last-update timestamps during session restore. (e55752e) (3a7361d) (5fcaee8)

Accessibility & Platform Integration

  • Prevented browser crashes caused by synchronous COM re-entrancy during Windows accessibility event dispatch by securing object references and validating manager/node/frame host liveness. (a752502)
  • Optimized Windows UI Automation (UIA) attribute queries by skipping expensive coordinate translations for attributes that do not depend on text offsets (such as IsReadOnly), resolving UI thread freezes during focus tracking. (a96815e)

Networking & Embedder APIs

  • Modernized public Content Security Policy parsing utilities in services/network/public/cpp with std::string_view, heterogeneous base::flat_set lookups, and a new ToStringView(mojom::CSPDirectiveName) helper to eliminate unnecessary string copies. (d4c1323)
  • Updated blink.mojom.ManifestManager Mojo interfaces to support nullable Manifest? responses while maintaining backward compatibility with existing browser-side callers via ManifestManagerHost fallbacks. (277bebc)

Performance & Testing Utilities

  • Eliminated heap allocations during complex text shaping by adopting absl::InlinedVector for script extensions in RenderTextHarfBuzz. (ae6aa9e)
  • Excluded compositor PaintOpBuffer destruction, resets, and scratch vector resizing from PartitionAlloc safety check quarantining, significantly cutting deallocation overhead and memory churn. (7028282) (0e95ec7)
  • Introduced a DestroyBrowserContext() virtual teardown hook in content::RenderViewHostTestHarness to allow custom test contexts to be cleanly destroyed before test environment shutdown. (2521b65)
