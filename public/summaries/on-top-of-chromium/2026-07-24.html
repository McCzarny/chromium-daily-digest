Chromium Digest: 2026-07-24

Overview

Daily summary of Chromium changes for 2026-07-24 (main branch) covering 714 total commits, with 543 relevant commits affecting Windows and macOS browser features, APIs, extensions, and security. Ranging from commit (8e78fe0) to (74c50be).

Browser UI & Desktop Navigation

  • Added a display boundary monitoring feature in TabDragController to dynamically resize dragged single-tab browser windows or detached tabs to fit the target display's work area on macOS. (15a58c5)
    UITabsmacOS
  • Integrated launch confirmation dialogs into WebInstallServiceImpl when a manifest-based navigator.install() call resolves to an already installed web application. (b9fee11)
    BrowserUI
  • Added the CombinedBookmarksView to expose local and account bookmark models as two distinct subtrees for consumers requiring dual-tree views. (19590c7)
    BookmarksUI

Extension System & Core APIs

  • Optimized memory overhead in SimpleFeature by using compile-time std::string_view spans for generated match patterns instead of heap-allocated string vectors, eliminating per-process allocations across hundreds of extension feature definitions. (9a10da2)
    ExtensionsPerformanceBase
  • Exposed GetDeviceForExtension on the UsbDeviceManager Mojo interface to allow Chrome extensions and legacy Chrome Apps using the chrome.usb API to execute unrestricted USB control transfers by default. (454c3be)
    ExtensionsUSB
  • Added support for specifying an alarm name via AlarmCreateInfo.name in the extension alarms.create() API. (d458c84)
    Extensions

Security, Networking, & Privacy

  • Added a security check in RenderFrameHostImpl::ValidateDidCommitParams ensuring that renderer-supplied DidCommit URLs strictly match NavigationRequest::GetURL() for error pages. (e2b48fe)
    SecurityNavigation
  • Updated URLRequestHttpJob to ignore DBSC headers when a connection encounters TLS certificate errors, preventing unauthenticated endpoints from manipulating persistent session state. (6472984)
    SecurityNetworkSSL
  • Bounded filename reads in ui/base/clipboard/clipboard_win.cc by the HGLOBAL allocation size, preventing out-of-bounds browser-process memory reads on non-NUL-terminated clipboard buffers on Windows. (ae6c58a)
    SecurityWindows

Base Framework & Platform Utilities

  • Converted ui::Layer color APIs (SetShowSurface, SetColor, and background colors) across Views and core UI components to use SkColor4f instead of SkColor. (3cd0131)
    UIBaseCompositor
  • Switched custom macOS accessibility attribute definitions in ui/accessibility/platform to native macOS ApplicationServices and AppKit SDK constants. (1966211)
    AccessibilitymacOS

Developer Tools, Testing & Infrastructure

  • Updated Kombucha interactive browser test failure handlers to dump and format full HTML DOM trees for all instrumented web contents. (14aa317)
    TestingDevTools
  • Granted AppContainer LPAC SIDs modify access to LLVM profile directories to enable continuous code coverage logging for sandboxed child processes on Windows. (a53cf7b)
    SecurityTestingWindows
