Build Infrastructure & Tooling

  • Added src/third_party/cpython3 CIPD packages for Windows and macOS platforms to transition GN and Siso toward hermetic execution environments. (322a178)
  • Implemented foundational configuration flags, dependencies, and loaders to support splitting renderer execution into a separate binary (chrome_renderer.dll) on Windows platforms. (74a9bb4)
