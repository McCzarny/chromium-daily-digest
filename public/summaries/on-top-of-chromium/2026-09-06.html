Chromium Digest: 2026-09-06

Overview

This digest summarizes 12 commits touching various areas of the Chromium codebase, spanning from (313abe8) to (d8a1ff2). Focus areas for desktop embedders (Windows and macOS) include security profile isolation within the Actor subsystem, extension keybinding and UI focus lifecycle refactoring, audio resampler fixes, and unit test harness modernizations under Project Bedrock.

Security & Permissions

  • Enforced strict profile boundary validation across ActorTask, ActorKeyedService, and tooling (ToolController, WindowManagementTool, WaitTool, PageTool). Validation now fails closed when a referenced tab or window is null or belongs to a different user profile, returning the new result code kActionTargetCrossProfile. (8d12fea)
    SecurityProfilesBrowser
  • Performed code style and structure cleanups in PermissionServiceImpl and related embedded permission control unit tests. (86b9dd1)
    SecurityPrivacy

Browser UI & Extensions

  • Migrated ExtensionKeybindingRegistryViews to the UnownedUserData pattern hosted on BrowserWindowInterface, replacing direct accessor methods on BrowserWindowFeatures with ExtensionKeybindingRegistryViews::From(). (023b0db)
    ExtensionsUIBrowser
  • Updated views::ExternalFocusTracker to manage its observation lifecycles via base::ScopedObservation. (85c6bec)
    UI

Media & Audio

  • Resolved a CHECK failure in media::AudioConverter when input buffer sizes are smaller than SincResampler::kMinRequestSize (48 frames) by rounding up resampler request sizes and bridging chunks via an AudioPullFifo. (d8a1ff2)
    Media

Testing Infrastructure

  • Refactored GlicLinkoutHandlerTest from BrowserWithTestWindowTest to ChromeRenderViewHostTestHarness as part of Project Bedrock, replacing Browser* dependencies with tabs::MockTabInterface. (337659e)
