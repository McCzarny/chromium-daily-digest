Overview

Out of 355 commits on 2026-11-07, 195 were filtered as relevant. No confirmed breaking changes to stable embedder-facing public APIs were found. First commit: (455737d); last commit: (93f28f2).

Security & Networking

  • QWAC verification is now enabled by default on desktop. The kVerifyQWACs feature default flipped and its field-trial study was removed; qualified website authentication certificates are validated by default. This is a behavioral change for enterprise/desktop TLS deployments, not an API break. (5a259c6)
    NetworkSSLEnterprise
  • Windows Mojo/ipcz pipe adoption is hardened. Transport::Deserialize() now requires the received named-pipe handle to be the sole open handle for that end, and ChannelWin matches IOCP completions to its own outstanding OVERLAPPED. This closes an IOCP packet-spoofing vector; embedders with custom Windows IPC should review assumptions. (f365a99)
    SecurityWindowsBase
  • Security fixes for libxslt and filesystem access. A reentrancy use-after-free/double-free in libxslt's direct pattern-match cache was fixed, and the File System Access sensitive-path blocklist (for example .ssh and home-directory dotfiles) is now matched case-insensitively. (61cab3f) (1138e49)
    SecurityStorage
  • Proxy implicit bypass now includes unspecified IP literals. Requests to 0.0.0.0, [::], and IPv4-mapped unspecified addresses skip PAC/manual proxy settings via kBypassProxyForUnspecifiedIpAddresses, which is enabled by default. Network embedders should verify proxy expectations for unspecified-address traffic. (1119818)
    NetworkPrivacy
  • Remoting host hardening on Windows and macOS. Windows pre-warms the LowBox AppContainer and falls back to launching without SECURITY_CAPABILITIES on resource exhaustion; macOS adds per-display capture-excluded privacy overlays; Windows curtain mode caps the RDP virtual desktop at 4K with DPI scaling. (2fbb17b) (3d99c84) (3a1c820)
    SecurityWindowsmacOS

Browser UI & Tabs

  • macOS omnibox popup fullscreen and click-focus fixes. OmniboxPopupView::OnFullscreenTransitionStarting() lets the Full WebUI popup close and reshow cleanly during fullscreen transitions, and clicks into an unfocused popup focus the input rather than activating the AI Mode button. (00011f9) (8a49ab3)
    UImacOSBrowser
  • Omnibox popup WebUI architecture refactored. New OmniboxPopupContentDelegate and optional OmniboxPopupContentSizer decouple content from presenters; OmniboxPopupUI::SetPresenterDelegate is renamed to SetSearchboxHandlerDelegate. Stated no behavior change, but out-of-tree code touching these chrome/browser/ui/views/omnibox internals must adapt. (56a4aea)
    UIBrowser
  • Other device tabs submenu now updates live. OtherDeviceTabsSubMenuModel subscribes to SessionSyncService foreign-session changes and notifies its delegate; ActionAppMenu::RebuildSubmenu() repopulates open-tab actions. (c00e304)
    UISyncBrowser
  • Omnibox WebUI popup pool now reacts to memory pressure. OmniboxPopupWebUIPool becomes a stateless MemoryConsumer and destroys idle shared WebUI popups under pressure, with new parameters for idle and moderate-pressure drops. Defaults vary by platform. (1812171)
    UIPerformance
  • Unified tab strip: animation, vertical-state crash fix, and throbber layer painting. Direct switches between focused tab groups animate horizontally; VerticalTabStripStateController is no longer accessed outside vertical orientation for tabbed PWAs/non-normal windows; throbbers can paint to a layer while animating. (65641bc) (1ad61fb) (17c3098)
    TabsUIPerformance
  • Session restore fixes cross-scheme URL rewrites. ToNavigationEntry() decodes into a temporary context and synthesizes PageState for cross-scheme entries, while Navigation API history collection stops at origin boundaries, avoiding history leaks and use-after-free risks. (6f72c7c)
    NavigationHistoryBrowser

Extensions, Policy & AI APIs

  • Subresource loader proxy IPCs get a high-priority task queue when extensions intercept requests. BrowserTaskType::kSubresourceLoaderProxy (behind kSubresourceLoaderProxyTaskQueue) binds CreateLoaderAndStart and header/receive callbacks from proxying factories to a deferred high-priority runner, preserving frame lifecycle and allowAllRequests ordering. Relevant to embedders hooking ContentBrowserClient::WillCreateURLLoaderFactory. (d24bf1f)
    ExtensionsPerformanceNetwork
  • Extension preference controllability is now explicit. PrefTransformerInterface::IsExtensionModifiable() and PrefModifiabilityObserver were added; chrome.types/chrome.privacy set() and GetLevelOfControl() now reject non-modifiable prefs such as extension-scoped ProxyOverrideRules for unaffiliated users on managed devices. (455737d)
    ExtensionsPolicyEnterprise
  • Built-in AI session API changes from context size to input size. OnDeviceSession::GetContextSizeInTokens() becomes GetInputSizeInTokens(), counting prefilled create-time context plus execution input in create-time checks, usage measurement, and per-call quota for Summarizer/Writer/Rewriter. Experimental API consumers must update. (b6a2ea9)
    AI
  • Glic adds passkey-gated opaque invoke error diagnostics. InvokeErrorDiagnosticsPasskey, SetOnErrorWithDiagnostics(), and TakeOnErrorWithDiagnostics() are explicitly documented as non-stable debugging hooks for Glic invoke failures. (a714692)
    AI
