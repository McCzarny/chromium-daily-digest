Chromium Digest: 2026-11-11

Overview

Chromium main received 1,196 commits on 2026-11-11, of which 946 were relevant to this digest. The range runs from (e73b8fa) to (0fba83b). The day includes several source-breaking public-interface changes, security/privacy tightenings, networking behavior fixes, desktop UI improvements, and notable performance work in tabs and session persistence.

Breaking API & Interface Changes

  • ⚠️mojo::Message parameter-struct constructors were removed. Generated bindings now preallocate the parameter struct and use MessageFragmentBase::ClaimInitialPayload(). Out-of-tree embedders with hand-written serialization, custom message construction, or vendored generated bindings must migrate or regenerate. (80d5b48)
    BaseBuild
  • ⚠️content::MediaSession gained a new pure virtual RebuildAndNotifyMediaPositionChanged(). Any embedder that implements, subclasses, or mocks content::MediaSession must add the override. Companion work enables Read Aloud progress/rate/end-of-stream reporting for desktop media notifications. (f268721) (7b55cf2)
    MediaBrowser
  • ⚠️ContentBrowserClient::EnforceSystemAudioEchoCancellation() was deleted along with the --system-aec-enabled switch and related feature/policy remnants. Out-of-tree ContentBrowserClient subclasses declaring this virtual with override will fail to compile. (07cd5aa)
    MediaBrowser
  • ⚠️content::DigitalIdentityProvider::Get() now requires a UiWarningLevel argument, and ComputeInterstitialType() is replaced by ComputeUiWarningLevel(). Update every override, call site, content-shell/headless implementation, and test mock. (66be729)
    PrivacySecurity
  • ⚠️CookieSettingsBase::ShouldAlwaysAllowCookies() gained a net::CookieSettingOverrides parameter. Subclasses of this exported interface must widen their overrides. The same change makes privileged WebContents force-allow cookies/storage and bypass user site settings, which PWC/Glic adopters should account for. (03d01e1)
    NetworkPrivacySecurity
  • ⚠️HistoryClient gained a pure virtual CanDeferBackendInit() and deferred backend init now keys off the client rather than a global feature. Embedders implementing components/history HistoryClient must add an override; startup behavior also avoids forcing history DB init during NTP startup. (8cd36fc)
    HistoryProfiles
  • ⚠️Tab-strip observer and model APIs changed. OnTabCloseCancelled() and TabGroupedStateChanged() now use tabs::TabHandle instead of raw TabInterface*, with the index removed from the grouped-state callback. Public TabStripModel persistability helpers were also removed in favor of session_tab_group_utils. Downstream observers must be rewritten and handle stale handles. (3b0d498) (9adaf8d) (3986ec1)
    TabsUI
  • ⚠️base::i18n::GetConfiguredLocale() was removed; use base::i18n::GetDefaultIcuLocale() instead. Locale strings are now BCP 47, which can change values exposed through LocalizationUtils.getNativeUiLocale(). Raw icu::Locale::getDefault() is also being presubmit-banned outside base/i18n. (e206c25) (a25540d)
    I18nBase

Security & Privacy

  • FileChooser symlink containment is now bounded by the user's authorizing grant. The symlink walk stops at the actual granted directory rather than the renderer-supplied path, preventing uploads from following a symlink above the chosen folder. Some symlinked-folder uploads regain content; a rare prior-ancestor-grant case fails safe. (0fc0e20)
    SecurityUI
  • Web Install manifest fetches now enforce Local Network Access and renderer isolation. The fetcher supplies request_initiator and ClientSecurityState, blocks public-to-loopback/private probes at the socket layer, and rejects untrustworthy initiating origins. Cross-origin public manifest fetches still work; loopback fetches now fail. (5e32afa)
    SecurityNetworkNavigation
  • encrypted-media Permissions Policy is now enforced in the browser process. MediaInterfaceProxy::CreateCdm() rejects policy-denied frames with ReportBadMessage, closing a renderer path that could bind CreateCdm directly and persist per-StorageKey CDM state despite the policy. (339b6c4)
    SecurityMedia
  • DBSC deletion is scoped to unpartitioned, first-party data. BrowsingDataRemoverImpl no longer ORs in device-bound-session removal for partitioned or non-first-party filters, preventing third-party Clear-Site-Data from over-deleting DBSC sessions. The filter-builder interface also gains GetStorageKey() for out-of-tree implementers. (5a50e8e)
    PrivacyNetworkStorage

Networking & Storage

  • Sparse HTTP cache entries are always validated before serving a range. If a sparse entry does not fully cover the requested range, the first chunk is validated before headers are returned, ensuring a fresh network response and timestamps are stored before network body bytes are stitched in. This closes a stale-timestamp/modified-body path but adds a validation round-trip where the old shortcut existed. (76f1e9f)
    NetworkStorage
  • Native system-proxy resolution is now an opt-in ConfiguredProxyResolutionService capability, using a defaulted system_proxy_service parameter and bypassing PAC for system-origin baselines. HostCache also now reports age/original TTL on fresh hits, improving DNS staleness diagnostics. Both changes are additive. (d8f831d) (376051e)
    Network
  • Component updater downloads now stop and resume on connection-cost changes. On Windows, metered connections cancel in-flight component downloads when the component disallows metered updates, then retry after the connection is unmetered. Windows BITS/background downloads are intentionally not cancelled. (e4b44d9)
    UpdaterNetwork

Browser UI & Platform Behavior

  • Omnibox popup now handles modal dialogs, IME-click safety, and URL input semantics more consistently. The popup closes during window-modal dialogs and restores draft text/selection on close; the first mouse press after an IME commit is stabilized; and the WebUI omnibox uses URL-oriented input modes on supported states. (ad8126e) (341dace) (145e77e)
    UIBrowser
  • Reading Mode sessions survive side-panel/immersive presentation switches. Sessions are moved rather than closed and reopened, preserving Read Aloud, pending listen/translation, and omnibox attribution across transitions. Pagination duration is recorded per view mode. (3f6d0e8)
    UIBrowser
  • macOS live-resize and app-shim keyboard behavior were fixed. Tiling/live-resize stutter and AppKit clamp feedback loops are removed, center-resize drift under async live resize is corrected, and out-of-process PWA app shims now forward Cmd+KeyUp and JIS Eisu/Kana key events through shared CrApplication logic. (456f04b) (5fc7e17) (da053b0) (df734d6)
    macOSUI
  • Desktop search behavior improved. Chrome menu search now reaches items inside submenus, maps bookmark-bar and incognito synonyms, and restores the full app menu when the query clears. History hostname-suffix matching is locked in with tokenized host: queries and url.DomainIs() semantics. (52d3cc3) (8f9b004) (0b94369)
    UIHistory

Performance & Stability

  • Tab-strip handle lookups went from O(n) to O(1). RootTabCollectionNode now maintains a hash map of handles, and subtree-membership checks use Contains(). With 1,436 restored loading tabs, UpdateLoadingAnimations dropped from ~3.3 ms to ~0.30 ms per throbber tick. (e131fc7)
    TabsPerformance
  • Session files are no longer fully rewritten on every second navigation. History-bounds tracking now stores an inclusive bound with a one-step lookahead instead of forcing a rewrite after startup/restore. The change must land after the associated session-persistence safety fix. (e84055b)
    PerformanceBrowserProfiles
  • Windows drag-and-drop no longer leaks STGMEDIUM handles on every drag update. OSExchangeDataProviderWin now releases IDataObject::GetData() results on all paths, avoiding exhaustion of the 65,535 movable-handle limit after long drag sessions and preventing subsequent clipboard failures or crashes. (66b2016)
    WindowsUIPerformance
  • Windows D3D12 H.264/H.265 software screen-content encoding is substantially improved. The rate controller now uses a one-second HRD buffer, caps display-content QP at 35, and follows real frame timestamps, fixing severe blur in tab-mirroring of static pages at low bitrates. (6c5ba76)
    MediaWindowsPerformance

Developer Tooling & Build
