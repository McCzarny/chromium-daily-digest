Chromium Digest: 2026-08-10

Overview

This report summarizes 489 relevant Chromium commits out of 633 total changes processed for Windows and macOS desktop platforms on August 10, 2026. Ranging from commit (a53a191) to (1da21d4), this edition highlights critical security hardening, desktop UI and startup performance enhancements, content client API adjustments, and infrastructure updates tailored for Chromium-based embedders.

Core Embedder APIs & Content Layer

  • ⚠️Removed IsSharedStorageAllowed() and IsSharedStorageSelectURLAllowed() virtual methods from content::ContentBrowserClient. Embedder applications overriding these methods must remove them to avoid compilation errors. (e8edeb7)
    BrowserStorage
  • Added the WebRtcRecording public interface under content/public/browser/webrtc_recording.h to cleanly manage WebRTC diagnostic data, origin filters, and event streams per BrowserContext. (da48209)
    BrowserWebRTC

Security, Sandbox & Extensions

  • Restricted extensions using chrome.debugger from attaching to or enumerating privileged WebContents such as internal WebUI side panels. (3f9b7ce)
    ExtensionsSecurity
  • Guarded VM buffer address access during process shutdown in Mojo's ChannelMac to prevent EXC_BAD_ACCESS during event loop teardown on macOS. (e8736f9)
    BasemacOSSecurity
  • Capped key derivation cycles per encrypted archive in the sandboxed UnRAR analyzer to protect against CPU exhaustion attacks. (09845d8)
    Security

Browser UI, Window Management & Performance

  • Introduced kDeferLayoutDuringBrowserStartup to skip redundant BrowserView layout passes while windows are invisible during startup, measurably reducing First Paint latency on Windows and macOS. (d7e2365)
    BrowserPerformanceUI
  • Updated ui::Shadow and gfx::ShadowDetails to accept gfx::RoundedCornersF for asymmetric and pill-shaped nine-patch shadow layers. (69e443b)
    UI
  • Restricted NSGlassEffectView geometry strictly to top chrome regions on macOS to avoid GPU rendering overhead over main page content. (d1f9216)
    macOSUI

Build Infrastructure & Tools

  • Updated generate_v8_context_snapshot to output files to root_out_dir instead of root_build_dir, preventing Ninja output collisions during multi-toolchain builds. (1a7e758)
    BuildInfra
  • Added the src/third_party/cpython3 CIPD package to support hermetic execution of Python scripts within GN and Siso. (dea0739)
    BuildInfra
