Security & Network Architecture

  • Enhanced security checks inmojo and ipcz driver layers to strictly validate remote process eligibility based on sender and receiver privilege classifications. (d003e09)
  • Partitions PreflightCache quota and eviction logic strictly by top-frame site using an outer LRUCache to prevent cross-partition eviction oracles. (188fdac)
  • Removed the Intervention HTTP request header from the CORS-safelisted request headers list, forcing outgoing requests with this header to trigger preflight checks. (9eddf1b)
  • Implemented strict syntactical validation on Isolated Web App update manifest sources and propagated IP address spaces to prevent Local Network Access SSRF bypasses. (9da45f8)

Browser UI & Core Features

  • Continued the architectural migration of detaching profile-level tab helpers from TabHelpers::AttachTabHelpers into dedicated TabFeatures components. (f1be4a0) (ef1ab9e) (6ae5242)
  • Fully extracted all remaining source files out of the legacy chrome/browser/ui:ui build target into dedicated, granular source sets and locked down the target. (01fce4e) (92988b3)

Extensions & APIs

  • Added an experimental DevTools Protocol command Page.getSpellCheckCustomDictionary to inspect custom spelling dictionary entries. (2e2393b)

Infrastructure, Performance & Installer

  • Introduced the ANGLETrimMemoryOnIdle finch feature flag to invoke glTrimMemoryANGLE on inactive WebGL contexts to reduce idle foreground memory consumption. (ddf3c65)
