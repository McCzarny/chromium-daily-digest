Overview

This digest analyzes 28 commits ranging from (a996837) to (7e018a5), focusing on 6 desktop-relevant changes in core public APIs, extension framework events, and desktop windowing safety.

Public APIs & Embedder Interfaces

  • ⚠️Added a required GlobalRenderFrameHostId requesting_frame_id parameter to ServiceWorkerContext::RegisterServiceWorker and PaymentAppProvider::InstallAndInvokePaymentApp to enforce Connection-Allowlist checks. Embedders calling RegisterServiceWorker directly on content::ServiceWorkerContext must update their calls. (95a6d23)

Extensions Framework

  • Delayed dispatch of the chrome.sidePanel.onOpened extension event until ExtensionHost::has_loaded_once() returns true, ensuring chrome.runtime.getContexts() reliably discovers newly opened side panel contexts without race conditions. (876099a)
  • Added renderer completion signaling via webRequestInternal.eventHandlingDone for per-context webRequest blocking dispatches, allowing the browser to apply aggregated modifications and unblock network requests once all listeners complete. (8532729)

Desktop UI & Windowing

  • Added string resource IDS_LENS_COBROWSE_CURRENT_TAB_IPH_DESCRIPTION to support Lens cobrowse In-Product Help prompts in the Omnibox. (103f420)
