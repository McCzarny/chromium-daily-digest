Chromium Digest: 2026-11-18

Overview

1,271 commits landed on main on 2026-11-18, of which roughly 1,016 are relevant to embedders building Chromium-based projects on Windows and macOS (Blink rendering internals, ChromeOS/Ash, Linux, iOS and Android-only work excluded). The day is defined by a cluster of **breaking API removals** across resource packaging, Blink embedder interfaces, content/public, views and the file system access factory, alongside substantial networking/security hardening (Negotiate target-host validation, GPU context-confusion fixes) and a large macOS bookmark-menu performance win. Range: (f3b7097) → (6af779c).

Breaking API Changes

  • ⚠️Resource packaging defaults to zstd: GRIT now compresses .js/.html/.css/.svg/.json and .code_cache with zstd, ui::ResourceBundle::IsGzipped()/IsBrotli() are deleted in favour of IsCompressed(), and the extensions source-map path loads through LoadDataResourceString(). Custom .pak pipelines and embedders calling the removed ui/base APIs must migrate; the related Brotli code-cache pass shrinks bundled resources by ~15.6%. (4a89327) (3f2c376)
    BaseBuild
  • ⚠️Blink embedder interface removals: WebView::PageEncoding(), WebLocalFrameClient::SetUpSharedMemoryForDroppedFrames(), RenderFrameObserver::DetailedConsoleMessageAdded() and WebLocalFrameClient::DidAddMessageToConsole() are gone (console reporting now flows through WebLocalFrameObserver/blink::Platform), and FrameHost::UpdateEncoding moved to blink.mojom.LocalMainFrameHost, so encoding updates originate in Blink. Out-of-tree embedders and custom IPC mocks no longer compile. (e1489bc) (5781c29) (716ea16)
    BlinkBrowser
  • ⚠️content/public and scheme-registry lock: BrowserThread::PostBestEffortTask() is removed outright (use ThreadPool::PostTask with TaskPriority::BEST_EFFORT plus BindPostTask), and the new WebSecurityPolicy::LockSchemeRegistries() hard-locks custom scheme registration after RenderThreadStarted() — a DCHECK in debug but a silent no-op in release, so late RegisterURLScheme* calls just stop working. (94a7b45) (4e6d72e)
    BaseSecurityBlink
  • ⚠️url::SchemeHostPort/url::Origin reject empty hosts: non-file: standard schemes with an empty host are now invalid, GetURL() enforces the invariant, and Mojo Origin deserialization fails for tuples such as ("chrome", "", 0). Embedders registering custom standard schemes or inflating such origins receive invalid values or a CHECK crash instead of a round-trippable origin. (73392c2)
    NetworkSecurity
  • ⚠️File System Access entry-factory signature change: FileSystemAccessEntryFactory::CreateFileEntryFromPath() gains a required SensitiveEntryReadCheck, and SharedHandleState gains an optional read_blocklist_exempt_path. This restores Windows PWA file_handlers launches and drag-and-drop of files staged in %LOCALAPPDATA%\Temp; deserialized handles are now also checked against the sensitive-entry blocklist. (ea88bf4) (975ab82)
    StorageSecurityWindows
  • ⚠️Branded search-provider overrides removed: switches::kIgnoreSearchProviderOverrides, TemplateURLPrepopulateData::GetOverriddenTemplateURLData(), ClearPrepopulatedEnginesInPrefs() and BrandcodedDefaultSettings::GetSearchProviderOverrides() are deleted, and DefaultSearchManager no longer observes prefs::kSearchProviderOverrides. Builds shipping a default engine via search_provider_overrides silently stop applying it and must move to kDefaultSearchProviderData or policy. (587dacd)
    BrowserProfiles
  • ⚠️views::FocusManager::ViewRemoved() takes the new parent: the signature becomes ViewRemoved(View*, View* new_parent) with no default argument, alongside the new views::kRetainsFocusWhenReparented property; removing a subtree now notifies the focus manager once per subtree rather than once per descendant. Callers such as NativeViewHost::ClearFocus() must pass the parameter, and focus-observer timing changes for reparented views. (18cfccd)
    UIBrowser

Security & Networking

  • Negotiate/GSSAPI target-host validation: the DNS canonical name substituted for the SPN is now re-checked against HttpAuthPreferences allowlists before and after the handshake (kValidateNegotiateCnameAllowlist, kValidateNegotiateTargetPrincipalHost), so ambient credentials or delegation tickets cannot go to an unrequested host, including via PTR lookups. AuthServerAllowlist, AuthNegotiateDelegateAllowlist and DisableAuthNegotiateCnameLookup now document canonical-host requirements — CNAME-based SPNs with non-canonical allowlist entries may start failing. (461e753) (16cfb97)
    NetworkEnterpriseSecurity
  • GPU context-confusion and device-loss hardening: OzoneImageBacking now uses ScopedMakeCurrent before UploadFromMemory/ReadbackToMemory (previously Skia could import a NativePixmap onto the wrong GLContext during overlay fallback copies), D3D shared images promote cleared state after EndAccess(), failed writePixels flushes its discard-clear, Dawn representations tolerate device loss, and a lost Dawn context restarts the GPU process rather than leaving commands running against stale memory. (f1831b8) (51ef3bb) (0fb2fd2) (d03ec5f)
    GPUSecuritymacOS
  • Renderer trust-boundary fixes: worker StorageKey origins are verified against the script URL (blocking cross-origin ServiceWorker registration promotion via WithOrigin()), SharedWorkerConnectorImpl is document-scoped so teardown can't resolve against a new document, renderer-supplied popup bounds are clamped to 16384 DIP, and WebNN's ORT embed_mode must be explicitly 1 to prevent GPU-process file reads. (d031101) (bba4565) (811be3d) (de3207d)
    SecurityNetworkGPU

Performance

  • macOS bookmark menu performance: behind kBookmarkMenuOptimizations, titles are elided once per item, the default favicon NSImage is reused, favicon callbacks update only the icon, and teardown stops starting new favicon loads. On an Apple Silicon VM with 210K bookmarks: menu open 61.7s → 24.2s (favicon drain 20.2s → 1.6s) and profile teardown 41.8s → 20.1s. (aaa43d2) (ac50863)
    macOSPerformanceBookmarks
  • Pref-load and autofill hot paths: PrefHashFilter::FinalizeFilterOnLoad() no longer deep-copies the whole PrefService store twice on the UI thread (250KB Preferences: 1.9ms → 0.7ms with extensions, 0.39ms → 0.02ms without), and AutofillProfileComparator switches from std::set to base::flat_set to drop per-token allocations. (afffda7) (67e05d0)
    PerformanceAutofillPrivacy
