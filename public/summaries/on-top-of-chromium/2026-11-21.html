Chromium Digest: 2026-11-21

Overview

On 2026-11-21, 382 commits landed on the main branch, of which 166 were relevant to Chromium embedders and web developers working on Windows and macOS. The day mixed hard public-API removals in //base, cookie privacy enforcement, Bluetooth serial permission hardening, enterprise proxy error redirection, macOS omnibox fixes, and WebNN/WebAuthn plumbing. First commit: (14f4be7); last commit: (59b4060).

Breaking API Changes

  • ⚠️base::MemoryPressureListener, MemoryPressureListenerRegistry, MockMemoryPressureListener, RegisteredMockMemoryPressureListener, and the whole base/memory/memory_pressure_listener*.h/.cc header set are deleted from the base component (~962 deletions across 18 files). This is a hard removal, not a deprecation — any embedder including the header or overriding OnMemoryPressure(MemoryPressureLevel) stops compiling and must migrate to base::MemoryConsumer. (99e76b6)
    Base
  • ⚠️base::i18n::CreateTransliteratorFromRules(id, rules) is removed now that callers use CreateTransliterator() with pre-baked und-t-und-x0-* BCP-47-T IDs. transliterator.{h,cc} are additionally moved behind !is_cronet_build in base/BUILD.gn. Same CL fixes an LSan leak, cxx FFI out-of-bounds reads via StringViewToRustSlice/RustStrToStringView, and inverted Hira-Kana/Kana-Hira aliases. (6e04465)
    BaseI18n
  • ⚠️CookieSettingsBase::GetStorageAccessStatus() gains a mandatory bool is_storage_access_potentially_allowed parameter (no default), propagated through URLLoaderFactoryParams, TrustedUrlRequestParams, CorsURLLoaderFactory, CorsURLLoader, and NetworkContext::GetRestrictedCookieManager(). Behavior is unchanged today (all in-tree callers pass true, enforcement is flag-gated), but out-of-tree callers and overriders must update. (ca0280d)
    NetworkPrivacy

Security & Privacy

  • Clear-on-exit now also deletes partitioned cookies when their partition's top-level site is session-only, closing a real privacy leak where a third-party cookie from an allowed domain embedded on a session-only site survived restart. net::SQLitePersistentCookieStore::DeleteAllInList gains a top_frame_site_keys parameter (empty keys never match, so unpartitioned cookies are untouched), and CookieManager::DeleteSessionOnlyCookies applies the same predicate on startup. Gated by network::features::kClearPartitionedCookiesOnExitByTopLevelSite, enabled by default (kill switch available). (cfd48e2)
    NetworkPrivacyStorage
  • Bluetooth permission hardening: Web Serial now stores and verifies the canonical 128-bit service class UUID so a persistent Bluetooth serial grant scoped to a MAC address no longer grants access to all services on that device (legacy grants are intentionally invalidated and must be re-granted). WebBluetoothServiceImpl::RequestScanningStart() was missing the GetBluetoothAllowed() gate and now returns early before any prompt. Separately, the dangerous should_unbond_on_error flag is dropped from ConnectToServiceInsecurely / adapter.mojom, so a failed RFCOMM connect can no longer unbond a paired keyboard, mouse, or headset. (5c7518a) (b5d347e) (53964c8)
    BluetoothSecurityPrivacy
  • Reader Mode / web-distiller Mojo hardening: BindDistillerJavaScriptService now requires no outer document, a committed origin scheme of chrome-distiller://, and a committed URL scheme of chrome-distiller:// (primary-frame violations get ReportBadMessage), the service is re-scoped to the document lifetime via content::DocumentService, and kMinFontScale is raised 0.4 → 0.5 with non-finite/out-of-range scales rejected end-to-end. (64a9d6c)
    SecurityBrowserPrivacy
  • Site isolation: unassigned SiteInstances no longer inherit initiator origins. Empty document schemes other than about: (e.g. chrome-native:) that never assign a site now get an opaque origin with no precursor, plus a CHECK that nothing committed in an unassigned SiteInstance carries one — a step toward disallowing committed origins in unused ProcessLocks. (89fa0a4)
    SecurityNavigation
  • Hybrid post-quantum variations seed signing: pins three ECDSA P-256 + ML-DSA-44 keys, advertises them via a new X-Seed-Key-Ids request header, reuses X-Seed-Signature with a <key_id>:<base64> prefix, verifies via BoringSSL, and on the first valid new-key seed sets variations_legacy_seed_key_distrusted in Local State to reject subsequent legacy-only seeds. Legacy signatures remain accepted during transition, so no embedder action is required today. (a00ee1e)
    NetworkSecurityCrypto

Networking & Enterprise

  • Enterprise 407 url= static error-page redirect: primary main-frame navigations hitting a disguised-error 407 from a configured HTTPS enterprise proxy now redirect to the challenge's validated https:// url= param via a clean browser-initiated GET (empty Referrer, no POST body, opaque initiator → Sec-Fetch-Site: cross-site, SameSite=Strict cookies withheld, Back history preserved). Hardened with strict RFC token validation, duplicate param/header rejection, HTTPS-only enforcement, and a one-hop loop cap. Gated by enable_static_error_page_redirect on EnterpriseProxyErrorHandling. (cb20f3e)
    EnterpriseNetworkSecurity
  • ResourceRequest gains an optional content_user_agent field (mojom traits, EqualsForTesting, PrefetchMatches) used by the network service only when no explicit UA header is present; CORS preflights take the UA from this field when kAllowUserAgentHeaderFromScript is on. CorsURLLoaderFactory::IsValidRequest() rejects the field with ReportBadMessage while the feature is off and truncates to 512 bytes with a NetworkService.ContentUserAgentSize histogram. Feature disabled by default and nothing sets the field yet, so zero behavior change. (13a1f52)
    Network
  • WebTransport: a peer closing with WT_CLOSE_SESSION + FIN that also STOP_SENDINGs the CONNECT stream now signals a clean close without requiring both FINs, so the session no longer transitions to FAILED via OnConnectStreamAborted() before OnSessionClosed() can reach CLOSED. Covers both frame orders and the symmetric peer-reset case. (6437a2a)
    Network

Browser UI & UX

  • macOS: the Full WebUI omnibox popup reshow is now deferred until the host window is on-screen. Previously, reopening the popup for an unfocused fullscreen draft while the window sat on another Space rendered it over an unrelated window. ReshowPopup() queries its host, and OmniboxPopupFullPresenter defers and reopens on return (workaround removable once crbug.com/588536651 is fixed). (1288653)
    macOSUI
  • Browser::OnActiveTabChanged() now populates active global infobars before BrowserWindow::OnActiveTabChanged() swaps InfoBarContainer's manager, eliminating the 0px container collapse and the second WebContents reflow that previously happened on every tab switch. ShowGlobally() activation order now uses a FIFO vector instead of sorting by InfoBarIdentifier. (dd9b015)
    UITabsPerformance
  • The Trusted Types Checker (TTC) overlay now prompts for a Gemini API key after the built-in default key was removed from internal resources: it adds InitializationState.NEEDS_API_KEY with an inline password input, persists the key in window.localStorage under ttc_gemini_api_key on chrome-untrusted://ai-overlay-dialog, and supports Retry / Change-API-key recovery from invalid keys. Auth precedence is CLI loadTimeData → saved WebUI key → bundle apiConfig.apiKey. (2b942fa) (d781f64)
    AIUI
  • Contextual Tasks / Glic wiring: voice queries now upload context when an audio stream is active or recently active (interaction timestamp and audio capture token are both consumed on submit to prevent double-reads), CommandAiModeUnshare is gated on the rearchitected side panel, Glic provider-switch notices drop from all hosts when the provider pref clears, GlicInactiveSidePanelUi::OnViewFocused posts activation with a weak pointer instead of destroying the observed view mid-dispatch, and Glic auto-submit moved into LaunchpadService. Side-panel WebContents now start initially_hidden so background rebuilds can't hijack the active task's ChipController. (1bb228f) (2b2da10) (296a5f8) (62d020a) (4103823)
    AIUITabs

Platform, Performance & Graphics

  • ClientSharedImage sync tokens are split into a single write_sync_token_ plus a per-sequence read_sync_token_map_: read-only accesses wait only on the write token and record their completion there instead of serializing behind prior reads. ExportedSharedImage mojom changes managed_sync_tokens → write_sync_token + read_sync_tokens (duplicate-client-ID validation retained per read token), and SharedImageTexture waits on creation_sync_token() directly. (0c43af3)
    GPUCompositorPerformance
  • WebNN: the WebNNContextProviderImpl worker moves to a dedicated base::Thread configured with gpu::CreateGpuSequenceManagerSettings() (required for gpu::Scheduler task queues that ThreadPool runners can't provide), and the kWebNNCompilerProcess default flips false → true on Windows with minimum WinAppRuntime 2.7.0. --webnn-ort-logging-level at INFO/VERBOSE now sets NPU.LOG_LEVEL=LOG_INFO inside the OpenVINO EP only. (565e7b7) (f6c3c2d) (a26856b) (66f5ef3)
    AIGPUWindows
  • WebAuthn GPM wiring: new GpmBrowserAuthenticatorDiscovery / GpmBrowserAuthenticatorController pull security-domain secrets from TrustedVaultClient, query TrustedVaultConnection for registration state, drive the AuthenticatorRequestDialogModel steps, and persist new passkeys to PasskeyModel. The follow-up moves EnclaveAuthenticatorDiscovery construction into ConfigureGpm(), deletes the consider_enclave flag and enclave EventStream plumbing, and attaches additional_discoveries unconditionally so embedder discoveries survive kInternal erasure on Windows. (9a48d09) (6fe241f)
    PasswordManagerSecurity
  • Windows USB: UsbDeviceHandleWin::Request now owns the transfer buffer for the operation's full lifetime and hands it back through StartWatchingCallback. Previously GenericTransfer passed and moved the buffer in the same MaybeStartWatching() call, and unspecified argument evaluation order could move it first — leaving Request::buffer_ unset while overlapped I/O was in flight. (baf0de3)
    USBWindows
  • Remoting hardening: HostEventDispatcher enforces kMaxEventMessageSizeBytes = 4096 (oversized event messages dropped without parsing, logged at most once per 10 s; messages with no InputStub dropped in release). WorkerProcessLauncher no longer schedules relaunch when auto_relaunch is false, duplicate associated-interface binds early-return after process crash handling, and the new Windows IoCompletionPortDrainer replaces a posted-task drain that could free Core while kernel job packets still referenced it. (22d0fcd) (2f8d1c8) (f53b183) (370d8a0)
    WindowsNetworkSecurity

Extensions, Data Models & Tooling

  • ExtensionSettings policy can now block on internal permissions via an allowlist mapping internal permissions to manifest keys (searchProvider, homepage, startupPages for chrome_settings_overrides, newTabPageOverride for chrome_url_overrides). A blocked permission prevents install and disables already-installed extensions. Backward compatible: other internal permissions remain ignored, manifests still cannot request internal permissions, and SettingsOverrideAPIPermission::FromValue now accepts valueless entries. (4ae4f73)
    ExtensionsPolicy
  • Extensions menu: a new kPrefPermissionsWithheldOnInstall / WerePermissionsWithheldOnInstall() pref is set at initial install when WITHHOLD_PERMISSIONS is present and persists across updates, ignoring post-install manual site-access changes.     ExtensionsUI

On-disk format stays v7-compatible. (ef9d99c)
    BrowserStorage
