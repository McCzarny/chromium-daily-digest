Chromium Digest: 2026-11-13

Overview

On 2026-11-13, 1,123 commits landed on the Chromium main branch, of which roughly 889 were relevant to embedders and web developers working on Chromium-based projects. The day was dominated by three genuinely breaking changes to stable exported interfaces (DragSourceEndedAt, ApplicationLocaleStorage, and cc::TextureBacking/PaintImage), a cluster of high-impact security fixes (Connection-Allowlist bypass, clipboard policy bypass, WebOTP Permissions Policy enforcement, lookalike-interstitial under-triggering, a WebAuthn UAF), QUIC/alt-svc retuning, and continued Omnibox/Unified Tabstrip work. First commit: (ff58f9e); last commit: (076899f).

Breaking Changes & Public APIs

  • ⚠️BREAKING: content::RenderWidgetHost::DragSourceEndedAt() and content::WebContentsImpl::DragSourceEndedAt() now take const std::optional<gfx::PointF>& client/screen points instead of four floats / two points; widget.mojom's DragSourceEndedAt message and all Blink/Aura/Mac call sites were migrated. Out-of-tree overrides, callers, and mojom consumers must be rewritten; points must be both set or both omitted (CHECK_EQ enforces this). When a drag is rejected before a system drag session starts, coordinates are omitted so screen coordinates no longer leak to the renderer. (fc7461e)
    BrowserUI
  • ⚠️BREAKING: ApplicationLocaleStorage::Get(LocaleFormat)/Set(std::string), the public enum class LocaleFormat, and the cached tag_string_ are removed outright. Callers must migrate to GetTag()/SetTag(base::i18n::LanguageTag); there is no shim. This is a reland that already forced a downstream iOS migration, so any embedder reading the app locale as a raw string or requesting BCP47 formatting will fail to build. (92f0395)
    I18nBase
  • ⚠️BREAKING: cc::TextureBacking::readPixels() is now a pure virtual taking SkPixmap (previously SkImageInfo + raw buffer + row bytes + source origin), and cc::PaintImage::readPixels() is consolidated onto the same shape. Every out-of-tree TextureBacking subclass (e.g. mirrors of MailboxTextureBacking/VideoTextureBacking) must be rewritten; the reinterpret_as_srgb_ path now mutates a local SkPixmap copy. (2d7901a)
    CompositorGPU
  • Chrome-layer API removals requiring migration: TabStripModel::SetTabNeedsAttention() and TabChangeType::kAttentionOnly are deleted — callers must use TabUIHelper::From(tab)->SetNeedsAttention(), and TabDataObserver::OnTabUIChange() now always reports kAll. Also content::WebContents gains a new pure virtual ShouldIgnoreUnresponsiveRenderer(), so out-of-tree WebContents subclasses/mocks need an override. (7cabae4) (baf42d7)

Security & Privacy

  • Connection-Allowlist bypass fixed: ClearNetworkRestrictions() erased a document's network_restrictions_id while a retained/cloned CorsURLLoaderFactory for that ID was still alive, and a missing ID means *unrestricted* — so subsequent requests and redirects escaped allowlist checks. NetworkContext now tracks live factories per ID and defers erase until the last one dies. (07baaf8)
    NetworkSecurity
  • Renderer no longer trusted for policy/permission decisions: ContentClipboardHostImpl::WriteBookmark() now runs IsClipboardCopyAllowedByPolicy() like every other Write*() handler (previously arbitrary URL+title could reach the OS clipboard regardless of enterprise Data Controls), and BindWebOTPService() now enforces the otp-credentials Permissions Policy in the browser, terminating the renderer with a new bad-message reason when disallowed. (6147d2f) (641160e)
    SecurityPrivacy
  • Lookalike interstitial under-triggering fixed on two independent axes: the action type is now computed per-URL rather than from the first hop gating the final URL, and domain-candidate matching is ranked by GetActionForMatchType() severity instead of returning the first heuristic hit (a weak eTLD+1 skeleton match could previously shadow a target-embedding match). Expect a measurable *increase* in interstitials and UKM/histogram discontinuities at landing. (50536ee) (974fb6b)
    SecurityNavigation
  • WebAuthn CTAP2 use-after-free in FidoHidDevice::Transition(): synchronous error callbacks (hairpinned into Ctap2DeviceOperation::Start() before token_ was assigned) could destroy the owning FidoTask and leave a dangling write. Error callbacks now post asynchronously. Remotely-influenced device I/O, so this is a real security fix. (517732d)
    SecurityBluetooth
  • Sandboxed-context data leaks closed: the CacheStorageSideDataWriter pipe is no longer handed to workers with opaque StorageKeys (nested workers of CSP-sandboxed workers no longer inherit the precursor origin), and BFCache now evicts the page when a dedicated worker is created after the frame went inactive instead of starting an unpaused worker (new kCreateDedicatedWorker disallow-activation reason). (7f00dca) (cad1925)
    SecurityServiceWorker

Networking

  • QUIC retry semantics change on all platforms: kInitialDelayForBrokenAlternativeService (10s) and kMaxDelayForBrokenAlternativeService (30m) are now on by default for non-Cronet builds, so a transient failure no longer parks QUIC for 300s/2 days. Separately, QuicHttpStream::IsConnectionReused() now caches whether a session ever created streams and treats preconnected sessions as reused, so HttpNetworkTransaction correctly retries ERR_CONNECTION_CLOSED when a pooled session dies before InitializeStream(). (6fcb0b3) (4ce6260)
    Network
  • Legacy (pre-M55) push subscriptions forced onto InstanceID in PushMessagingServiceImpl: legacy app_id registrations without an InstanceID token are now invalidated (removed, getSubscription() returns null), unsubscribe drops legacy encryption keys, and Chrome stops sending the legacy GCM unregister request so old server-side registrations linger. Desktop-visible behavior change for anyone with very old push registrations. (f717ea8)
    NetworkNotifications
  • Randomized DNS job capacity: net::PrioritizedDispatcher gains Limits::additional_capacity and a SocketPoolExpandability state machine, TryAcquireSlot() replaces direct slot checks, and HostResolverManager supplies capacity whenever no HostResolverDispatch field-trial group is set — randomizing effective DNS concurrency above the soft cap (anti cross-site probing). PrioritizedDispatcher is NET_EXPORT_PRIVATE, but forks calling SetLimits() must not set the new field alongside reserved slots. (dfb549a)
    Network
  • Prototype surface teardown / signature change in base: the Reduce Accept-Language prototype is fully deleted — avail_language/content_language removed from network::mojom::ParsedHeaders, and the exported kReduceAcceptLanguage{,HTTP} feature symbols and CONTENT_EXPORT switches removed. base::ContainsEncodedBytes() in base/strings/escape.h now takes span<const unsigned char> instead of const std::set<unsigned char>&; out-of-tree callers must update. (d2f299e) (ee66e23) (08d91cd)
    NetworkBase
  • ServiceWorker synthetic responses corrected: a new capture_intercepted_headers param (default false) interposes a pass-through URLLoaderClient so eligible 2xx headers are cached even when every navigation hits an embedder preload handler; and registration lookup no longer creates synthetic registrations before consulting storage, so real workers with no/empty fetch handlers again bypass loader creation and keep embedder preload interception.
