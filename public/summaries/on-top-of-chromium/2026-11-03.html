Chromium Digest: 2026-11-03

Overview

Chromium main branch activity for 2026-11-03: 1,144 commits landed, of which 877 were filtered as relevant to browser, extensions, network, security, performance and API work. The day's span runs from cb6b5d6f304d0102292271fb9a326200404063ee to db957e720f2ce6cb9ce71239e463f109feaa0bfa. The most consequential items are three true breaking changes (media copy_required removal, RunOrPostTask becoming opt-in, and WebSettings font-family setters collapsing into one enum-based API), a batch of Windows enterprise policy/trust fixes, and continued migration of chrome/browser/ui/tabs features off TabFeatures accessors onto UnownedUserData.

Breaking Changes & Public APIs

  • ⚠️Breaking: media::VideoFrameMetadata::copy_required is removed (including merge and mojom serialization), along with the media::kUseSharedImageUsageForVideoFrameCopy killswitch. Copy decisions now derive solely from SharedImageUsageSet containing SHARED_IMAGE_USAGE_DISPLAY_READ. Secondary signature changes: VideoFrameFactoryImpl drops its gpu::GpuPreferences ctor parameter and CreateVideoFrame_OnImageReady() drops bool video_frame_copy_required. (2970dc0)
    MediaGPU
  • ⚠️Breaking behavior: SequencedTaskRunner::RunOrPostTask() no longer runs tasks synchronously on an idle bound thread unless the SequenceManager is explicitly configured with Settings::Builder::SetCanRunTasksSynchronously(true) (default is now false); when enabled, a nested RunLoop outside a task now CHECKs. A companion fix uses release/acquire ordering between PostImmediateTaskImpl and ReloadEmptyWorkQueues so RunOrPostTask can't jump ahead of posted tasks. (ac3dcbe) (89ff75a)
    BasePerformance
  • ⚠️Breaking: the seven public WebSettings font-family setters (SetStandardFontFamily, SetFixedFontFamily, SetSerifFontFamily, SetSansSerifFontFamily, SetCursiveFontFamily, SetFantasyFontFamily, SetMathFontFamily) are removed and replaced by SetGenericFontFamily(GenericFontFamily, ...); GenericFontFamilySettings accessors change from Standard()/UpdateStandard() to Get()/Update(). Any embedder implementing or calling WebSettings must update. (9cbb3a4)
    BlinkFonts
  • services/cert_verifier/public/mojom collapses UpdateChromeRootStore, UpdateKeyPinsList and DisableCtEnforcement into a single UpdatePKIMetadata call (with a network_service_only mode) driven by one background read of the PKIMetadata component. In-tree callers are migrated, but anything calling the removed methods directly must move to the new entry point. (d882dac)
    NetworkSSLSecurity

Security, Enterprise & Policy

  • Windows management trustworthiness work: platform policies are reloaded when cached device-management trustworthiness changes (previously sensitive policies stayed blocked for up to 15 minutes after an Entra/AAD join), and a new synchronous blocking getter (base::AssertBlockingAllowed()) is used for the initial policy load so sensitive policies aren't wrongly blocked on first run. In the same area, WebView2-based updater UI is disabled inside elevated processes, falling back to native UI. (5ce54bf) (cc7c2b7) (861dd67)
    WindowsPolicyUpdater
  • enterprise_net::IsDeviceManaged() now treats EMM/platform-managed devices (trusted PlatformManagementService) as managed even without CBCM affiliation IDs. Consequence: user-scoped ProxyOverrideRules/ProxyProvisioningDomains are ignored by default on those devices unless the machine-scoped EnableProxyOverrideRulesForAllUsers is set — deployments relying on the old permissive path must flip the machine policy. (0afdd89)
    EnterprisePolicyNetwork
  • InsecureFormNavigationThrottle now also compares query parameters when a mixed-form GET submission redirects, closing a data-leak vector in the mixed-content form path. No API surface change. (1ebc768)
    SecurityNetworkNavigation
  • crypto::ProcessBound no longer leaves plaintext on the heap: buffers are reserved before resize and explicitly zeroed via SecureZeroBuffer in the destructor, copy and move paths. Caller signatures are unchanged. (0eb4bd8) (edec62a)
    CryptoSecurity
