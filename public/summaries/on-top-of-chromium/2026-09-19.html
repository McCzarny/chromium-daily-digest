Chromium Digest: 2026-09-19

Overview

A total of 61 commits were analyzed across the codebase, with changes focused on Desktop platforms (Windows and macOS). The commits include security hardening for extension script execution, desktop browser UI cleanups, session management crash fixes, D3D12 media encoding extensions on Windows, and stability improvements across GPU framebuffers and Omnibox components. Key commits range from (5007f59) to (fe3b691).

Security & Permissions

  • Prevented extension script injection execution on prerendered non-primary main frames when extension host permissions are withheld. (65257bf)
  • Integrated views::InputEventActivationProtector into the extensions menu site access toggle to prevent accidental clicks during page transitions and layout shifts. (973f483)
  • Marked navigations initiated from the HaTS survey dialog as renderer-initiated with precursorless opaque origins to avoid bypassing navigation security throttles. (efabd3f)
  • Fixed initiator parameter propagation in WebViewGuest::OpenURLFromTab so guest-view navigations retain accurate initiator context. (c771845)
  • Prevented marking GPU framebuffer attachments as cleared when lazy clear fails under VRAM pressure, preventing potential cross-origin memory disclosure. (cb7ce88)

Browser UI & Window Management

  • Added keyboard support (Shift + Arrow keys) to sequentially extend tab range selections in TabStrip for both horizontal and vertical modes. (f9d707a)
  • Refactored LocationBar access to route directly through BrowserWindow::FromBrowser() and removed intermediate accessor shims from BrowserWindowFeatures. (97ad96a) (cc4d224) (9a1eb9b)
  • Eliminated visual flicker during transitions between the AIM popup and Full WebUI Omnibox popup, and preserved user input and selection states across focus transitions. (86394bc) (f2cb9f8) (53a4063) (49c0536)
  • Fixed a transient white flash during macOS glass-frame window deactivation by synchronizing glass view destruction with compositor frame presentation. (c26ffbe)
  • Linked App Menu zoom controls and default browser actions to Action Item states, and added sync preferences for auto-pinning toolbar actions. (09db4c4) (161aa50) (4c92a73)

Media, Graphics & GPU

  • Added support for HEVC range extension formats (4:2:2 and 4:4:4 profiles) to the Windows D3D12 hardware video encoder and added dynamic video processing format probing. (049dab2) (1d8b843) (b415ec5)
  • Fixed a negative-size memory underflow and heap corruption crash in cc::ListContainerHelper and Viz overlay processor by preventing duplicate occluding mask candidates. (5d3262a)

Sessions & State Management

  • Deferred encrypted session writes until OSCryptAsync is ready, eliminating session command deduplication bugs and commands_since_reset_ invariant crashes. (6bb217d)
  • Updated session restore logic to track and restore closed tabs to their original index within saved tab groups. (18efd0a)

Autofill & Passwords

  • Clamped password manager form field bounding boxes to the local root coordinate system to prevent cross-origin mis-anchoring of popups. (e74b6ee)
  • Refined Save and Fill dialog UX to show validation errors only when an input loses focus, made CVC fields mandatory, and enforced HTTPS URLs for password sharing recipients. (73111ac) (7f5a1bf)

Developer Tools, Mojo & Core Infrastructure

  • Unified ChromeDriver asynchronous script timeouts around the DevTools deadline clock and ensured qualified DOM tag names are built with prefixes per WebDriver specification. (a8a5468) (852d53b)
  • Added Mojo C++ helper functions and constructors to support bi-directional Message passing and handle ownership transfer with Rust bindings. (ecef6b0)
  • Decoupled CBOR dependencies from //crypto into a separate cose source set to reduce compilation dependencies on the build critical path. (5f117d4)
  • Introduced DecorationSpec and DecorationGenerator C++20 concepts into ui/decoration to enforce compile-time equality and ordering requirements. (f93ba6f) (78a9a52)
