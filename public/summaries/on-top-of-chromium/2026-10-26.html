Chromium Digest: 2026-10-26

Overview

On 2026-10-26, **783 commits** landed on the Chromium main branch, of which **633** were relevant to embedders and web developers (first: (6f11890), last: (8b4e206)). Four confirmed breaking changes remove or restructure public content/ and media/ API surface (WebContentsDelegate::GetAIPageContent(), content::ProvisionFetcherImpl, media::AudioBuffer planar accessors, and a new pure virtual on AudioOutputDispatcher), so out-of-tree embedders will need compile-time updates. The rest of the day was dominated by browser-process crash/UAF hardening, WebUI omnibox focus fixes, DNS/QUIC and 1xx response correctness work in net/, several measurable base-layer performance wins, and build/infra changes that affect downstream GN consumers.

Breaking API Changes

  • ⚠️content::WebContentsDelegate::GetAIPageContent() is removed from the public content API, along with all overrides in BrowserWebContentsDelegate, TabWebContentsDelegateAndroid and headless. Embedders that override or call this virtual will fail to compile; Page.getAnnotatedPageContent is now served from embedder-side DevTools PageHandlers (Chrome's Android PageHandler is now always built, including for untrusted clients, while Page.printToPDF remains trusted-only). (17d4573)
    DevToolsBrowserAI
  • ⚠️content/public/browser/provision_fetcher_impl.h/.cc and the exported content::ProvisionFetcherImpl class are removed from the public API and moved to content/browser/media/. Embedders including the public header or instantiating the class lose that API entirely; provision_fetcher_factory.h remains public. (a9235b4)
    MediaBrowser
  • ⚠️media::AudioBuffer::channel_data() and channels() (plus PopulateChannelData() and the backing member) are deleted from the MEDIA_EXPORT header after a deprecation period. Decoder integrations reading raw per-channel pointers must migrate to planar_data(), planar_channel(), interleaved_data() or bitstream_data(). (4558926)
    Media
  • ⚠️AudioOutputDispatcher::CloseAllIdleStreams() is now a pure virtual method and AudioManager gains a new virtual void CloseIdleStreams(); BrowserMainLoop::ShutdownThreadsAndCleanUp() now closes cached idle streams before AudioManager::Shutdown(). Any embedder subclassing these MEDIA_EXPORT interfaces must add overrides. (403b19a)

Network Stack

  • HttpNetworkTransaction behavior change: a 1xx informational response (e.g. 103 Early Hints) followed by socket close before the final response now fails with ERR_CONNECTION_CLOSED instead of surfacing a fabricated success with empty headers. Retry suppression is extended to informational responses; HasReceivedResponse() and a received_informational_response_ flag are added. (a156403)
    Network
  • DNS/QUIC correctness: DnsTaskResultsManager::UpdateEndpoints() now appends the non-SVCB fallback ServiceEndpoint whenever real addresses are available, matching HostCache::Entry::ConvertToServiceEndpoints() so intermediate results no longer delay QUIC attempts when Alt-Svc advertises h3 without an HTTPS RR. Separately, HostCache::RestoreFromListValue() skips only the malformed entry (NAK) instead of discarding the entire persisted host cache. (4257815) (06bc8d1)
