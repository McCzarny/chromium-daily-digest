Chromium Digest: 2026-07-27

Overview

This digest synthesizes Chromium development activity for July 27, 2026, across 709 total commits, with 548 commits identified as relevant to Windows and macOS embedders and browser architecture. The tracked changes range from security policy enforcement, Safe Browsing v5 integrations, and storage caching updates to browser UI refinements and build infrastructure adjustments. The work spanned from the initial commit (9521ac8) to the final commit (3040bd1).

Security & Sandbox Isolation

  • Updated ChromeContentBrowserClient::IsJitDisabledForSite() to check ChildProcessSecurityPolicy::IsWebSafeScheme() instead of restricting checks solely to http/https URLs, ensuring non-HTTP web-safe site URLs respect the JAVASCRIPT_JIT content setting. (ffb88da)
    SecurityBrowser
  • Added strict input validation for incoming Mojo IPC metadata parameters in skhdr::AdaptiveGlobalToneMap to reject corrupt or out-of-bounds HDR metadata payloads. (36e3c8b)
    SecurityGPU
  • Browser-side validation now strictly enforces allow-orientation-lock and allow-forms iframe sandbox attributes to prevent compromised renderers from bypassing checks. (259b02d)
    SecurityBlink

Storage, Caching & Networking

  • Introduced shared cache support to the SQL persistent store backend (net/disk_cache/sql), including shared_cache_resource_id fields, entry migration functions, and schema updates. (dcaf3dd) (8048cf8) (edebcea) (2f2955a) (5c50974)
    StorageNetwork
  • Implemented UDP Generic Receive Offload (GRO) processing for POSIX systems and enforced a 64KB minimum buffer size (kMinimumReadMultipleBufferSize) for ReadMultiple() datagram buffers to prevent packet truncation. (f2e5221) (8b3425b)
    Network

Browser UI & Embedder Services

  • Updated tab closure command logic in chrome/browser/ui/browser_commands.cc to present a confirmation toast when attempting to close pinned tabs when no unpinned tabs are selected. (07c59a3)
    UITabsBrowser
  • Added vram_mb to ChromeMLModelDescriptor within the on-device model service to expose VRAM capacity for performance-based fallback logic. (46cf389)
    AIPerformance
  • Cleaned up and removed Plus Address management links and associated sublabels from the Autofill settings UI. (f46c7e8)
    AutofillUI

Build Infrastructure & Tools
