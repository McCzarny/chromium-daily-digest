Chromium Digest: 2026-11-06

Overview

Chromium's main branch had 1,190 commits today, 930 relevant to embedder-facing work. The range is (d0d03a0) through (b6382b0). This digest focuses on Windows/macOS embedder APIs, networking and security, browser UI, extensions, and performance; test-only, ChromeOS/Ash, iOS/Android/Linux-only, and Blink/V8 rendering changes are largely omitted.

  • ⚠️BREAKING (Windows): the exported sandbox broker contract changed: BrokerServices::Shutdown() is now pure virtual, BrokerServicesDelegate::BeforeTargetProcessCreateOnCreationThread() was removed, CreateTarget() is static, and async SpawnTargetAsync() callbacks can be cancelled after shutdown with SBOX_ERROR_UNEXPECTED_CALL or ERROR_SHUTDOWN_IN_PROGRESS. Embedders implementing BrokerServices/BrokerServicesDelegate must update. (4fa4bb6)
    SecurityWindows
  • ⚠️BREAKING: content::ReduceAcceptLanguageUtils was removed from content/public/browser, along with navigation-time reduced Accept-Language header injection. Embedders that linked this public API or depended on stable per-navigation header reduction must update code and expectations. (abd2c99)
    NetworkNavigation
  • ⚠️BREAKING: memory-pressure delivery now goes through base::MemoryPressureSource, and MemoryPressureListenerRegistry is a subscriber to it. Embedders constructing the registry must also create and own a source; listeners registered while notifications are suppressed now start at the last simulated level rather than the real one. (90b5c33)
    BasePerformance

Security and Privacy

  • Synchronous about:blank origin checks in RenderFrameHostImpl are hardened: renderer and browser origins must now match exactly, closing opaque-origin nonce reuse and opaque-to-file: precursor escalation.     SecurityNavigation

    SecurityStorage

Performance and Stability
