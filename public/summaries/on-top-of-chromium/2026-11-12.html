Chromium Digest: 2026-11-12

Overview

Chromium's main branch received 1,223 commits on 2026-11-12, of which 943 were relevant to browser embedders after filtering out Blink/V8 page-processing work and ChromeOS/Ash, Android, iOS and Linux-only changes. The day is defined less by one big flag flip than by a cluster of public-interface removals (content, base, PerformanceManager, media) plus steady security hardening, WebUI-omnibox restructuring and measurable GPU/build speedups. Day range: (102958c) → (cbf092c).

Breaking API Changes

  • ⚠️FedCM Set-Login parsing is now synchronous. content/public/common/web_identity.h loses ParseSetLoginHeaderCallback and GetSetLoginHeaderInProcessParser(), and MaybeCreateIdentityUrlLoaderThrottle() drops its parser argument; the async deferral machinery in IdentityUrlLoaderThrottle (defer flags, parse-state, WeakPtrFactory) is gone. Any embedder supplying a blink::URLLoaderThrottleProvider (content, headless, shell) must remove the parser argument. (f52e46e)
    NetworkSecurityBrowser
  • ⚠️Renderer visibility callbacks deleted from the content API. content::RenderFrameObserver::WasShown()/WasHidden() and their blink::WebLocalFrameClient counterparts are removed in favor of blink::WebLocalFrameObserver; overrides declared with override fail to compile and overrides without it silently stop firing. Migrate to WebLocalFrameObserver and replace render_frame()->GetWebFrame() with GetWebLocalFrame(). (4ee513b)
    BrowserBlink
  • ⚠️Raw memory() accessors removed from base shared-memory mappings. ReadOnlySharedMemoryMapping::memory() and WritableSharedMemoryMapping::memory() are deleted with no deprecation window; switch to data(), GetMemoryAs<T>(), GetMemoryAsSpan<T>() or span(mapping). (90a961f)
    Base
  • ⚠️PerformanceManager PageNode timestamps replaced by state structs. GetLastVisibilityChangeTime() becomes GetVisibilityState() and GetTimeSinceLastAudibleChange() becomes GetAudibleState(); the new accessors also fix timestamps that lagged inside change observers, which mis-classified recently hidden tabs as discard-eligible. (770243c) (1dc46bd)
    PerformanceBrowser
  • ⚠️Skia YUV/color helpers removed from media/base/video_util.h. The MEDIA_EXPORTed SkColorTypeForPlane*, SkYUVAPlaneConfigForFormat() and SkYUVASubsamplingForFormat() are replaced by VideoPixelFormatSkInfo / GetSkInfoForFormat(), with a new skia::YUVBitAlignment distinguishing P010-style MSB from LSB 16-bit storage. Out-of-tree media/graphics code must migrate before rebasing. (cea52ad)
    MediaGPU

A DecodeImageFromString() adapter covers string call sites, but every embedder-provided subclass, mock or fake must update its override; Start()/StartWithOptions() gained an explicit RefCountedMemory instantiation. (f7a9540)

Security & Privacy

  • Payment handler dialogs now use the invoking frame's origin. LoadURLParams::initiator_origin was populated from the top-level WebContents, so a cross-origin iframe with allow="payment" inherited the embedder's origin and could get SameSite=Strict cookies sent back after a 301 redirect. Both desktop and Android now derive it from the RenderFrameHost that invoked PaymentRequest, behind a payments feature flag. (e7b96a1)
    PaymentsSecurityPrivacy
  • WebRTC routing preferences now apply to extension renderers. Extension pages and offscreen documents previously bypassed the media-permission gate and leaked raw local IPs in ICE candidates; they now follow the same IP/UDP-port/mDNS rules as web pages (platform apps stay exempt). Kill switch EnforceWebRtcRoutingPreferencesInExtensions, admin allowlisting via WebRtcLocalIpsAllowedUrls. (588c4ea)
    WebRTCExtensionsPrivacy
  • Autofill tightens renderer trust boundaries. DispatchAutofillEvent() could pass references to DOM elements into a cross-origin document on a DomNodeId collision; it now verifies element ownership. Separately, ContentAutofillDriver::RouteToManager() drops all browser-bound IPC from error documents (with speculative-RFH-safe classification), closing a signal-spoofing path. (254762f) (949aa12)
    AutofillSecurity
  • Renderer-supplied input validated more strictly in printing and Viz. A duplicate typeface ID with data_included=true in DeserializeOopTypeface() returned a cached typeface without consuming stream bytes, desynchronizing the Skia stream over renderer-controlled shared memory — the DCHECKs become CHECKs and the print utility process now terminates. Separately, unbounded frame sinks must use viz::kBrowserClientId, so a renderer can no longer name another client's frame sink (bad Mojo message → disconnect). (b722f1f) (967751f)
    PrintingGPUSecurity

Networking, Policy & Enterprise

  • DoH no longer applies search suffixes to multi-label names. With kDnsHttpsDontAppendToMultiLabelName (default enabled), DnsTransactionImpl bypasses DnsConfig::search expansion and ndots reordering for multi-label queries over AttemptMode::kHttp, matching Windows (append_to_multi_label_name = false, ndots = 1). Single-label names still expand; enterprise deployments relying on suffix expansion over DoH will now issue bare queries. (ca528f0)
    NetworkEnterprise
  • Global Privacy Control and DNT are now sent on browser-initiated prefetches. Sec-GPC: 1 and DNT are attached during phase-2 header preparation (PrefetchPrivacyHeaders, default enabled), with plumbing through browser_initiated_resource_request, navigation_request, prefetch_resource_request_utils, the service-worker loader and worker script fetcher. Headers now appear on requests that previously lacked them — audit any code that signs, replays or inspects prefetch traffic. (258b7cf)
    NetworkPrivacy
  • Enterprise/Windows behavior fixes. policy::GetNetworkName() now returns empty on Windows 11 24H2+ to avoid UI-thread hangs from synchronous WLAN queries, suppressing only the network-name field in SecOps device metadata; and kEnterpriseRealTimeUrlCheckUrlSkiplist is enabled by default so warmup URLs (and about:blank on Android) skip real-time URL lookups, cutting DNS errors for orgs using RT lookup. (1603168) (e52cdf8)
    PolicyEnterpriseWindows

Performance & Build

  • D3D12 command allocator pooling replaces per-frame allocator resets in D3D12VideoDecoderTask with a fence-tracked 2-allocator pool (rotating after 64 recorded frames, CPU-waiting only when both are in flight). Measured +4% to +15% decode throughput across H.264/H.265/VP9/AV1 in the WebCodecs 720p sample, with output bit-identical to D3D11. (f38fe1e)
    MediaGPU
  • GPU scheduling tuning. GpuImageDecodeCache::TryFlushPendingWork() flushes pending context work again but only signals busy/not-busy when real unlock or deletion work exists, keeping GpuChannelHost::VerifyFlush() from a blocking IPC on the compositor thread each frame (restores 12–35% of per-frame rendering CPU); command-buffer wait boosts are capped at kNormal with a 100 ms escalation so a renderer's readPixels() can no longer jump ahead of Viz DrawAndSwap. (f37e9a5) (494e61e)
    GPUPerformanceCompositor
  • Precompiled Python build actions. New python_binary()/python_action() in build/config/python.gni replace per-action interpreter startup for write_build_config and every Mojom action: 35.9s → 29.7s wall (−17%) and 1124s → 927s CPU across 2,486 mojom actions without __pycache__ (−3% with a warm cache). (789a8a5)
    BuildInfra

Web Platform, Extensions & User Features

  • Web app focus-existing launches now carry user activation. RenderFrameHost::NotifyUserActivation(kWebAppLaunch) fires before EnqueueLaunchParams for deliveries into an already-loaded document (focus-existing, navigation capturing, intent picker, TWA non-nav launches), so window.open() and requestFullscreen() succeed where they previously threw (WICG/web-app-launch#101, ChromeStatus 5191118118584320). Navigating launches are unchanged; killed switch WebAppLaunchHandlerUserActivation defaults on. (440c2c0)
    BrowserUI
  • chrome.windows.getAll() now returns standalone windows such as Document Picture-in-Picture, since the GetBrowserWindowInterface() null filter was dropped. The function->extension() guard in CanOperateOnWindow() is also removed, so IsVisibleToTabsAPIForExtension() is always consulted and platform-app/unrequested DevTools windows are filtered even for WebUI callers — results sets change without any signature change. (0993b1f)
    ExtensionsBrowser
  • Chrome Copy Links plus multi-URL clipboard writes on macOS. New tabs::CopyLinks() writes HTTP/HTTPS tab URLs and titles through ScopedClipboardWriter::WriteURLs() and now excludes non-web schemes (chrome://, view-source:) from that path; ClipboardMac::WriteURLs() writes one NSPasteboardItem per link so plain-text paste joins with newlines and bookmark paste reads every item. (d63250f) (9c2fb02)
