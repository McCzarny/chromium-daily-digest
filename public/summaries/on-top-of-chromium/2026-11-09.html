Chromium Digest: 2026-11-09

Overview

On 2026-11-09 the main branch received 1109 commits, of which 905 were judged relevant to Windows/macOS browser embedders (ChromeOS/Ash, Linux, iOS, Android and Blink/V8 page-processing work excluded). The day is headlined by five public-API breaks — the ContentBrowserClient prerender-prefetch hook, the views::MdTextButton color-override setters, NetworkContextParams::bound_network, base::i18n::GetCanonicalLocale, and the DBSC SessionService signing-quota methods — plus a broad set of security hardening, networking correctness work, and a large wave of release-build CHECK→DCHECK rollbacks. Range: first commit (7ac45ca), last commit (544df16).

Breaking API Changes

  • ⚠️Removed ContentBrowserClient::UsePrefetchPrerenderIntegration() from content/public/browser/content_browser_client.h along with its ChromeContentBrowserClient override, features::UsePrefetchPrerenderIntegration() and kPrefetchPrerenderIntegration (default-on since M151).
