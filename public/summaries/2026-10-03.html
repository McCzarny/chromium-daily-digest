Chromium Digest: 2026-03-30

Overview

This digest reviews 49 commits from Chromium trunk, spanning from (aae0329) to (b495062). Key updates include security hardening around opaque origins and permission revocation, performance enhancements in Crubit rust-to-C++ build concurrency and WebGPU memory transfers, multi-platform UI refinements on macOS and Android, and extensive Blink pointer safety modernization.

Security & Permissions

  • Stricter validation rejects opaque filesystem: URLs in both request and commit checks while preserving the allowance for opaque blob URLs in ChildProcessSecurityPolicyImpl. (077bf0d)
    SecurityStorage
  • Hardened IdleManagerImpl against cross-origin permission leakage by rejecting opaque origins and subscribing to live permission status changes via PermissionController to immediately sever active monitors and halt polling upon permission revocation. (4e1d830) (81c5487)
    SecurityPrivacyBrowser

Blink, DOM, & Core Renderer

  • Migrated productSub, vendor, and vendorSub members to NavigatorID, and statically resolved member [Exposed] annotations on non-[Global] interfaces to eliminate redundant runtime global scope checks in generated bindings. (cc2df82) (7b7f965)
    BlinkHTML
  • Modernized pointer safety across Blink DOM, CSS, SVG, layout, XML, and font subsystems by transitioning raw pointers to UnprotectedInRelease and marking transient stack structures with STACK_ALLOCATED. (de611ab) (39204b5) (99735ae) (3ccf929) (76b175b) (c7739e1) (902eacf) (fac79a9)
    BlinkBase
  • Expanded actionable page content (APC) fallback label extraction (including HTML titles, button alts, SVG metadata, and table summaries) and added logic to remove duplicate labels that match inner DOM text. (b495062)
    BlinkAIAccessibility

GPU, Graphics, & Hardware

  • Re-enabled and stabilized importing dedicated shared memory transfer buffers directly as WebGPU buffers to avoid extra copies during mapped buffer transfers. (96d0fd9)
    WebGPUGPUPerformance
  • Extended gamepad HID parsing to support 48-byte standard Bluetooth input reports and SPI subcommand responses for Nintendo Switch Pro Controllers and Joy-Cons on Linux. (cb7fa52)
    LinuxUSB
  • Gracefully handled null GPU channels in VizProcessTransportFactory during Windows session teardown and increased renderer soft file descriptor limits to 4096 on Linux and ChromeOS. (c2b9efa) (b10b0e3)
    GPUCompositorLinuxWindows

UI & Platform Integration

  • Enabled synchronous widget activation on macOS when focusing a View in an inactive window (kMacActivateWidgetOnFocusRequest), resolving issues where keyboard input bypassed the focused view. (c01f799)
    UImacOS
  • Introduced ViewBuilder for on-demand view construction in AnchoredPopupWindow and optimized snapshot downsampling on iOS by moving rasterization into serial background queues. (0c2d781) (fd430a7)
    AndroidiOSUI

Build System & Developer Tools

  • Parallelized Crubit Rust-to-C++ header generation tasks by separating pure GN metadata targets from action dependencies, breaking Ninja serialization bottlenecks. (336d507)
    BuildPerformance
  • Upgraded PRESUBMIT rules to flag redundant multi-argument BASE_FEATURE macro definitions as errors and cleaned up expired certificate verification and hints-fetcher histograms. (c70964f) (15c38e3) (1291880)
    BuildBaseNetwork
