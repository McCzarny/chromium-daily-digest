Chromium Digest: 2026-09-07

Overview

A summary of Chromium changes for 2026-09-07 (main branch), covering 379 total commits (238 relevant). Ranging from first commit (f4df34e) to last commit (ee5a367).

Blink & Web Platform

  • Implemented float clipping inside line-clamp containers per CSSWG specifications by adding a new LineClampFloatClip property tree node and corresponding layout/fragment flags. (1f237d5) (49ab5f7)
    BlinkCSS
  • Strict validation has been introduced for SVG attribute property base implementations, causing them to correctly fallback to initial values when empty strings are passed instead of accepting them as valid. (c6c0a98)
    Blink
  • Updated WebRTC Encoded Video Frame to throw exceptions instead of hitting NOTREACHED on empty frames, and added width and height properties to RTCEncodedVideoFrameInit. (1c6dbea) (2d83c51)
    BlinkWebRTC

Autofill & Passwords

  • Excluded standalone CVC and IBAN field types from password manager credential parsing to prevent passwords from being incorrectly saved or suggested on payment-only fields. (5f51b75)
    AutofillPasswordManagerPayments
  • Introduced a centralized --mock-otp-value command-line switch across components/one_time_tokens/ and migrated manager modules to bypass network pushes during testing. (42e0262)
    AutofillTesting

Security & Enterprise

  • Hardened Device Bound Sessions by deriving .well-known discovery URLs strictly from authoritative url::Origin structures, preventing port injection attacks and query parameter leakage. (c3341a0)
    SecurityNetwork
  • Implemented multiple controls to restrict features in Enterprise Isolated Mode profiles, including suppressing recent tabs, forcing light color schemes, and blocking WebRTC logging of URLs. (f962c70) (9c54a44)
    EnterpriseProfilesPolicy

ChromeOS & Ash UI

  • Added FaviconServiceProvider to allow ash code to fetch favicons via AccountId, decoupling saved desks, birch views, and window restore utilities from direct chrome dependencies. (a0b8b20) (f6d7c78)
    AshChromeOS

Infrastructure & Stability

  • To resolve production stability issues and release crashes, multiple strict CHECK macros were converted back to DCHECK across critical browser internals like MIME type checks and Cache Storage. (92b285a) (db9f3a2)
    BaseBrowserStorage
  • Upgraded the Siso build engine to version 1.6.0 with corresponding build rule adjustments and added macOS SDK path tracking to GN logs. (5422502) (e1feba3)
    BuildInfra
