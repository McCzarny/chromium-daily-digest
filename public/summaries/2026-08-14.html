Security & Process Architecture

  • Introduced pwc.mojom.PrivilegedBridge, a Mojo capability bridge exclusively for fully qualified, origin-isolated primary main frames of a PrivilegedWebContents with strict static and runtime validation checks. (ce70f9e)
    SecurityBrowser
  • Completely removed SecurityStateTabHelper from the codebase, migrating state computation to on-demand free functions and model delegates. (ead9ffa)
    SecurityUI
  • Tightened macOS GPU process access to Darwin user directories by scoping them to isolated per-process subdirectories using DIRHELPER_USER_DIR_SUFFIX via kMacGpuSandboxDarwinUserDirs. (184ba1c)
    GPUmacOSSecurity

UI, Extensions & Project Bedrock

  • Advanced the Project Bedrock initiative by decoupling core browser UI code, tab controllers, and web handlers from concrete Browser dependencies in favor of BrowserWindowInterface. (057da39) (c457355) (2f2a8f0)
    BrowserUITabs
  • Introduced CreateSplit() and Unsplit() methods into TabListInterface to support split views across platforms, wiring up options in chrome.tabs.create. (ad9f08d) (b159bd6)
    ExtensionsTabsUI
  • Added support for handling UTF-8 character matching, incomplete/invalid sequences, and strict case sensitivity checks within URLPattern::MatchesPath. (6803303)
    ExtensionsNetwork

Blink, Rendering & Web Platform

  • Removed support for the non-standard _current frame target keyword following deprecation and telemetry metrics thresholds. (0751d7a)
    BlinkHTMLNavigation
  • Updated <area> elements to treat themselves as display:none per the official HTML rendering spec, eliminating unnecessary inline boxes and culled-inline hacks. (693c5da)
    BlinkHTML
  • Migrated the setShape API for Isolated Web Apps on ChromeOS from a Blink extension to a standard Blink module interface on Window. (72d209a)
    BlinkChromeOS

Performance, Media & Architecture

  • Expanded AsyncDnsJob to run up to two connection attempts concurrently (primary and secondary slot), utilizing a slow timer to fallback and race IPv4/IPv6 candidates. (3e5a304)
    NetworkPerformance
  • Marked DrawQuadWithSharedQuadState as STACK_ALLOCATED() and adopted mojo::OptionalAsPointer to serialize nullable SharedQuadState and MaskFilterInfo types without unnecessary object copies. (6a42ed0)
    CompositorPerformance
  • Renamed D3D11H265Accelerator to D3DH265Accelerator to decouple it from D3D11-specific API expectations in anticipation of the upcoming D3D12 video decoding pipeline. (1df8907)
    GPUMediaWindows

Mobile Platforms & Infrastructure
