Overview

A summary of Chromium changes for 2026-08-03, covering 544 total commits, of which 390 were relevant. Spanning from commit (3260aa4) to (27cea59).

Security & Isolation

  • Forced origin-keyed process isolation (Origin-Agent-Cluster: ?1) for subframes inside privileged WebContents. (31f5cf3)
    SecurityBrowser
  • Blocked privileged WebContents from registering service workers and connecting to shared workers. (61147bb) (0a8bb52)
    SecurityServiceWorker
  • Fixed Android Content URI vulnerability to prevent File System Access API blocklist bypasses. (cfd4ac7)
    SecurityAndroid
  • Gated service worker window open and focus methods for clients running inside fenced frames. (17630fd)
    SecurityServiceWorker

Autofill & Payments

  • Integrated Wallet orders and shipments into the AutofillAI entity model with sync support. (acad037) (9786e94) (06fb6cf)
    AutofillPaymentsAI
  • Updated suggestion logic to deduplicate obfuscated local values with remote raw CMS suffixes. (5eab1c6)
    Autofill

Architecture & UI

  • Extracted sub-apps install dialog and batch upload delegate out of the monolithic chrome/browser/ui build target into dedicated sub-targets. (9216479) (4499b91)
    BrowserUI
  • Transitioned ZeroSuggestPrefetchTabHelper to be owned directly by TabFeatures as a std::unique_ptr. (643ccef)
    BrowserTabs
  • Removed deprecated Browser::type() and Browser::browser_actions() methods in favor of newer window interface abstractions. (e63c163) (135f89c)
    BrowserUI

Blink & Rendering

  • Standardized video decoding on SubmitDecoderBuffers across Windows platform code and removed obsolete GPU workarounds. (c16050c)
    MediaGPUWindows
  • Moved Windows camera device enumeration off the main thread to prevent UI and video stream freezes. (b43405d)
    MediaWindows
  • Renamed the Container Timing ignore attribute to containertimingignore per standard specification revisions. (3f012c7)
    BlinkHTML
