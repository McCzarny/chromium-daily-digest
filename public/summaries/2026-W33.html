Chromium Weekly: 2026 Week 33

Overview

Chromium development in Week 33 of 2026 featured major progress on Project Bedrock refactoring, security isolation improvements, and tab management enhancements across desktop and mobile. Key architecture shifts include removing legacy IPC factory classes, introducing privileged Mojo capability bridges, and decoupling video accelerators in preparation for D3D12. Across 5 days, 3035 relevant commits out of 3842 total were landed.

Core Architecture & Refactoring

  • ⚠️BREAKING CHANGE: Completely removed legacy IPC factory classes (IPC::ChannelFactory, PlatformChannelFactory, MojoChannelFactory), requiring embedders and internal code to initialize ChannelProxy directly via mojo::ScopedMessagePipeHandle. (d90baa8)
    BaseBrowser
  • ⚠️BREAKING CHANGE: Advanced Project Bedrock by decoupling core browser UI handlers, tab controllers, and view frames from concrete Browser instances in favor of BrowserWindowInterface and BrowserWindowCreateParams. (2dc6b71) (51a0f58) (bed2c76) (057da39) (c457355) (2f2a8f0)
    BrowserUITabs
  • ⚠️BREAKING CHANGE: Added GetNavigationId() as a virtual method on the public content::RenderFrameHost interface to allow public accessors rather than internal getters. (0ab6894)
    NavigationBrowser

Security & Process Isolation

  • ⚠️BREAKING CHANGE: Introduced pwc.mojom.PrivilegedBridge, a Mojo capability bridge restricted to fully qualified, origin-isolated primary main frames of a PrivilegedWebContents with strict runtime validation. (ce70f9e)
    SecurityBrowser
  • Enhanced frame boundary security by denying window creation when the opener WebContents is privileged, and completely removed SecurityStateTabHelper in favor of on-demand free functions. (a26c127) (ead9ffa)
