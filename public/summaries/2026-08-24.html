Daily development digest for Chromium on 2026-08-24, synthesizing 531 total commits (438 relevant) spanning from commit (389b229) to (3af4758).

Architecture, UI & Project Bedrock

  • Continued the 'Project Bedrock' initiative by migrating core browser window features and unowned user data registries away from monolithic Browser instances to BrowserWindowInterface patterns. (e0ed6d5) (5292207) (ded807f)
    BrowserUITabs
  • Decoupled tab dragging implementations into dedicated GN targets and cleaned up legacy browser view unit tests. (e4da516) (e3605d5)
    UIBuildTesting

Performance, Graphics & Core Systems

  • Eliminated redundant Vulkan system info probes during GPU process initialization on Linux, Android, and ChromeOS when no explicit override is active. (6988f55)
    GPULinuxAndroidChromeOS
  • Optimized extension function registry structures to use an absl::flat_hash_map with string_view keys, reducing individual allocations and runtime overhead. (42aa033)
    ExtensionsPerformance
  • Implemented a text-to-style cache for constructible stylesheets, improving Speedometer 3 benchmark scores significantly. (48a45d2)
    BlinkCSSPerformance

Security, Cryptography & Network Infrastructure

  • Added initial ML-DSA support to SSLPlatformKeyCNG (Windows) and the SSPrivateKey framework. (48c2de0) (de57222)
    CryptoSSLWindows
  • Configured Web Store API icon fetches to use a client security state with a blocking Local Network Access (LNA) policy to prevent internal network probing. (1ca8599)
    SecurityNetworkExtensions
  • Introduced PrivateVerificationTokensURLLoaderThrottle to handle Private Verification Token issuance and redemption during browser navigations. (023fae5)
    PrivacyNetworkNavigation

Blink, CSS & Web Platform

  • Updated @apply rule flattening to give each effective MixinMap a unique renderer-wide identifier, preventing mixin state leaks across mismatched document tree scopes. (dd52ddf)
    BlinkCSS
  • Kept lazy-parsing state inline within StyleRule to eliminate separate parser allocations and reduce Oilpan memory consumption. (3cff5eb)
    BlinkCSSPerformance

Mobile, OS & Build Infrastructure

  • Upgraded the Siso build tool to version 1.5.29, adding sandboxing options, improved metrics, and updated protoc integrations. (967eeea)
    BuildInfra
  • Modernized Android TabObserver to use Java default interface methods directly, eliminating obsolete EmptyTabObserver adapter classes. (31460e8) (8a0cb75)
    AndroidTabs
  • Deferred early startup registration for MetricKit subscribers on iOS using low-priority startup pipelines to prevent CPU cache thrashing. (035a5db)
    iOSPerformance
