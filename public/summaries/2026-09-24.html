Security, Privacy & Data Protection

  • Removed the deprecated crypto::SignatureVerifier utility class and updated associated certificate verification flows to use modern alternatives. (d19202f) (0bc3f4b)
    CryptoSecurity
  • Updated Data Controls and Enterprise Connectors to resolve precursor origin URLs for blank or uncommitted frames to prevent bypasses. (fc9908e)
    EnterpriseSecurity
  • Enforced SRI message signatures for synthetic Service Worker responses to prevent signature spoofing. (b47df21)
    SecurityServiceWorker

Blink & Web Platform

    BlinkCSS
  • Split PeriodicWaveHandler out from PeriodicWave and converted real-time audio thread time variables in WaveShaperHandler to std::atomic<double> to eliminate lock contention. (9a20dcc) (b6cc280)
    BlinkMedia
  • Removed the TreeRubyPlacement runtime flag after a stable multi-milestone rollout. (6b6a76d)
    BlinkHTML

Performance, Memory & Allocator Management

  • Added Scudo heap allocator periodic memory purging support via madvise(MADV_DONTNEED) in the out-of-process GPU service on Android. (8bde176)
    AndroidPerformanceGPU
  • Refactored blink::IDBAny to store payloads in a std::variant, shrinking sizeof(IDBAny) from 128 bytes down to 32 bytes. (14e7a29)
    BlinkPerformanceStorage
  • Restricted the ASLR mask and pool size for PartitionAlloc on ARM64 ChromeOS to prevent virtual address space fragmentation. (1e55346)
    ChromeOSPerformance

UI/UX & Browser Features

  • Hardened the bookmark manager row origin display against URL spoofing via prefix truncation and LTR text direction pinning. (a88888f)
    BookmarksUI

    TabsUI
  • Converted generated extension features into constinit const static data objects, shrinking SimpleFeature footprints and reducing chrome.dll size. (cbf068f)
    ExtensionsPerformance
