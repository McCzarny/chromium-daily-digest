Chromium Digest: 2026-09-14

Overview

On 2026-09-14, the Chromium main branch received 626 total commits, with 490 relevant changes analyzed across multiple core subsystems. Highlights include extensive Glic integration work, Blink rendering updates, network and caching enhancements, and security architecture improvements. The development cycle ranged from commit (a4082f8) to (57d2a24).

AI, Glic & Contextual Features

  • Continued heavy development around Glic integration, Android actor features, composebox, context management, and accessibility dialog controls, including background continued processing for Actor tasks on iOS. (e526fbe) (4768e38)
    AIUIiOS
  • Added the --ai-overlay-dialog-test-mode switch to streamline E2E testing workflows for AI overlay dialogs. (bee07ef)
    AITesting

Blink, Rendering & CSS

  • Added CSS text-overflow support to <textarea> elements via the TextOverflowInTextarea feature flag, ensuring ellipsis and string truncation render correctly inside multi-line editor controls. (3df54b3)
    BlinkCSSHTML
  • Optimized 16-bit property and keyword name lowercase transformations in the CSS parser using bit-twiddling tricks, matching the performance of the 8-bit parser. (449faa2)
    BlinkCSS
  • Fixed datalist slider tick marks disappearing entirely below 100% page zoom by clamping painted tick sizes to a minimum of one pixel. (f45701b)
    BlinkUI

Network, Storage & Caching

  • Introduced SharedHttpCacheClient and associated Mojo interfaces to support the Renderer-Accessible HTTP Cache (SQLite-based shared cache), featuring thread-safe in-memory hash set filtering for zero-IPC/zero-disk-IO cache misses. (cf9b6ba) (6747302) (d60e493)
    NetworkStorageBrowser

Security, Privacy & Enterprise

  • Updated Local Network Access (LNA) to stop classifying chrome-untrusted:// origins as loopbacks, preventing potential renderer exploits against internal services. (011c5d2)
    SecurityPrivacy
  • Added input validation to FontSettingsSetFontFunction in extensions to prevent potential font ID structure injection or malicious CSS insertions. (4b57ab6)
    ExtensionsSecurityFonts

Android, iOS & Mobile UI

  • Fixed activity navigation on foldables by ensuring SettingsActivity is explicitly invoked when tapping settings in app menus on folded devices. (bd48874)
    AndroidUI
  • Resolved a bug where opening multiple tabs could evict a background PDF tab and cause it to render blank upon return by forcing synchronous fragment removal on destroy. (750c625)
    AndroidPDFTabs

Infrastructure, Refactoring & Testing

  • Reverted strict CHECK assertions back to DCHECK variants across several core modules (such as overscroll controllers and service workers) to prevent unexpected production renderer crashes on non-fatal invariants. (94d6d74) (bf9e507)
    BaseBrowser
  • Completed codebase-wide migrations enforcing raw_ptr on std::list<T*> and std::queue<T*> containers as part of MiraclePtr memory safety efforts. (f067a2a) (d521714)
    BaseSecurity
