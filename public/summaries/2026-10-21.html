Chromium Digest: 2026-10-21

Overview

On 2026-10-21, the Chromium main branch received 899 commits, of which 741 were relevant after filtering ((8fe8d65), (c83f6c5)). The day was dominated by a large wave of API removals and embedder-facing signature changes: Shared Storage, Top-Level Storage Access, Related Website Sets, per-widget software compositing, trichrome Android targets, and several ContentBrowserClient / base::FeatureList / iOS public API changes. Beyond the breaking changes, work included security hardening, JNI handle modernization, performance improvements, extensive test infrastructure cleanup, and flag removals.
