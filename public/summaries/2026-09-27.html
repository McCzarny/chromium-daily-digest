Chromium Digest: 2026-09-27

Overview

This digest covers **37 commits** from 2026-09-27, ranging from (1498cf2) (revert of a Contextual Tasks integration test) to (0784c35) (Ash shelf window previews). Detailed diff review of the highest-risk candidates — the (ddb2447) and the omnibox enum-class conversions — confirmed **no major breaking changes to stable public APIs**: WebMCP remains an experimental, flag-gated API (RuntimeEnabled=WebMCP), and the enum conversions are internal C++ modernization. The day's activity was dominated by AV1 encoder bitstream conformance fixes, internal migration of six tab helpers to the new TabFeatures architecture, macOS VoiceOver accessibility fixes, and stability/performance work.

Media & AV1 Encoder Fixes

  • Fixed a series of AV1 bitstream conformance bugs in the hardware encoder (media/gpu/av1_builder.cc): allow_warped_motion is now written on inter frames when the sequence enables warped motion, skip_mode_present is emitted when skipModeAllowed evaluates true, and frame-header elements implied by frame type (error_resilient_mode, refresh_frame_flags, frame_size_override_flag, gated use_ref_frame_mvs/primary_ref_frame/reference_select/global motion, use_superres inside frame_size()) are correctly inferred. Each omission or extra bit previously shifted every subsequent syntax element. (380c6e4) (a33531d) (99868f2)
    MediaGPU
  • Additional AV1 conformance fixes: loop filter, CDEF and tx mode are now gated on CodedLossless and loop restoration on AllLossless (lossless frames reachable from WebCodecs with quantizer 0 previously wrote syntax that desynchronized the header); separate_uv_delta_q moved to the sequence header per spec 5.5.2; and fixed-size leb128 padding is now properly terminated with dchecks against truncation. (0046509) (15fd67d) (5a7d254)
    MediaGPU

WebMCP (Experimental Web API)

  • Added document.modelContext.ontoolactivated and ontoolcancel event handler attributes with new ToolActivatedEvent/ToolCancelEvent types, as part of a transition to standardized event attributes per [spec PR #146](https://github.com/webmachinelearning/webmcp/pull/146). (776ddbf) (aa45bc8)
    BlinkAI
  • Removed the WebMCPEvent interface and its WebMCPEventInit dictionary from Blink (~182 deletions); toolactivated/toolcancel events are now dispatched on document.modelContext via the dedicated event classes instead of on window. Not a stable-API break: WebMCP is an in-development, flag-gated API (RuntimeEnabled=WebMCP) still evolving through spec PRs. (ddb2447)
    BlinkAI

Tab Architecture Refactoring (Internal)

  • Continued migration of WebContentsUserData tab helpers to the new TabFeatures/TabFeaturesAndroid architecture: TailoredSecurityUrlObserver, SiteProtectionMetricsObserver, NavigationMetricsRecorder, NavigationPredictorPreconnectClient, NoStatePrefetchTabHelper, and ExternalProtocolObserver were moved off WebContentsUserData inheritance and out of TabHelpers::AttachTabHelpers. Purely internal refactoring with no embedder-facing API impact. (636c3b1) (1d5918e) (70f4169) (59da456) (019110a) (30fa524)
    BrowserTabs

Omnibox Code Modernization

  • Converted AutocompleteProvider::Type from an unscoped C-style enum to a scoped enum class (72 files, e.g. TYPE_DOCUMENT → Type::kDocument with explicit static_cast<int> for bitmask ops), and AutocompleteMatchType to scoped omnibox::AutocompleteMatchType (205 files, e.g. CALCULATOR → kCalculator). Internal C++ type-safety modernization across omnibox, Ash app-list, and quick-insert code; no stable public API removal. (1d9bb5a) (ceb5b20)
    UIBrowser

Accessibility (macOS VoiceOver)

  • Stopped exposing content-derived list names as AXTitle on macOS so VoiceOver no longer announces the text of every item when an unnamed focusable list receives Tab focus; it now announces only the list role and item count, matching Safari behavior. (f1699d6)
    AccessibilitymacOS
  • Excluded the current column header from AXColumnHeaderUIElements on macOS, fixing VoiceOver double-announcing the 2nd through Nth column headers when navigating tables (WebKit behaves the same way). (72aefe3)
    AccessibilitymacOS

Bug Fixes & Stability

  • Fixed a NOTREACHED crash in ThumbnailSchedulerImpl::Schedule by keeping ThumbnailReadinessTracker in kNotReady while a WebContents is discarded (preventing hover-triggered reloads of discarded tabs), and hardened the scheduler against state corruption by updating is_capturing before scheduler callbacks and resetting capture priority to kNone in RemoveTab(). (4ac0142)
    UITabs
  • Relanded the fix for the bookmark manager not opening redirected URLs (legacy numeric IDs → UUID mapping helper), now using a faked browser instance in tests to eliminate the timing flakiness that caused the original revert. (60fdad7)
    BookmarksUI
  • Fixed an in-the-wild renderer kill (Prefetch/IsValidCrossOrigin: frame origin mismatch) in cross-origin <link rel=prefetch> handling: BindContext now tracks did_commit_navigation, stale requests are aborted with net::ERR_ABORTED instead of ReportBadMessage(), and EnsureCrossOriginFactory() is deferred until after origin validation succeeds. (ef7e3ce)
    NetworkNavigation
  • Fixed a tvOS compositor-thread crash by not using Mojo's DirectReceiver on tvOS: ipcz node-link handoff uses a Mach handle, but tvOS transmits over ChannelPosix, which only carries file descriptors. (339bb55)
    BaseCompositor
  • Fixed the Android Glic experimental opt-in dialog being cut off in landscape: now uses a 600×310dp size, caps the card to the available dialog space, and re-reads dimensions on rotation. (ebbb770)
    AIAndroid

Performance

  • Lazily create NavigatorUAData's detached-context brand placeholder list instead of eagerly allocating it in the constructor; navigator.userAgentData access improved ~8.9% (1206→1099 ns) and the constructor dropped from 6.4% to 0.2% of main-thread samples, with observable behavior for detached contexts unchanged. (94b2cc6)
    BlinkPerformance
  • Disabled main-thread YUV async readback in WebCodecs VideoFrame.copyTo() by default (behind disabled-by-default kWebCodecsAsyncYuvReadback), so YUV frames use ReadbackOnThread() instead — RasterInterface::ReadbackYUVPixelsAsync incurred 3 GPU shader passes plus a synchronous GPU-CPU wait, regressing videoFrame-copyTo-videoDecoder.html performance. (df32559)
    MediaPerformance

Security & Policy

  • FM registration token upload now starts its invalidation listener only once the policy core has a CloudPolicyClient, so unmanaged and signed-out desktop profiles no longer check in with android.clients.google.com and register unused FCM tokens at every startup. (89cf896)
    PolicyEnterprise
  • Continued reviving Chromium builds with safe_browsing_mode=0: scoped password-protection, hijacking-detection, suspicious-site UI, redirect attribution, and download-protection paths behind build flags while keeping generic HTTPS, security-state, Page Info, and search-engine settings coverage available in mode 0. (dd5257a) (201fde4)
    SecurityBuild

Blink Editing & IME

Added shared code-point→UTF-16 helpers in ime_code_point_utils.{h,cc} and a stable-status EditContextCodePointDeletion runtime feature. This is a correctness fix for IME behavior, not an API break.
