Chromium Digest: 2026-09-08

Overview

A summary of Chromium changes for 2026-09-08 covering 726 total commits (546 relevant). Ranging from commit (735ee6a) to (146d1cc).

UI & Browser Features

  • Introduced the CachedFlag kAvoidRecreateOnTouchscreenOrColorModeChange to prevent unnecessary activity recreations on Android during touchscreen or color changes. (476e3da)
    AndroidUI
  • Added visual separators between pinned and regular tabs in vertical tab collapse mode. (a0c8a94)
    TabsUI

Blink & Web Platform

  • Added support for the 'before' keyword in scroll-snap-stop, governed by the CSSScrollSnapStopBefore runtime feature flag. (0fbf795)
    BlinkCSS
  • Implemented datagram writable priorities (sendOrder and sendGroup) in WebTransport utilizing stable per-writable FIFO queues. (8806b98)
    BlinkNetwork

Security & Cryptography

  • Updated Windows attestation key certification to leverage native CNG APIs via NCryptCreateClaim rather than assembling low-level TPM commands. (420a23d)
    CryptoSecurityWindows
  • Hardened site token providers against denial-of-service by capping payload sizes at 64KB and returning empty strings in incognito to prevent tracking vectors. (c997740)
    PrivacySecurity

Performance & Infrastructure

  • Added fast-path substring guards and diff checks in PRESUBMIT.py for DanglingUntriaged and base feature macros, slashing execution times by over 90%. (4454d90)
    BaseBuildInfra
  • Added new Hash(HashKind) overloads in crypto/ taking span or string_view and returning owned std::vector digests directly to eliminate output buffer pre-allocation. (8a0c311)
    BaseCrypto
